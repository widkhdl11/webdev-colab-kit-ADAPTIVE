# UI 레이어 규칙
- 비즈니스 규칙 금지 — 판단은 features/entities에서 가져오고 여기선 조합·표시만
- 작업 전 projects/<이름>/docs/design/design-rules.md를 읽는다. checkpoint로 승인된 기준이 취향보다 우선
- **pages/widgets 구현은 승인된 projects/<이름>/docs/design/design-rules.md(status: approved)를 전제로 한다 — 게이트가 강제(design/BEFORE_UI). 미승인이면 화면 구현 전 디자인 국면 먼저.**
- 접근성 기본: 본문 대비 4.5:1 이상, 본문 16px 이상, 이미지 alt, 폼 label 연결
- 외부 링크 target=_blank에는 rel="noopener noreferrer"
- 외부·원문에서 온 이미지는 본문 칸을 넘지 않게(max-width:100%; height:auto) + 내재 치수(width/height) 보존 —
  로드 실패·과대 이미지의 레이아웃 붕괴 방지 (2026-08-02 content-safety 스펙에서 이관: 보안 아닌 UI 사안)
- 색/radius/shadow: 하드코딩 금지 — 디자인 토큰(CSS 변수)으로
- 간격(spacing): 반복되는 공통 레이아웃은 spacing 토큰(--space-*) 사용, 일회성은 px 허용 — 단 모든 간격은 짝수(2의 배수)만 (1px 헤어라인·-1px sr-only 제외)

## 레이아웃 안정성 · 방어적 CSS (2026-10-18 사용자 지시 — 「웹디자인 구현과 QA 할때 적용」)

계기: fankkuk 크리에이터 카드 v28 에서 이름과 팬덤 뱃지를 한 줄에 나란히 뒀더니, 이름(최대 20자)이 길면 뱃지가 최소 폭까지 줄어 「하..」 한 글자만 남았다.
시안과 시험 데이터는 짧은 이름뿐이라 리뷰어 넷과 테스트 2252개가 모두 통과한 뒤 사용자가 물어서야 드러났다. **데이터는 시안보다 길고, 비고, 많다.**

구현할 때 (CSS 를 쓰는 그 자리에서):
- **내용 길이를 정하지 않는다.** 글자가 들어가는 칸은 그 값의 최대 길이(DB 제약·검사 함수의 글자 수)를 찾아 그 길이에서 깨지지 않게 짠다. 한 줄 말줄임을 쓰면 `title` 이나 다른 방법으로 전체 값을 볼 수 있게 한다.
- **한 줄에 늘어나는 것 둘을 나란히 두지 않는다.** 둘 다 가변 길이면 한쪽이 다른 쪽을 밀어낸다 — 줄을 나누거나, 어느 쪽이 먼저 줄지(`flex-shrink`·최소 폭)와 줄었을 때 무엇이 남는지를 정해 둔다.
- flex·grid 자식에는 `min-width: 0`(말줄임이 필요한 칸), 격자 칸은 `minmax(0, 1fr)` — 기본 최소 폭이 내용 폭이라 긴 글자가 칸을 밀어 가로 넘침이 난다.
- 끊을 곳이 없는 긴 문자열(주소·URL·이메일·영문 아이디)은 `overflow-wrap: anywhere`.
- 줄 바꿈이 일어날 수 있는 가로 묶음은 `flex-wrap: wrap` 이거나, 넘침 처리(`+N`·말줄임)가 있어야 한다.
- 글자가 든 상자에 고정 `height` 를 주지 않는다(`min-height` 로). 고정 높이가 꼭 필요하면(같은 높이 카드 격자) 그 줄의 줄 수가 고정이라는 근거가 있어야 한다.
- 이미지·영상·나중에 들어오는 칸(광고·로딩)은 자리를 먼저 잡는다 — `aspect-ratio` 또는 `width`·`height` 속성, `object-fit`. 늦게 들어온 내용이 아래를 밀면(레이아웃 밀림) 안 된다.
- 비었을 때도 모양이 유지되는지 — 값이 없는 줄을 빼면 카드 높이가 달라지는 격자에서는 자리를 남긴다. 목록 0개·1개·많을 때를 각각 정한다.
- 화면 폭 기준 미디어 쿼리로 나눈 격자는, 그 칸이 사이드바 등으로 좁아지는 화면에서도 쓰이는지 확인한다(칸 폭 기준이 맞으면 컨테이너 쿼리).

QA 할 때 (사인오프 전, 브라우저로 — 화면 기능은 화면에서 확인한다):
- **최대 길이 데이터로 한 번 본다**: 이름·제목·팬덤명 같은 칸에 저장 가능한 최대 글자 수를 넣고(DOM 의 글자만 바꿔도 된다), 빈 값·목록 0개·많은 개수도 본다.
- 폭: 390 · 카드가 가장 좁아지는 경계 폭(열 수가 바뀌기 직전) · 1440. 가로 스크롤 0 · 겹침 0 · 잘린 글자에 전체 값을 볼 길이 있는지.
