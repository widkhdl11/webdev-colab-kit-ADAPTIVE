# 계측이 멈춘 것을 턴 끝에 신고하게 한다 (사용자 적용)

`gates/` 는 보호 파일이라 제가 못 씁니다. **판단 로직은 전부 `scripts/` 에 넣었고, 여기
붙일 것은 네 줄입니다.**

## 왜

대시보드 기록은 두 층인데 한 층만 살아 있습니다.

| 층 | 누가 쓰나 | 2026-09-15~17 |
|---|---|---|
| 활동 (`activity*.jsonl`) · 서브에이전트 | 훅 | **정상** — 558줄 |
| 위치·이력 (`transitions.jsonl`·`state.json`) | **모델이 손으로** (`report-note.mjs`) | **0건** |

결과는 빈 화면이 아니라 **살아 있는데 위치만 틀린 화면**입니다. 활동 피드가 흐르니 고장으로
안 보입니다. 그리고 노드별 체류 시간이 영영 안 나오는데, 설계도 대기열의 착공 신호
(③ 왕복 속도 · ④ 실험 공간 · 라이프사이클 뷰)가 전부 그 집계입니다 — **계측이 멈춰 있으면
다음 단계를 시작할 신호 자체가 안 생깁니다.**

## 무엇을 하나 / 안 하나

- **막지 않습니다.** 그래프 밖 작업이나 문서만 고치는 턴에는 전환이 없는 것이 정상이고,
  거부로 만들면 정상인 턴까지 막습니다. 세어서 한 줄 알리는 것이 전부입니다.
- **매 턴 떠들지 않습니다.** 마지막 전환 이후 활동이 60줄(한 턴 분량보다 넉넉히 위) 넘게
  쌓였을 때만 뜹니다. 매 턴 뜨는 알림은 신호가 아니라 잡음이 되고, 잡음은 습관적으로
  넘겨집니다.

## 붙일 것 — `gates/graph-stop.mjs` 두 군데

### ① 파일 위쪽 import 묶음에 한 줄

기존 (13~14행 근처):

```js
import { spawnSync } from "node:child_process";
import { createHash } from "node:crypto";
```

뒤에 다른 import 들이 이어지는데, **그 묶음 맨 끝**에 이 줄을 더합니다:

```js
import { 격차신고 } from "../scripts/measurement-gap.mjs";
```

### ② `HANDOFF 갱신` 을 찍는 줄 **바로 아래**

지금 (479행):

```js
console.log(`● HANDOFF 갱신 (${relative(ROOT, HANDOFF)}). 프론티어: ${f.length ? f.join(", ") : "없음(전부 clean)"}`);
```

그 줄 **다음에** 이 블록을 넣습니다:

```js
// 계측이 멈췄으면 한 줄 신고한다. **막지 않는다** — 그래프 밖 작업이나 문서만 고치는 턴에는
// 전환이 없는 것이 정상이다. 판단은 scripts/measurement-gap.mjs 가 하고 여기서는 찍기만 한다.
// try/catch 로 감싸는 이유는 아래 4.5 절과 같다 — 이 훅에는 최상위 try/catch 가 없어서
// 여기서 던지면 6단계(차단 판정, exit 2)에 영영 도달하지 못한다.
try { const 격차 = 격차신고(); if (격차) console.log(격차); } catch { /* 계측 신고가 차단을 막으면 안 된다 */ }
```

## 적용 전후 판정 — 코드를 안 읽어도 됩니다

```
node scripts/check-measurement-gap.mjs --require-wiring
```

- **적용 전**: `FAIL G1 — gates/graph-stop.mjs 가 이 도구를 부른다` · **종료 코드 1** (실측 확인)
- **적용 후**: `계약 테스트 통과` · **종료 코드 0**

`--require-wiring` 없이 부르면(게이트가 그렇게 부릅니다) 배선이 없어도 **막지 않고**
「배선 대기 1건」 한 줄만 찍습니다. 배선은 보호 파일 패치라 사용자만 할 수 있는데, 그걸
게이트 실패로 만들면 패치를 붙일 때까지 **다른 모든 작업이 막히기** 때문입니다.
대신 조용해지지는 않습니다 — 이 패치 문서가 사라지면 미루기의 근거가 없어진 것으로 보고
그때는 그냥 실패합니다.

G1 은 배선을, G2 는 그 배선이 `try/catch` 안에 있는지를 봅니다. **판단 로직이 멀쩡해도
부르는 자리가 없으면 화면엔 아무것도 안 뜬다**는 것이 이 두 항목이 지키는 것입니다.

검사에는 **일부러 어긋난 상태를 심어 잡히는 것을 보는 항목**이 들어 있습니다:

| 항목 | 심은 것 | 안 잡히면 무엇이 통과하나 |
|---|---|---|
| B | 전환이 옛날에 멈춘 상태 | 「언제나 침묵」인 구현 |
| C2·C3·C4 | 멀쩡한 상태(임계 미만·기록이 따라옴) | 「언제나 신고」인 구현 |
| D | 전환 줄 순서가 뒤섞인 파일 | 마지막 줄만 믿는 구현 (옛 줄 하나로 격차가 사라진다) |
| H3 | 오늘치 파일만 센 결과 | 날짜별로 갈라진 파일을 안 읽는 구현 |

H 는 실제로 한 번 틀렸던 자리입니다. 처음엔 `activity.jsonl` 만 읽었는데, 그 파일은 날마다
`activity-YYYY-MM-DD.jsonl` 로 넘어갑니다. 그래서 **며칠에 걸친 고장이 하루치로 보여**
임계에 못 미쳤습니다 — 오래 멈출수록 안 잡히는 셈이라 정확히 거꾸로였습니다.
2026-09-15~17 의 실제 고장으로 재 보니 45줄이었고, 넘어간 파일까지 읽으니 **394줄**로
확실히 잡힙니다.

## 부분 적용 조합 — 어느 쪽이든 안전하게 실패합니다

패치가 두 군데(import + 호출)이고 `scripts/` 쪽 새 파일 둘에 기댑니다. 조합을 하나씩 확인했습니다.

| 조합 | 무슨 일이 나나 | 안전한가 |
|---|---|---|
| `scripts/` 만 있고 패치 안 붙임 | 아무 일도 안 난다. 검사가 `G1` 로 실패해 안 붙었다고 말한다 | 안전 |
| import 만 넣고 호출 안 넣음 | 아무것도 안 찍힌다. `G1` 이 `격차신고` 가 없어 계속 실패한다 | 안전 |
| 호출만 넣고 import 안 넣음 | `격차신고 is not defined` 가 **try/catch 에 잡혀** 조용히 넘어간다. 훅은 그대로 돌고 차단 판정도 그대로 | 안전 (다만 조용하다 — `G1` 이 통과로 보일 수 있으니 ②를 넣었으면 ①도 넣을 것) |
| 패치는 붙였는데 `scripts/measurement-gap.mjs` 가 없음 | **import 가 모듈 로드 시점에 던진다 → 훅이 통째로 죽는다.** 이 조합만 위험하다 | **위험** |

마지막 조합은 패치와 스크립트가 같은 커밋에 있으면 생기지 않습니다. 걱정되면 import 대신
호출 자리에서 동적으로 부르는 쪽으로 바꿀 수 있는데, 그러면 그 줄이 `await` 를 쓰게 되고
찍는 순서가 달라집니다 — 지금은 같은 커밋 전제로 정적 import 를 골랐습니다.
