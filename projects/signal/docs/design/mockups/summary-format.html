AI 요약 서식 — A안 / B안

두 안은 같은 요약 글을 담았다. 다른 것은 순서와 B안의 「핵심」 라벨뿐이다. 각 안마다 왼쪽이 1280px 화면(읽기 컬럼 704px), 오른쪽이 390px 휴대폰 폭이다.

A안 — 지금 순서 (요약 문단 → 표 → 핵심 목록)

지금 화면과 같은 순서에 서식만 더했다. 처음 읽는 것이 문단이라 흐름은 자연스럽지만, 요점이 맨 아래에 있어 훑어보는 사람은 표까지 지나야 닿는다.
