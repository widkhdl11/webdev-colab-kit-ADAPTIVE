## 2026-08-02 · 피드 + 소식 상세 · checkpoint 승인

첫 시각 방향이다. 이후 화면은 특별한 사정이 없는 한 이 언어를 물려받는다.

### 한 줄

**깔끔한 뼈대에 귀엽고 가벼운 디테일.** 가벼운 SNS 피드처럼 훑되 피로감은 낮게.
발랄함은 캐릭터나 일러스트가 아니라 **포인트색·라운드·작은 움직임**에서 나온다.

### 색

라이트 전용. 다크 모드는 지금 범위가 아니다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#EFEFF5` | 페이지. 라벤더 기가 도는 옅은 회색 |
| `--surface` | `#F8F8FC` | 카드·요약 박스. 페이지보다 **밝다** |
| `--surface-h` | `#FDFDFF` | 호버. 순백 직전까지만 |
| `--sunken` | `#E5E5EE` | 코드 블록. 글 흐름에서 눌러 앉는 면 |
| `--hairline` | `#E2E2EC` | 헤더 밑선 |
| `--dot` | `#C9C9D6` | 점선 구분선 |
| `--text` | `#1F2024` | 본문. 순검정은 쓰지 않는다 |
| `--text2` | `#4A4E55` | 요약문 |
| `--meta` | `#656A72` | 출처·시각 등 메타 |
| `--accent` | `#4F46E5` | 포인트색(인디고) |
| `--accent-soft` | `#E9E8FB` | 뱃지 배경 |

**순백 배경은 쓰지 않는다.** 매일 훑는 리더라 눈부심이 그대로 비용이 된다.
레퍼런스(biko)는 흰 페이지에 회색 카드였지만 우리는 명암을 뒤집었다 — 회색 페이지에 밝은 카드.
부수효과로 카드 분리가 더 뚜렷해졌다.

**포인트색은 면적을 최소로.** 활성 상태, '뜨는 중' 뱃지, 로고 점, 링크 정도에만 닿는다.
전면 배경으로 까는 것은 금지. 2차 강조색(초록 등)도 두지 않는다.

### 형태와 입체감

- 카드 라운드 **12px**, 칩·버튼·세그먼트 토글은 **완전 알약(999px)**, 이미지 8px
- **입체감은 "아직 안 봄"의 신호다.** 안 읽은 카드에만 아주 옅은 그림자를 두 겹으로 준다:
  `0 1px 2px rgba(31,32,36,.05)`(경계를 또렷하게) + `0 4px 10px rgba(31,32,36,.05)`(면을 살짝 띄우기).
  읽은 카드는 그림자가 없다. 호버는 `0 2px 4px rgba(31,32,36,.06)` + `0 10px 22px rgba(31,32,36,.08)`
  에 `translateY(-1px)`
  > 처음에는 레퍼런스를 따라 "그림자 없이 면으로만 분리"로 갔다가, 읽음/안읽음 구분이 약해
  > 이 규칙으로 대체했다. 입체감이 상태를 나르는 쪽이 흐릿함과 같은 방향으로 겹쳐 작동한다.
- 테두리 선은 거의 쓰지 않는다. 면과 그림자로 나눈다

### 타이포

- **Pretendard** 하나. 코드 블록만 모노
- **크기 단계를 늘리지 말고 굵기로 위계를 만든다.** 지금 쓰는 단계: 28 / 22 / 16 / 13.5 / 12,
  굵기 800·700·600·500
- 초대형 헤드라인 금지. 피드 페이지 제목도 22px/700까지
- 상세 본문은 **17px, 줄높이 1.78, 읽기 컬럼 704px** — 이 사이트의 핵심 가치가 "편하게 읽기"다

### 레이아웃

- 최대 폭 **1168px** 중앙 정렬. 카드 그리드 3열, gap 16px, 카드 안쪽 padding 16px
- 데스크톱 우선. 980px에서 2열, 640px에서 1열
- 상단 헤더는 아주 얇게. 네비 메뉴는 두지 않는다(2페이지짜리 개인용)

### 시그니처 (이 사이트를 알아보게 하는 것)

1. **카드 안 점선 구분선** — 제목·요약 블록과 아래 메타 줄을 나눈다. 상세에서도 이어 쓴다
2. **알약 필터 칩 줄** — 정렬 세그먼트 토글 + 주제 태그 칩이 목록 위에 나란히
3. **뱃지로 압축한 정보** — '뜨는 중', 태그 칩

### 상태 규칙

- **읽음**: 카드 채움을 페이지 쪽으로 눕히고(`#F3F3F8`), 제목 `#666B73`/굵기 600, 요약·메타 `#6A6F77`,
  태그 칩 글자 `#63676F`, 그림자 제거.
  **흐릿하게 = 눌러두는 것이지 못 읽게 만드는 게 아니다** — 읽은 항목도 대비 4.5:1을 지킨다
- **호버·포커스에서 완전 복구**: 읽은 카드도 색·굵기·입체감이 안 읽은 카드와 같아진다.
  다시 읽으려는 순간에는 또렷해야 한다. 키보드 이동(`:focus-visible`)도 같다
- **뱃지 중립화**: 읽은 카드의 '뜨는 중' 뱃지는 포인트색을 잃는다.
  색은 "아직 안 본 것"에만 쓴다
- 상태를 색으로만 알리지 않는다. 읽음에는 스크린리더용 텍스트를 함께 둔다

### 날짜 그룹

수집이 매일 아침 한 번 도는 배치라, **날짜가 1차 묶음이고 정렬(뜨는순/최신순)은 그 안에서 2차**다.
점수가 날짜를 가로지르면 "오늘 뭐 왔지"를 볼 수 없다.

- 섹션 헤더는 절제한다: 13.5px, 메타색 + 굵기. 옆에 그날 건수를 작게(`오늘 · 5건`),
  남는 폭은 시그니처인 점선으로 채운다
- 제목 계층은 h1(페이지) → h2(날짜) → h3(카드)
- '뜨는 중' 뱃지는 전역 상위가 아니라 **그룹 안에서의 상위**에 붙는다

### 접근성

- 텍스트 대비 **4.5:1 이상**. 포커스 스타일을 제거하지 않는다
- 이건 장식 규칙이 아니라 실제로 설계를 몇 번 바꿨다:
  레퍼런스의 메타색 `#8A8F95`는 우리 카드 위에서 2.95:1이라 탈락했고,
  읽음 상태를 더 흐리게 하려다 색으로는 바닥에 막혀 **굵기까지 낮추는 쪽**으로 풀었다.
  태그 칩은 배경이 카드보다 어두워서 글자색을 따로 뒀다
- 현재 최저값 4.57:1(읽은 카드의 요약·메타). **더 흐리게 하려면 색이 아닌 수단을 써야 한다** —
  카드를 접어 부피로 줄이는 방식이 다음 후보다
- 움직임은 `prefers-reduced-motion`을 존중한다

### 하지 않는 것

- 포인트색 전면 배경(히어로·네비 풀블리드)
- 초대형 헤드라인(60px 굵은 제목류)
- 마스코트 캐릭터·3D 이모지 일러스트 — 귀엽되 유치하지 않게. 작은 이모지 포인트까지만 허용
- 복잡하고 산만한 포털 룩: 사이드바·배너·위젯 나열. 한 줄기 피드 + 최소 컨트롤만
- 카드 제목을 한 줄에서 `…`로 자르는 것 — 2줄까지 허용한다
- 순백 배경, 2차 강조색

### 아직 안 정한 것

- 다크 모드 (범위 밖)
- 빈 상태·오류·로딩 화면 — 필요해질 때 시안으로 확인받고 여기 덧붙인다
- 모바일 전용 조정 — 지금은 1열로 접히는 수준까지만 봤다
