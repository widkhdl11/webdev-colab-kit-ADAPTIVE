### https://www.biko.kr/ (+ /practice)

- **색**: 주조 = 선명한 보라 `#9E4EFF` ~ `#7125EC` (히어로 전면 배경으로 대담하게 사용) · 배경 = 흰색 `#FFFFFF`,
  카드 채움 = 아주 옅은 회색 `#F7F8F9` · 본문 검정 `#000`, 메타 회색 `#8A8F95` · 강조 초록 `#37FFA9`(히어로 카피) · 라이트 전용, 다크 없음
- **타이포**: Pretendard 단일. 히어로 h1 60px/w800/자간 -1.8px (아주 굵고 자간 좁음), 섹션 h3 36px/w800,
  본문 16px/w400/줄높이 1.6, 메타 12px. 굵기 대비로 위계를 만들고 크기 단계는 단순함
- **밀도**: 여유~중간. 최대 폭 1168px, 카드 3열 그리드에 gap 16px, 카드 내부 padding 16px. 섹션 사이 여백은 크게
- **형태**: 카드 radius 8px(목록) / 16px(홈 큰 카드), 필터·버튼은 **완전 알약**(100px·9999px).
  목록 페이지는 **그림자를 거의 안 씀** — 회색 채움으로 카드를 분리. 홈만 아주 옅은 그림자 `rgba(154,154,154,.12) 0 1px 20px`.
  테두리 선도 거의 없음
- **레이아웃**: 상단 고정 네비(보라 배경) → 페이지 타이틀 배너(보라 전면) → 알약 필터 줄 + 검색 → 카드 3열 그리드 → 페이지네이션
- **시그니처 요소**:
  1. **점선(dotted) 구분선**이 카드 안에서 제목과 메타를 나눔 — 가볍고 친근한 인상의 핵심
  2. **알약 필터 칩 줄**(난이도·유형·키워드 드롭다운)이 목록 위에 나란히
  3. 카드 좌상단 `#4925` 회색 ID + 노란 원형 `Lv.1` 뱃지 → 정보를 뱃지로 압축
  4. 마스코트 캐릭터(비버) + 3D 이모지 일러스트로 플레이풀함을 공급
- **한 줄 인상**: "이 사이트는 **뼈대는 아주 얌전한 회색 카드 그리드인데, 색과 캐릭터로만 발랄함을 얹은** 느낌"

## signal 이 가져올 것 / 버릴 것

| 가져올 것 | 버릴 것 |
|---|---|
| 카드 안 **점선 구분선**(제목 ↔ 메타) — 귀엽고 가벼운 인상을 값싸게 | **보라 전면 배경**(히어로·네비 풀블리드) — 하루 몇 번 훑는 리더엔 피로 |
| **그림자 없이 옅은 회색 채움**으로 카드 분리 — 눈이 편함 | **60px w800 초대형 헤드라인** — 소식 피드엔 과함 |
| **알약 필터 칩 줄**(정렬 토글·주제 필터에 그대로 적용) | **마스코트 캐릭터·3D 이모지** — "유치하지 않게" 선을 넘음 |
| **작은 회색 메타**(12px)로 출처·시간 눌러두기 | 카드 제목이 한 줄에서 `...`로 잘리는 것 — 피드는 2줄까지 허용 |
| **Pretendard**, 크기 단계는 적게 두고 **굵기로 위계** | 초록 등 2차 강조색 — 포인트색 하나로 |
| 최대 폭 ~1168px, 카드 gap·padding 16px 리듬 | |
