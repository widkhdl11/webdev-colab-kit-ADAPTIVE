알림 패널 시안

승인된 세 언어(랜딩·목록·상세)는 전부 종이 위에 세로로 쌓이는 화면이라 떠 있는 면이 하나도 없었습니다. 이 시안이 그 언어를 처음 만듭니다. 한 페이지에 같은 부품의 다섯 상태를 세로로 늘어놓았고, 자바스크립트는 쓰지 않았습니다 — 각 블록이 이미 열린 모습입니다.

상태 1

패널이 열린 기본 상태

안 읽음 3줄 + 읽음 3줄. 알림 다섯 종류(신청·수락·거절·강퇴·나감)가 한 번씩 나옵니다. 패널은 종 바로 아래, 헤더 아래쪽 테두리에서 8px 떨어져 뜨고 폭은 360px 입니다. 뒤 화면은 어둡게 덮지 않습니다 — 드롭다운은 바깥을 가리지 않습니다.

상태 2

링크가 없는 줄 — 스터디가 지워졌을 때

문장은 그대로 남고, 스터디 이름에만 잉크 취소선이 그어집니다. 시각 옆에 「지워진 스터디예요. 열 수 없습니다」가 붙고, 마우스를 올려도 줄이 반응하지 않습니다. 마크업도 링크가 아니라 그냥 요소입니다(a href 를 쓰지 않았습니다). 아래 세 줄 중 마지막이 비교용으로 둔 평범한 줄입니다.

왜 취소선인가

색을 죽이면 두 가지가 깨집니다. 문장을 약한 잉크로 내리면 「읽음」과 구분이 사라지고, 더 흐린 색을 새로 만들면 대비 하한(4.5:1)에 걸립니다. 취소선은 색을 건드리지 않으면서 「이건 이제 없다」를 형태로 말합니다 — 다이어리에서 끝난 줄에 줄을 긋는 것과 같은 어휘입니다.

낭독기는 취소선을 읽지 않으므로, 같은 뜻을 시각 옆 안내 문구가 글자로 맡습니다.

상태 3

안 읽은 것이 없는 상태

종 옆에 코랄 숫자 알약이 없고, 「전체 읽음」은 비활성입니다. 왼쪽 4px 띠 자리는 비어 있어도 그대로 남습니다 — 없애면 읽음/안 읽음이 섞였을 때 문장 시작점이 줄마다 어긋납니다.

설명 문구를 「참가 신청이 오거나 신청 결과가 정해지면 여기에 쌓입니다」로 썼습니다. 알림 다섯 종류를 하나로 묶은 말이라 강퇴·나감이 문장에 안 들어갑니다. 다섯을 다 적으면 길어져서, 사용자가 가장 자주 받을 둘만 골랐습니다.

상태 5

모바일 — 같은 카드가 폭만 화면 가득

시트도 모달도 서랍도 아닙니다. 같은 드롭다운이 좌우 12px 만 남기고 넓어집니다. 헤더는 승인된 모바일 헤더 그대로 네비가 아래 한 줄로 내려갑니다. 아래 틀은 375px 폭 래퍼로 흉내 낸 것입니다(iframe 을 쓰지 않았습니다). 로그아웃 버튼은 이 시안이 정하는 것이 아니라 생략했습니다.

이 시안이 새로 정한 것

떠 있는 면 — 2px 잉크 테두리 · 둥글기 18px(카드와 같음) · 그림자는 승인된 큰 쪽 0 12px 26px rgba(80,66,44,.18). 새 색도 새 그림자 값도 만들지 않았습니다. 바깥을 덮는 어두운 막은 없습니다.

패널 안 줄 — 여백 14/14, 왼쪽은 띠 4px + 12px = 16px. 줄 사이는 2px 점선 괘선(카드 내부 구분 규칙 그대로). 머리도 같은 점선으로 갈립니다.

링크 없는 줄 — 스터디 이름에 2px 잉크 취소선 + 「지워진 스터디예요. 열 수 없습니다」 + hover 무반응 + a href 아님.

삭제(×) — 기본은 테두리 없이 아이콘만(항상 보입니다), 마우스를 올리면 2px 잉크 테두리가 나타납니다. 키보드 초점은 포커스 링(3px 잉크 실선)이 맡습니다 — 테두리를 겹치면 두 겹이 됩니다. 인터뷰 결론대로 한 번에 지워지고 확인 단계가 없습니다.

남이 쓴 글자 — 스터디 이름은 호스트가 자유롭게 정한 값이고 그 뒤는 제품이 쓴 말입니다. 굵기만으로는 안 갈리므로(안 읽은 줄에서는 700 대 600) 이름을 낫표 「」로 두릅니다. 낫표가 굵게 밖에 있는 것은 「누를 수 없는 줄」의 취소선이 이름에만 걸리게 하려는 것입니다 — 안 읽은 줄에서 낫표와 이름을 가르는 신호는 아닙니다(둘 다 잉크입니다). 호스트가 제목에 적어 넣은 낫표는 그릴 때 겹낫표 『』로 바뀝니다 — 그래야 두름을 흉내 낼 수 없습니다. 2026-09-09 추가.

비활성 톤 — 「전체 읽음」이 비활성이면 테두리만 잉크에서 괘선으로 내리고 글자는 약한 잉크입니다. design-rules 에 비활성 톤이 없어서 이 시안이 처음 정합니다.
