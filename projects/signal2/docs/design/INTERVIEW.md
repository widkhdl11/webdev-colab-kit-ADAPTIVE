# 디자인 인터뷰 — signal (피드 + 상세)

회차: 3 — **인터뷰 종료(확정)**. 이 문서는 시안(design-drafter)의 입력이다.

> ✅ **확정된 방향 (2회차에서 사용자 승인 "1번 맞고"):**
> "**깔끔한 뼈대 + 귀엽고 가벼운 디테일**" — 정돈은 미니멀하게 하되, 무겁고 진지한 '테크' 룩이 아니라
> **가벼운 SNS 피드처럼 피로감 낮게**. 라이트 톤, 살짝 라운드, 포인트색은 **보라-파랑 사이(페리윙클/인디고)**.
> 피드는 카드(제목+짧은 요약)를 훑다가 누르면 상세로.

## 1. 무엇을 만드나
- 화면/페이지: **피드(소식 목록)** + **소식 상세(원문 전문)**
- 목표: 피드 = 뜨는 것부터 빠르게 훑기 / 상세 = 원문을 사이트 안에서 편하게 읽기
- 보는 사람: 나 자신(+소수), 하루 몇 번 짧게 훑고 관심 것만 깊게. 로그인 없음.

## 2. 원하는 느낌
- 무드: **[o]미니멀 [o]플레이풀** — (귀엽고 가벼운 SNS 느낌, 피로감 낮게)
  > 🤖 종합: **미니멀=구조/여백**, **플레이풀=디테일(둥근 카드·부드러운 색·산뜻한 태그 칩·작은 이모지 포인트 허용)**.
  > 즉 "차분한 레이아웃에 친근한 온기". 진지한 대시보드/포털 룩은 배제.
- 절대 아니어야 할 느낌: **(a) 복잡·산만한 포털** ← 사용자 선택(2회차)
  > 결과: 한 화면에 위젯·배너·사이드바를 늘어놓지 않는다. **한 줄기 피드 + 최소 컨트롤(정렬 토글·주제 필터)**만.
  > 정보 종류를 늘리는 대신 **여백과 뱃지로 압축**한다. (b)차갑고 딱딱함은 어차피 '플레이풀' 무드가 막아줌.
  > 귀엽되 **너무 유치하지 않게**(성인 리더) — 이 선은 유지.
- 밀도: **중간** (사용자: "피드는 카드로 제목+간략 요약, 누르면 상세")
- 톤: **[o]라이트**
- 모서리: **[o]살짝 라운드**
  > 🤖: SNS·귀여움 방향이면 라운드를 조금 더 키워도 좋습니다(살짝~중간). 시안에서 보여드릴게요.
- 폰트 느낌: (사용자: "귀여운 느낌, 가벼운 SNS 글 보는 느낌")
  > 🤖 추천: **본문은 친근한 고딕(둥근 인상의 산세리프)**, 코드블록만 모노. 메타(시간·출처)는 작고 가볍게.
  > (1회차의 '메타도 모노'는 딱딱해질 수 있어 철회 — 부드러운 방향에 맞춰 조정)

> 요약: biko 는 "**뼈대는 아주 얌전한 회색 카드 그리드인데, 색과 캐릭터로만 발랄함을 얹은**" 사이트다.
> 우리는 **뼈대(점선 카드·알약 칩·회색 채움)는 그대로 가져오고, 발랄함의 공급원만 캐릭터 대신
> 포인트색·라운드·마이크로 인터랙션으로 바꾼다.** 이게 "귀엽되 유치하지 않게" 선을 지키는 방법.

## 4. 색
- 포인트색: **보라-파랑 사이(페리윙클/인디고)** — 사용자 지정
  > 🤖 제안: 포인트색 **페리윙클~인디고**(예: #6366F1 인디고 / #7C83FF 페리윙클 근처), 배경은 **살짝 라벤더 기 도는 밝은 중립**
  > (순백보다 눈이 편함 — 피로감 낮추기 요구에 맞음). '뜨는 것'·활성 상태에만 포인트색, 나머지는 중립 회색.
  > 시안에서 **톤 2안**(a: 조금 더 파랑=인디고 / b: 조금 더 보라=페리윙클~바이올렛)을 비교한다.
  > 정찰 참고: biko 의 `#9E4EFF`는 우리 페리윙클보다 훨씬 채도가 높다. **면적을 줄이고(칩·활성 상태만)
  > 채도를 낮춰** 쓴다 — 전면 배경으로 깔지 않는다.
- 중립 팔레트(정찰에서 가져옴): 카드 채움 `#F7F8F9` 계열(단, 살짝 라벤더 기), 메타 텍스트 `#8A8F95` 계열,
  본문은 순검정 대신 `#1F2024` 정도(피로감 낮추기)

## 5. 구성
- 피드: 항목 카드(제목·요약·출처·상대시간·태그) + 정렬 토글(뜨는순/최신순) + 주제 필터
- 상세: 제목·출처·시각·태그 + 원문 본문 + 출처 원문 링크
- 안 넣을 것: 댓글·공유·로그인 UI (PRODUCT 비범위)
- 반응형: **[o]데스크톱 우선** (모바일도 되게)

## 인터뷰 결론 (→ design-drafter 입력)

1. **한 줄**: 깔끔한 뼈대 + 귀엽고 가벼운 디테일. 가벼운 SNS 피드처럼 피로감 낮게.
2. **금지**: 복잡·산만한 포털(위젯·배너·사이드바 나열). 유치함(캐릭터·3D 이모지).
3. **뼈대**: biko 식 카드 그리드 — 점선 구분선 카드 · 그림자 없이 옅은 회색 채움 · 알약 필터 칩 줄 · 작은 회색 메타.
4. **발랄함의 공급원**: 캐릭터가 아니라 **포인트색·라운드·마이크로 인터랙션**.
5. **색**: 라이트. 포인트 = 페리윙클~인디고, 면적 최소(칩·활성·'뜨는 것'). 배경은 살짝 라벤더 기 도는 밝은 중립.
6. **타이포**: Pretendard(둥근 인상 고딕), 크기 단계 적게 + 굵기로 위계. 코드블록만 모노.
7. **레이아웃**: 데스크톱 우선, 최대폭 ~1168px, gap·padding 16px 리듬. 피드는 카드, 상세는 읽기 컬럼.

**남은 선택은 시안에서**: 포인트색 톤 a(인디고=파랑쪽) vs b(페리윙클=보라쪽), 라운드 강도(살짝~중간).
