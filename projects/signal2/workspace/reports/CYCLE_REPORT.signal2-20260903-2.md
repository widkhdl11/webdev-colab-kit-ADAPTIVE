## 4. 구조 변경 요약

**판정이 한 자리로 모였다.** 승격 판정·사이클 종료 판정·보류 상한이 각각 검사 스크립트 안에만
있었는데, `gates/lib/cycle-policy.mjs` 로 빼고 게이트·훅·검사가 전부 그것을 부르게 했다.
**게이트는 판정을 부르되 쓰지는 않는다** — 승격도 사이클 마감도 무엇을 적을지 판단해야 하는
쓰기라 사람과 에이전트가 한다. 강제는 쓰기가 아니라 검사로 한다: 2회가 쌓인 항목이 처리 없이
대장에 남으면 `[promotion/UNPROCESSED]` 로 실패한다.

**상한이 코드에 생겼다.** 문서에는 `상한(N)` 이라고만 적혀 있고 숫자 5 는 `PENDING.md` 산문에만
있었다. 훅의 종료 판정은 상한을 아예 안 봤다 — 보류가 몇 건 쌓여도 아무 일도 안 났다.
이제 `PENDING_CAP` 한 자리에만 숫자가 있다.

**`scope` 어휘에 하네스 칸이 생겼다.** 없어서 하네스 결정 열여섯 건이 전부 `api` 로 기록됐다.
그대로 승격됐으면 "바깥과 주고받는 자리"의 근거라고 선언된 규칙이 생길 뻔했다.

**훅이 파싱되는지를 검사가 본다** (`check-hooks` 56 → 58). `graph-stop.mjs` 에 닫는 `});` 한 줄이
빠져 파일 전체가 SyntaxError 였고 Stop 훅이 매 턴 죽어 있었는데, 그것을 잡으라고 만든 항목은
"배선이 안 됐다"고만 말했다 — **훅이 죽은 것과 훅이 할 일이 없던 것은 출력이 똑같다.**

**두 벌 동기화 검사가 게이트에 편입됐다**(전체 실행 전용, `--repo-only`). 편집 훅에 넣으면
`CLAUDE.md` 를 고치는 순간 두 벌이 어긋나고, 그걸 푸는 유일한 길인 `AGENTS.md` 편집이 같은
게이트에 막힌다.

**협업 규칙 문서가 207 → 195줄.** 리뷰어 라우팅 14줄을 `docs/references/review-signoff.md` 로 강등.

데이터 모델·페이지 구성은 바뀌지 않았다.
