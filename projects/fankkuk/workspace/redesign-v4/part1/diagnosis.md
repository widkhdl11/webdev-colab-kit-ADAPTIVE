# 1파트 팬 화면 다섯 진단 — 시안 4 기준 (2026-11-01)

비교 페이지: `docs/design/mockups/part1-v4-20261101/index.html` (지금 캡처: `docs/design/mockups/part1-v4-20261101/now/`). 원칙 번호는 `docs/design/design-prompt.md`.
문구·칸 순서·노출 조건은 지금 코드 그대로 두고 배치·위계·간격·색·경계·정렬만 다뤘다. 코드(`src/`)는 건드리지 않았다.
탭 다섯: 지금 할 일(세 상태) / 보낸 선물(진행 중·완료 탭) / 선물 상세(등록됨·발송됨·거절됨·기한 지남) / 함께한 시간 / 받은 선물(빈 상태·받는 중 목록). 열네 상태 × PC 1440 · 휴대폰 390.
캡처가 있는 상태(9장 모두)는 캡처 그대로, 캡처가 없는 상태(지금 할 일 여러 건·빈 상태, 보낸 선물 완료 탭, 받은 선물 받는 중)는 코드의 CSS 값(`action-center.module.css`·`gift-list.module.css`·`gift-status.module.css`·`together.module.css`·`my-revgifts.module.css`·`todo-box.module.css`·`base.css` 21절)으로 같은 틀에 다시 그린 「지금(재현)」이다.
기한 지남 캡처 둘(FC-W5N3T·FC-P4X7N)은 화면이 같아 하나로 합쳤다. 캡처 일부는 왼쪽 메뉴가 접힌 채(64) 찍혀 있다 — 왼쪽 메뉴는 이 파트 범위 밖이라 바꾼 뒤 시안에는 펼친 240 으로 그렸다.

1파트는 10-21 · 10-22(21·22·23절)에 이미 「강조 하나 + 촘촘한 줄」, 폭 제한, 같은 모양 카드, 위계 있는 상세, 사진 앨범으로 정리돼 시안 4와 겹치는 곳이 많다. 그래서 바뀌는 곳은 제목·뱃지·탭·선 버튼처럼 4파트(5·6·7)에서 먼저 정한 공통 부품과, 이 화면들 고유의 칸·정렬 몇 곳이다.

## 1. 지금 할 일 `/me/actions`
지금과 어긋나는 곳

## 승인 기준과 부딪혀 판단한 곳
1. **33절 「선물 정보 카드가 PC 반 폭, 오른쪽 반은 비움」 대 2-9**: 거절 · 기한 지남에서 「발송하지 마세요」 상자를 같은 줄 왼쪽에 놓아 빈 반을 채웠다. 33절 문장을 바꾸는 제안이다 — 정할 것 1.
2. **35절 팬 홈 뱃지(`.stt`)의 24% 테두리 대 37절 「누르지 않는 표시에 선을 두르면 버튼처럼 보인다」**: 시안은 테두리 없이 점 + 글자로 그렸다. 팬 홈 뱃지는 구현에 연한 테두리가 있어 둘이 다르다 — 정할 것 3.
3. **「한 화면에 강조 하나」(21절) 대 상세의 하늘 판 둘**: 할 일이 있으면 「지금 할 일」 칸과 상태 판이 모두 같은 하늘 그라데이션 판이다. 22절이 상태 판을 하늘로 정했고 둘을 구분하는 것은 위치와 안쪽 흰 입력 상자뿐이다 — 정할 것 4. 시안에는 지금 그대로 그렸다.
4. **탭 모양**(밑줄 → 고른 탭 면): 5·7파트 칩 · 탭과 같은 규칙으로 맞췄다. 공용 `.tabs--line`(`base.css`)이라 사이드바의 다른 화면 탭도 같이 바뀐다 — 정할 것 2.
5. **선 버튼**: 이 다섯 화면의 선 버튼 테두리는 21절 범위 규칙(`base.css` `:is(.v34, .lrow, .feat) .btn--line`)이라 이 범위 안에서만 바꾸면 된다. 공용 `.btn--line` 은 건드리지 않는다.
6. **시안의 한계**: 그림(고양이 · 선물 상자)은 코드의 같은 그림 파일을 복사해 썼다. 크리에이터 얼굴 사진은 고양이로 대신했다. 사이드바는 이 파트 범위 밖이라 단순화해 그렸고 접힘(64) 상태는 그리지 않았다.

## 정할 것 — 본체가 기준으로 정한 것과 묻는 것 (11-01)
시안 담당이 올린 여섯 가운데 기존 기준으로 답이 나오는 넷은 묻지 않고 정했다(사용자 지시 「분간해서 작업」).
- **물음 — 시안 승인에 포함**: 1. 거절 · 기한 지남의 「이 선물은 발송하지 마세요」를 흰 카드 + 「!」 원으로 묶어 선물 정보 옆에 나란히(빈 반이 사라지고 중요한 안내가 카드가 된다, 휴대폰은 위아래). 33절 한 문장이 바뀐다. 배치가 바뀌는 것이라 시안 승인으로 받는다.
- **정함 — 2. 제목 32 · 탭 모양**: 로그인 후 사이드바 화면 전체(`.page-head` · `.tabs--line`). 같은 역할은 한 모양(기본 원칙)이고 구현도 한 곳이다. 다른 파트 화면 제목 · 탭도 같이 바뀌며, 그 파트 정돈 때 다시 본다. 상태 뱃지 점 + 글자는 이 다섯 화면까지(팬 홈은 5파트에서 이미 이 모양).
- **정함 — 3. 팬 홈 `.stt` 뱃지 테두리**: 뺀다. 37절 4단계 뱃지와 같은 이유(누르지 않는 표시에 선을 두르면 버튼처럼 보인다).
- **정함 — 5. 상세 1040 · 목록 880**: 유지(22절 승인, 2:1 두 단은 880 에 좁다). 바꾸지 않는 것이라 묻지 않는다.
- **정함 — 6. 2:1 두 단 아래 빈 공간**: 유지(상자가 여럿이거나 「찾기」를 열면 채워진다).
- **미룸 — 4. 할 일이 있을 때 상세 상태 판을 흰 카드로 낮추기**: 상태마다 판 모양이 달라지는 방향 문제라 시안을 한 장 더 그려야 한다. 이번에 넣지 않고 BACKLOG.
