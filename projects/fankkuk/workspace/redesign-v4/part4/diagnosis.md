## 이 여덟 화면의 공통 원인
1. **정렬**: 4 + 8 묶음의 구간 이름(20/800)이 첫 줄 글자보다 위에 떠 있다 — 「보안」 y163 대 「비밀번호」 y181, 「받을 주소」 392 대 409(17~18 차), 「소개」 620 대 「닉네임」 633(13 차). 한 화면에서 폭이 둘인 곳이 있다(상세 설정).
2. **같은 역할 두 모양**: 저장 줄 보조 버튼(팬 계정 「되돌리기」 글자 버튼 / 상세 설정 「되돌리기」 · 프로필 「취소」 선 버튼), 「팬마크 업로드」(회색 채움) 대 「삭제」(선), 스위치(감사 답장 48×28 흰 손잡이 / 계정 52×32 짙은 손잡이), 상태(승인 서명 「연결됨」 알약 / 받는 주소 「등록됨」 글자).
3. **경계 3:1 미달**: 선 버튼 `--gray-200`(1.2:1) · 팔로우 「선물 보내기」 `--gray-400`(2.5:1) · 옵션 칩 · 라디오 칸 · 태그 칩 · 접힌 칸 · 입력 판이 `--line-on-white`(1.3:1) 한 줄뿐.
4. 판 안쪽 24 인데 같은 화면의 카드(`.card`)는 32. 오류 · 완료 상자에 색 말고 표시가 없다(37절 오류 상자는 「!」 원).

## 1. 계정 설정(팬) `/me`
지금과 어긋나는 곳
- 「보안」「받을 주소」 이름이 첫 줄보다 17~18 위(2-9, 2-10)
- **이메일 칸 — 사용자 지적(11-02)**: 가입은 「앞부분 @ 도메인 고르기」(목록 여섯 + 직접 입력, `signup-page.tsx` · `signup.module.css .email`)인데 여기는 전체 주소 한 칸 — 같은 값을 넣는 칸이 화면마다 다르다(4-1). 가입과 같은 모양(묶음 416 안에 칸 · 8 · @ · 8 · 칸(각 약 193), 직접 입력은 아래 416 한 칸, 휴대폰은 1fr)으로 바꿨다. 기존 주소는 `splitEmail` 대로 채움: example.com 은 「직접 입력」 + example.com(기본), gmail.com 은 고르기에서 선택(상태 하나 추가). 크리에이터 계정 설정에는 이메일 칸이 없어 그대로.
- 「되돌리기」만 테두리 없는 글자 버튼, 다른 화면 같은 자리는 선 버튼(4-1)
- 선 버튼 테두리 1.2:1(8-12, 37·40절). 결과 상자 색만(37절)
- **「저장」 버튼**: 비활성이 **아니다** — 사이트 채움 버튼(`--primary` #89CFF0 + 짙은 글자 8.8:1)이다. 비활성은 `aria-disabled`(저장 중)일 때만 회색(`--gray-100` + `--gray-600`)이고, 시안 「저장 중」 상태에 그렸다. 하늘 채움이 흰 바탕에서 옅어 보이는 것은 사이트 공통 채움 색이라 이 파트에서 바꾸지 않았다.

바꾼 것: 이름 글줄 가운데를 첫 줄 가운데에 맞춤(한 줄 줄 18 · 두 줄 줄 5), 「되돌리기」 선 버튼(`#6B7280` 1px 안쪽 테두리, 높이 48 — 저장과 같음), 선 버튼 짙은 선 `#6B7280`, 오류 · 완료 상자 앞에 「!」 · 「✓」 원.
바뀌지 않는 것: 이메일은 저장 버튼으로 함께 저장하는 단위와 확인 메일 흐름 · 안내 문장, 보안 → 받을 주소 → 개인정보 → 알림 → 저장 줄 → 회원 탈퇴 순서, 받을 주소 등록 전/후 문장, 확인 메일 대기 문장, 끌 수 없는 알림 늘 보임(27절).

## 승인 기준과 부딪혀 판단한 곳
1. **27절 틀 폭(팔로우 960 · 상세 설정 1200 + 「주소와 설정」 880) 대 한 화면 정렬선 하나(2-9)**: 팔로우는 880 으로, 상세 설정은 한 화면 안 폭을 하나로 맞췄다. 27절 문장을 바꾸는 제안이다(정할 것 1 · 2).
2. **27절 「점선 대신 낮은 대비 1px 테두리(`--line-on-white`)」 대 경계 대비(4-7)**: 구분선은 그대로 두고, 판 · 접힌 칸 · 카드는 40절의 흰 카드(`--hair` + `--card-shadow`)로 올렸다. 줄 사이 구분선은 장식이라 그대로.
3. **21절 「한 화면에 채움 하나」 대 상세 설정 받기 설정의 저장 버튼 셋**: 판마다 따로 저장하는 폼이라 유지했다. 하나로 합치면 저장 단위가 바뀌어 동작 변경이다.
4. **27절 팔로우 0명 「지금 그림 · 문구 그대로」 대 40절 빈 상태 흰 카드**: 그림 · 문구는 그대로, 상자만 흰 카드로.

## 정할 것
- **정할 것 1 — 팔로우한 크리에이터 틀 폭**: ① 880 으로(추천 — 판단: 같은 사이드바 팬 설정 화면 세 개가 모두 880 이라 제목 시작선이 같아진다. 목록이 576, 숫자 판이 288 로 좁아지지만 이름 · 칩 · 버튼이 한 줄에 들어간다) ② 지금 960 유지(27절 그대로, 화면 오갈 때 제목이 40 움직임).
