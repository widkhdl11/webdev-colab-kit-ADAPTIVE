# 세 역할 홈 — 비교 시안 요청

## 사용자 요청

로그인 전·팬 로그인 후·크리에이터 로그인 후 화면을 역할에 맞게 바꾸면서 최대한 비슷한 느낌으로 만들고 싶다. 로그인 전은 상단바, 로그인 후는 사이드바를 사용한다.

사용자 「응 시안 만들어줘」에 따라 아래 방향을 정적 비교 시안으로 만든다. 실제 화면 반영에 대한 승인은 아직 받지 않았다.

## 시안의 공통 구성

1. 비눗방울 배경 히어로: 같은 제목 단계·간격, 역할에 따라 검색 또는 내 프로필.
2. 그림 바로가기 네 개: 같은 모양, 역할별 이름·건수.
3. 같은 소개 배너: 원본 비율, 버튼 없는 이미지.
4. 역할별 본문: 방문자는 이용 안내·새 크리에이터, 팬은 진행 중 선물·팔로우, 크리에이터는 기존 업무 요약·최근 열람 기록.
5. 같은 모양 공지.

본문 최대 폭 880, 기존 하늘색·고양이·이미지·글꼴·반경 유지. 메뉴가 차지하는 폭은 본문 바깥에서 처리한다.

## 확인할 것

- 구역 순서와 모양을 맞췄을 때 세 화면이 같은 서비스로 보이는가.
- 크리에이터의 프로필·바로가기를 공통 틀에 넣어도 필요한 내용을 찾기 쉬운가.
- 화면 폭이 좁아져도 글자·그림·버튼이 겹치거나 잘리지 않는가.

범위는 정적 시안 세 화면과 비교 도구다. 로그인·DB·실제 메뉴 동작은 연결하지 않는다.
