# 로그인 전 히어로 배경

- 사용자 첨부 PNG를 그대로 `public/images/home/hero-bubbles.png`에 저장하여 로그인 전 히어로 배경에 적용했다.
- 자동 결정: 배경은 원본 비율로 영역을 채운다. 모바일은 오른쪽을 기준으로 배치해 비눗방울 장식을 남긴다. 기존 콘텐츠와 로그인 후 화면은 그대로다.
- 이미지·위치 조정만으로 별도 리뷰어·새 테스트는 생략했다. 기존 파일 구조와 CSS만 사용하여 새 라이브러리/API는 없다.
- 검증: `node gates/run-gates.mjs --quick` 1558개 파일 통과. Playwright 비로그인 `/` 1440·390px 이미지 로드·가로 넘침 0, PC/모바일 화면 캡처 확인.
