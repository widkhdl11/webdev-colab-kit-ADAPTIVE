# 바로가기 보조 문구 간격

- 사용자 「1건, 0건 이런 텍스트가 같이 너무 위로 올라가져있는거 같은데」.
- 실제 팬 홈에서 제목과 보조 문구 사이 간격 0px, 보조 문구 위 여백 -8px 확인. 이전 카드 규칙이 현재 공통 카드의 8px 간격을 취소하고 있었다.
- 보조 문구의 음수 여백을 0으로 맞춰 제목 아래 8px 간격을 둔다. 가로 중앙 정렬과 그림·제목·카드 배치는 유지한다.
- 기존 구성 안의 여백 수정이므로 새 시안·스펙·도메인 리뷰·테스트 감사는 생략한다. UI 리뷰와 프로젝트 검사 요구에 따른 보안 영향 확인을 받는다.
