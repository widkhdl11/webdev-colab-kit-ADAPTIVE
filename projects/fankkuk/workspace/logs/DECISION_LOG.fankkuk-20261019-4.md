# 로그인 후 소개 배너 추가

- 사용자 요청: 로그인 후 슬라이드 배너 부분에도 같은 이미지를 추가.
- 자동 결정: 팬 홈·크리에이터 홈·로그인 후 크리에이터 찾기에 소개 이미지를 첫 장으로 넣고 운영자 배너는 순서를 유지한다. 고정 소개는 운영자 광고 목록과 별개로 표시하며 DB·인증·기간·광고 표시 규칙은 변경하지 않는다.
- 자동 결정: 원본 비율 전체 이미지, 버튼 없음. 기존 슬라이드의 자동 넘김·멈춤·키보드 처리를 재사용한다.
- 표시 전용 `imageOnly` 옵션은 DB에 저장하지 않는다. 광고·관리자 미리보기는 기존 표시를 사용하여 광고 표식을 숨기지 않는다.
- Context7은 제공되지 않아 설치된 Next.js의 서버·클라이언트 구성 문서를 확인했다.

## 검증

- `npm run typecheck`: 통과.
- `npx vitest run tests/banners-ui.test.tsx tests/follow-row-scroll-ui.test.tsx src/widgets/home/ui/home-page.test.ts`: 3파일 45개 통과. 소개→기존 광고 전환과 광고 표시 유지, 배너 없음·읽기 실패 시 소개 한 장을 추가 검증했다.
- `node gates/run-gates.mjs --quick`: 1558개 파일 통과.
- ui-reviewer: 확정 지적 없음. 기존 비활성 장의 inert·aria-hidden, 광고 표시, 이미지 대체 텍스트 유지 확인. 인증·도메인 상태는 변경하지 않아 보안·코드 리뷰 생략, 불변식 테스트 신설이 없어 test-auditor 생략.
- Playwright 로컬 팬 계정 `/home`: 소개+기존 2장=3장, 1440·768·390px 가로 넘침 0·이미지 로드 성공. 모바일 점으로 기존 광고 이동, PC 이전 화살표로 소개 복귀 확인. 모바일은 기존대로 화살표가 숨겨져 점으로 조작한다.
- 로그인 후 `/creators` 소개 포함 3장 확인. 크리에이터 홈은 같은 조합 함수를 연결했으며 별도 계정 실측은 하지 않았다.
- 배포하지 않았다. 이전 로그인 전 이미지 변경도 작업 트리에 유지했다.
