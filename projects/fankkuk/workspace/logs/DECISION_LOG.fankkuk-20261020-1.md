# 세 역할 홈 비교 시안

- 사용자 요청: 로그인 전·팬·크리에이터 홈을 최대한 비슷하게 만들고 싶다. 제안한 공통 구성에 대해 「응 시안 만들어줘」.
- 사용자 지정 범위 세 화면으로 상담을 압축하고 design-drafter에 정적 시안을 위임했다. 실제 서비스 코드는 수정하지 않았다.
- 자동 결정: 본문 최대 880, 기존 사이드바 240, 기존 폰트와 이미지를 재사용. 히어로 → 바로가기 네 개 → 소개 배너 → 역할별 본문 → 공지 순서로 비교한다.
- 자동 결정: PC 1440·모바일 390 비교 전환과 개별 크게 보기를 제공. 서비스 보안 헤더가 일반 iframe을 막아 정적 HTML을 읽어 srcdoc로 표시했다. 서비스 설정은 변경하지 않았다.
- 수정: 각 상자 영역에 clipPath를 넣어 이웃 상자 조각을 제거했다. 사용자가 이전에 거절한 두 번째·세 번째 배너는 시안에서도 제외했다. 최근 열람 기록은 크리에이터 본인의 배송 정보 열람으로 표시했다.
- 검사: Playwright로 세 역할 × 1440·1024·390px 확인. 가로 넘침 0, 깨진 이미지 0, 일반 글자 계산 대비 최저 5.64:1.
- 배경 이미지 위 글자는 원본 픽셀을 3px 간격으로 표본 측정했다. 모바일 크리에이터 머리말 4.35:1을 발견해 공통 머리말을 짙게 바꿨고, 같은 위치 8.45:1·해당 히어로 최소 8.06:1로 개선했다.
- 비교 화면 PC/모바일 전환과 세 개 크게 보기 링크, srcdoc 렌더 확인. 스크린샷은 `docs/design/mockups/site/v31-role-home/comparison-desktop.png`·`comparison-mobile.png`.
- 보류: 시각 방향은 사용자 확인 대기. `report-decision.mjs --ask`는 열린 d103 카드 때문에 거부돼 기존 기록을 보존하고 PENDING에 남겼다. 새로운 승인이나 실제 구현을 진행하지 않았다.
- 정적 시안에 API·도메인 로직·DB 변경이 없어 코드·보안 리뷰와 기능 테스트는 생략했다.
