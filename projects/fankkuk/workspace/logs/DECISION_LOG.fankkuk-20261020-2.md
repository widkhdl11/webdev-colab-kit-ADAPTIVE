# 세 역할 홈 공통 구성 구현

- 사용자 「좋다 그렇게 하자」로 비교 시안 승인. 승인된 공통 구성과 역할별 내용을 실제 홈에 적용한다.
- 시각 방향은 사용자 결정, 공통 부품 분리·파일 배치·기존 데이터의 표시 조합은 자동 결정이다.
- 기존 상단바/사이드바·세션·DB 판정과 쓰기 동작은 유지한다. 크리에이터 홈에 이미 읽는 처리할 일과 선물 현황을 표시하되 업무 상태를 새로 만들지 않는다. 공개 페이지 링크는 기존 공개 조회로 실제 공개 여부를 확인한다.
- 이전 d103이 열려 있어 이번 카드가 생성되지 않았으므로 답변 도구로 다른 결정을 닫지 않는다. 사용자의 실제 승인 문구를 기준으로 기록했다.


## 반영과 검증

- 세 역할이 같은 홈 틀을 사용한다. 히어로, 바로가기 네 개, 소개·광고 배너의 순서는 공통이고 아래 내용만 역할에 맞춘다.
- 크리에이터의 처리할 일·진행 단계·조회 실패는 기존 데이터와 단계 판정을 그대로 표시한다. 공개 페이지 링크는 핸들 및 기존 식별자 주소 모두 실제 공개 확인 후 표시한다.
