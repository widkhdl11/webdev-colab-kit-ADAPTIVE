## 스펙 승인 — 휴대폰 비밀번호 찾기 · 가입 번호 암호화 · 운영자 번호 보기

사용자 지시는 그대로 스펙에 옮겼다(session-login INV-L10·L11, signup INV-U18, admin-console INV-K8 예외·K14, 화면 명세 password-forgot.md).
아래는 지시에 없어서 스펙이 채운 세부다. 다섯 가지 모두 추천대로면 「추천대로」.

1. **운영자(직원·대표) 계정은 휴대폰 비밀번호 찾기에서 뺀다.** 같은 응답만 돌려주고 인증번호를 보내지 않는다.
   이유: 운영자 계정은 모든 주문을 보는 계정이라, 문자 하나(번호 이동·유심 탈취)로 가져가는 길을 열지 않는다. 운영자 비밀번호는 대표가 Supabase 화면에서 바꾼다. 업계 표준(관리자 계정은 셀프 재설정 제외).
2. **인증번호를 맞힌 뒤 새 비밀번호를 저장할 수 있는 시간은 10분, 한 번.** 가입 때 「확인된 지 10분 안·한 번만」과 같다.
3. **가린 번호를 보일 자리.** 운영자 콘솔에는 회원 목록이 없다. 크리에이터 화면은 채널 확인 대기·재확인·유예 세 표다.
   - 추천: 그 세 표에 「휴대폰」 칸(010-****-1234)과 대표에게만 「보기」를 넣는다. 채널 확인 때 연락할 일이 있는 화면이다.
   - 다른 안: 회원(팬·크리에이터) 목록 화면을 새로 만든다 — 새 화면이라 화면 명세·시안부터 다시 한다.
4. **비밀번호 찾기는 한 화면 안 세 단계**(번호 → 인증번호 → 새 비밀번호). 메일 링크가 없어지므로 새 비밀번호 화면(`/password/reset`)은 없앤다. 인증번호 칸은 가입 3단계와 같은 모양·문구.
5. **이메일 재설정에 쓰던 DB 표·함수는 지운다**(마이그레이션). 남겨 두면 쓰지 않는 길이 열린 채 남는다.
