# 팬꾹 소개 페이지 시안 — 2026-11-01

- 사용자: 「시안 4 프롬프트로 팬꾹 소개 페이지도 만들어줘 볼래?」. 시안 4 = 두 디자인 프롬프트 합침 + 충돌 답(기록: `home-landing-20261031.md` 「네 번째 시안(D)」). 서비스 코드는 바꾸지 않았다.
- 산출물: `docs/design/mockups/about-20261101/index.html`. 미리보기 http://127.0.0.1:18547/docs/design/mockups/about-20261101/
- 내용: 배포된 소개(`src/widgets/about/ui/about-page.tsx`, 10-24 다듬은 문구가 정본) + 10-31 「1~6 기능은 소개 페이지로」. 문구는 배포본 그대로 옮기고, 시안 A의 03~06 문구는 사실 문장을 「~습니다」로 바꿨다.
- 순서(관심 → 이해 → 신뢰 → 행동): 첫 화면 → 왜 만들었나(680 한 기둥) → 01 송장 출력에만 사용하는 주소(하늘 띠, 잠김 → 열림 장면 + 다섯 단계) → 02 팬에게 보내는 선물(가로 흐름 세 장면) → 03 검수·04 배송 현황·05 함께한 시간·06 테마 색(제목 24로 한 단계 낮게, 엇갈린 카드) → 팬꾹이 지키는 기준 + 열람 기록 예시(행동 요청 전) → 끝 행동 요청.
- 사실과 다를 수 있어 확인 필요:
  - 02: 시안 A의 합포장(큰 상자에 모아 보내면 팬꾹이 나눠 보냄)은 PRODUCT에 「나중에 다시 설계, 그동안은 지금 방식」이라 넣지 않았다. 지금 역조공 방식(받을 팬 고르기 → 팬이 받기/받지 않기 → 팬꾹이 겉면·보낼 수 없는 물품 확인 후 배송)으로 그렸다. 역조공이 운영에서 열려 있는지는 확인하지 않았다(PRODUCT 10-09 「남은 것: 외부 연결」).
  - 05 「팬 본인만 볼 수 있습니다」는 PRODUCT 함께한 시간 줄(팬 본인만 보는 기록)을 근거로 넣었다.
  - 06 이름은 용어집대로 「테마 색」(퍼스널 컬러 아님).
  - 03 검수 1번 설명은 배포본 문장을 줄였다(「크리에이터에게 보낼 때·경찰에 넘길 때」 생략). 실제 반영 때 원문으로 되돌릴지 정해야 한다.
