# 메인 소개 섹션 시안

- 요청: 사용자가 제공한 여섯 매력을 다듬어 메인에 넣을 소개 섹션 시안 한 판 제작.
- 범위: 별도 정적 시안과 화면 확인. 서비스 코드 변경·배포는 요청 범위 밖이다.
- 기준: 기존 하늘색·흰색·고양이 이미지·본문 폭 880px을 유지한다. 여섯 항목을 같은 카드로 나열하지 않고 기능별 설명과 그림을 묶는다.
- 위치 제안: 로그인 전 메인의 소개 배너 다음 소개 영역. 기존 이용 순서와의 최종 통합은 시안 확인 후 정한다.
- 카피 판단: 주소는 팬에게 비공개이며 암호화 저장 후 승인·검수를 마친 송장 출력 때만 확인한다. 근거는 보안 안내와 공통 문구다. 인증한 팬에게 주소가 공개되는 것으로 쓰지 않는다.
- 검수: 팬 선물의 블루투스·RF·금속 탐지기 검사와 반응 시 개봉을 설명한다. 모든 위험을 찾거나 안전을 완벽히 보장한다고 쓰지 않는다.
- 역조공·배송: 근거 없는 가격 비교와 실시간 추적 대신 여러 팬에게 보내기·받는 팬별 진행 확인·지금 할 일을 설명한다.
- 기록·프로필: 선물·감사 답장의 기록, 크리에이터의 팬덤 이름·팬마크·테마 색을 설명한다. 팬에게 동일한 꾸미기가 제공된다고 쓰지 않는다.
- 표면: 정적 홍보 문구·시각 제안만. 인증·암호화·결제 구현에는 손대지 않는다. 따라서 기능 리뷰와 보안 리뷰는 실행하지 않는다.
- 참고: Context7 도구와 GLOSSARY.md는 현재 환경에서 찾지 못했다. 외부 라이브러리 없이 HTML·CSS로 만들고 프로젝트 문구 용어집을 사용한다.
- 진행 기록: 다른 대화의 운영 준비 결정 카드가 열려 있어 덮어쓰거나 대신 답하지 않는다. 이 시안의 방향 확인은 별도로 기록한다.

## 세 번째 시안 — 역조공 합포장을 대표 장점으로

- 시안 수정: 역조공을 첫 본문으로 올려 넓은 하늘색 영역·큰 제목·합포장 도식으로 강조한다. 기존 작은 역조공 설명은 중복하지 않는다. 핵심은 비용 절감과 한 번 발송이며 가격·할인율은 새로 정하지 않는다.
- 문서 대조: PRODUCT.md의 역조공 항목은 합포장 중계와 별도 요금·방문수거를 재설계 대기로 기록하고 있다. 사용자에게 차이를 보고했다. 이번 지시는 소개 시안의 강조 요구로 반영하며, 제공 상태·요금 확정이나 기능 구현 승인으로 확대하지 않는다. 시안 끝에 공개 전 문구 대조 필요를 표시한다.
- 우선순위 정정: 사용자 「메인 장점은 승인 시스템으로 인한 주소 노출 보안 강화, 두번째가 합포장 역조공이다」. 위의 역조공 첫 배치 제안은 폐기한다. 첫 강조 영역은 승인 기반 주소 보호, 두 번째는 합포장 역조공, 나머지 네 기능은 뒤에 배치한다.

## 다섯 번째 시안 — 주소 보호를 네 장면으로

- 사용자 피드백: 노란 「카카오톡 인증으로 선물마다 승인」이 촌스럽고, 설명을 바로 이해하기 어렵다. 암호화된 주소·팬의 선물 요청·승인·그때만 나타나는 주소를 그림으로 보여 달라는 요청.

- 마지막 장면은 「승인·검수 후 송장 출력 시」라고 표시해 승인 즉시 주소가 공개되는 것으로 오해하지 않게 한다. 팬에게 비공개라는 안내는 한 줄로 유지한다.
- 첫 번째 주소 보호, 두 번째 합포장 역조공, 상단 1.·2.·3. 순서는 유지한다. 실제 서비스 기능과 정책은 변경하지 않는다.

## 일곱 번째 시안 — 직선 화살표와 기능별 구분
