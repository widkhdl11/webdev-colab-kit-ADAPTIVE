# 스펙 고침안 — 2026-10-23 카드 d120 ①(역조공·반송 라벨을 확정 뒤에도 다시 출력)

사용자 결정(카드 d120 「추천대로」 = ①): 역조공·반송 상자도 크리에이터 상자처럼, 확정 뒤 택배 기사가 가져가기 전까지 남은 횟수 안에서 송장을 다시 출력한다.
그러려면 상자에 복사해 둔 팬(보낸 사람) 주소를 확정 순간이 아니라 **집하 확인 때** 지운다. 택배사 연결 전에는 집하 확인이 없으므로 **확정 + 72시간**에 자동 처리가 지운다.

**스펙 파일은 아직 고치지 않았다.** 아래 문장을 승인받으면 각 스펙에 옮기고 시나리오·이력 줄을 단다. 세 스펙 모두 surfaces 는 그대로다.

## 바뀌는 것 한눈에

| 주소 | 다시 출력 (지금 → 바뀐 뒤) | 사본 지우는 때 (지금 → 바뀐 뒤) |
|---|---|---|
| 크리에이터 배송지(팬 선물) | 출고 확정 뒤 집하 전까지 → **그대로** | 사본 없음(등록 주소) → 그대로 |
| 역조공 주소 사본 | 출고 확정 전까지 → **출고 확정 뒤 집하 전(연결 전에는 확정 + 72시간)까지** | 출고 확정 순간 → **집하 확인 때 · 연결 전에는 출고 확정 + 72시간** |
| 반송 주소 사본 | 반송 확정 전까지 → **반송 확정 뒤 집하 전(연결 전에는 확정 + 72시간)까지** | 반송 확정 순간 → **집하 확인 때 · 연결 전에는 반송 확정 + 72시간** |

받지 않음 · 취소 · 처분 · 경찰 인계는 **그대로 그 순간** 지운다(상자가 나가지 않으므로 다시 출력할 일이 없다).
횟수(상자당 첫 출력 포함 3번)와 「대표 계정만」 · 「열 때마다 기록」은 그대로다.

## 1. reverse-gift.md

- INV-R7 (c) 고침: 「몫이 검수 완료 상태이고 아직 출고 확정 전이며 …」 →
  「몫이 검수 완료 상태이거나, 출고 확정 뒤 아직 사본이 남아 있으며(INV-R9 — 집하 확인 전·출고 확정 + 72시간 전), 받지 않음·기한 지남·반송·취소가 아니다」.
  그 아래 「출고가 확정되면 더 열리지 않는다」 → 「사본이 지워지면 더 열리지 않는다. 출고 확정 뒤의 출력은 재출력이고 처음 송장번호를 그대로 쓴다(address-protection INV-P5 와 같다)」.
- INV-R9 고침: 「다음 중 하나가 되는 순간 지워진다 — 출고 확정, 받지 않음, 반송, 취소」 →
  「받지 않음·반송·취소가 되는 순간, 그리고 출고된 몫은 택배사 집하 확인 때 지워진다. 택배사 연결 전에는 집하 확인이 없으므로 출고 확정 + 72시간에 자동 처리(office-workflow INV-W11)가 지운다(2026-10-23 카드 d120 — 기사가 오기 전에 라벨이 망가졌을 때 다시 출력하려고)」.
  위반 시 줄에 덧붙임: 「사본이 72시간 넘게 남으면 그만큼 키가 털렸을 때 열리는 주소가 늘어난다. 너무 일찍 지우면 기사가 오기 전에 망가진 라벨을 다시 뽑을 수 없다.」
- 시나리오 새로: S9b (INV-R9) Given 출고 확정된 몫 / When 71시간 뒤 대표가 재출력 / Then 열림, 「재출력」 줄, 송장번호 같음. When 72시간 지남(자동 처리) / Then 사본 지움, 지운 줄. 그 뒤 재출력 / Then 거부.

## 2. address-protection.md

- INV-P18 고침: 「반송 송장은 이 복사본으로만 출력하고 … (a) 상자가 반송 대기이고 그 상자에 복사본이 있다」 →
  「(a) 상자가 반송 대기·반송 송장 출력됨이거나, 반송 확정 뒤 아직 복사본이 남아 있다」.
  「복사본은 반송 확정·처분 때 같은 처리에서 지운다」 → 「복사본은 처분 때 그 처리에서, 반송된 상자는 택배사 집하 확인 때 지운다. 택배사 연결 전에는 반송 확정 + 72시간에 자동 처리가 지운다(2026-10-23 카드 d120)」.
- INV-P5 문단에 한 줄: 「역조공 몫(reverse-gift INV-R7·R9)과 반송 상자(INV-P18)도 같은 규칙이다 — 확정 뒤에도 사본이 남아 있는 동안(집하 전, 연결 전에는 확정 + 72시간) 남은 횟수 안에서 다시 출력한다.」
- 시나리오 새로: S18d (INV-P18) Given 반송 확정된 상자 / When 대표가 재출력 / Then 열림. When 반송 확정 + 72시간 / Then 복사본 지움 · 재출력 거부.

## 3. office-workflow.md

- INV-W11(자동 처리) 목록에 한 줄: 「출고·반송 확정 + 72시간이 지난 역조공 몫·반송 상자의 주소 사본 지우기(reverse-gift INV-R9 · address-protection INV-P18) — 상자마다 한 번, 같은 처리에서 지운 기록」.
- 사무실 출고 화면: 「송장 다시 출력」 단추를 팬 선물 상자뿐 아니라 사본이 남은 역조공 몫·반송 상자에도 보인다(지금 `outbound-workbench.tsx:570` 은 팬 선물만).
