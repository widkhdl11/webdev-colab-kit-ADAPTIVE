## 구성 판단

- 칸 순서는 승인된 design-rules 16절을 지켰다: 첫 화면(검색) → 소개 배너 → 바로가기 넷 → 소개 → 새 크리에이터 → 약속 → 요금 → 공지.
- ③ 소개 칸을 home-benefits 시안의 여섯 기능으로 바꿨다. 우선순위는 사용자 2026-10-29 지시 그대로(1 승인 기반 주소 보호, 2 팬들에게 선물 보내기, 나머지 넷은 한 단계 낮게).
- 구역마다 구성을 다르게 했다: 01 = 큰 색면 안 설명 + 네 장면 사각 흐름(직선 화살표), 02 = 화면 끝까지 칠한 띠 + 세 장면 가로 흐름, 03 = 큰 그림과 장비 이름 묶음, 04 = 넓은 화면 예시, 05 = 카드 없이 선물 → 답장 장면, 06 = 색 선택이 미리보기를 바꿈(체크 + 테두리).
- 첫 화면 그림은 「팬은 팬꾹 주소로 보내고 크리에이터 주소는 보이지 않는다」를 보여 준다(바로가기의 기존 문구 「팬꾹 주소로 먼저 보내요」와 같은 사실).
- 배너는 승인 기준(가운데 한 장 56% + 양옆 흐리게, 아래 넘김 단추)대로 줄였다. 처음 안은 폭 전체를 써서 첫 화면보다 커 보였다.
- ⑤ 약속은 01과 겹치는 주소 잠금·검수 카드를 빼고, 01에 없는 세 가지(한 건씩 승인·열람 기록 공개·거절 이유 비공개)와 열람 기록 화면 예시, 가입 버튼만 남겼다.
- 04 제목은 320px에서 세 줄이 돼 「배송 현황과 / 지금 할 일」로 줄였다.

## 5차 수정 — 엇갈린 카드 그리드(staggered grid) 규칙으로

- 사용자: 「대충 맞았는데 이번엔 간격이 문제야. 이런 배치가 있어. 잘 찾아보고 그것처럼 해줘」. 이 배치의 이름은 엇갈린 카드 그리드(staggered grid): 두 열 중 둘째 열을 아래로 내려 카드가 계단처럼 엇갈린다.
- 표준 규칙 셋: ① 간격 하나(가로 = 세로) ② 카드 높이 같음 → 계단 높이 일정 ③ 둘째 열은 반 칸(카드 높이 + 간격의 절반) 아래. 좁은 화면에서는 엇갈림을 없애고 한 줄. 4차는 간격이 가로 32·세로 24로 달랐고 카드 높이가 제각각이라 계단이 324·288·205px로 들쭉날쭉했다.
- 구현: 같은 높이의 줄 칸 다섯 개에 카드마다 두 칸씩 걸친다. 카드 높이 = 2칸 + 간격, 오른쪽 열이 내려가는 정도 = 1칸 + 간격 = 정확히 반 칸. CSS만으로 되고 4차의 계산 스크립트는 지웠다. 05도 카드로 바꿨다. 남는 높이는 설명과 그림 사이로 보내고, 03·05의 배경 있는 그림 칸은 그 높이를 채운다. 카드 높이를 낮추려고 05 선물 → 답장을 PC에서 가로로, 03 그림을 176px로 줄였다(카드 642 → 532px).
- 확인: 1440·1199px 카드 높이 532 넷 모두 같음, 계단 282/282/282, 간격 32/32/32. 1024px 555·293. 768·1023px 한 줄 간격 24, 320·390·767px 한 줄 간격 16(05의 예전 위 여백을 지워 맞춤). 8개 폭 가로 넘침 0, 세 줄 제목 0, 번호 겹침 0, 칸끼리 겹침 0. 캡처 `pc-features-v7.jpg`(그림 칸 채우기 전).
