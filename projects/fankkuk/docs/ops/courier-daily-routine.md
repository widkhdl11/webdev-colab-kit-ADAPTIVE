# 저녁 출고 루틴 — 송장 출력 → 다음 날 집하

택배는 로지아이 소호사업자택배(실제 운송은 CJ대한통운)로 보낸다. 로지아이는 송장 출력 API 가 없어서
송장은 로지아이 「송장출력」 페이지나 엑셀 일괄 예약으로 만든다. 근거: DECISIONS 2026-11-09 「로지아이 답 반영」.

## 언제

- **저녁**에 그날 출고할 상자를 송장 출력까지 끝낸다.
- 로지아이는 **당일 03시까지 예약한 것**을 그날 집하한다. 저녁에 예약해 두면 다음 날 기사님이 가져간다.
- 토요일도 집하한다.

## 순서

1. 운영자 화면 「출고」(팬 선물·역조공)와 「선물함 출고·반송」에서 송장 출력 대기 상자를 확인한다.
   - 팬 선물·역조공 몫은 검수 완료, 선물함 신청은 명세서 결제 완료인 상자만 나온다.
2. 송장을 만든다. 지금 사이트의 송장 출력 방식은 **수동 입력**이다.
   - 상자마다 대표 계정으로 「송장 출력」을 눌러 주소를 열고, 로지아이 예약 화면에 옮겨 적는다. 주소 화면은 닫으면 사라진다.
   - 로지아이에서 받은 운송장 번호를 그 상자에 넣는다.
   - 엑셀 반자동은 아직 없다. 로지아이 엑셀 일괄 예약 양식 파일을 받으면 만든다(아래 「엑셀 반자동이 생기면」).
3. 로지아이 송장출력 페이지에서 라벨을 인쇄해 상자에 붙인다.
4. 다음 날 집하 전에 상자마다 「출고 확정」 스캔(송장 바코드 짝 확인)을 한다.

## 알림이 나가는 때

- 팬에게 가는 **출고 알림**은 주문의 상자가 모두 **송장 출력**되는 순간 나간다(notifications INV-N3, 2026-11-09).
  출고 확정 스캔 때 다시 나가지 않는다. 그래서 저녁에 송장을 출력하면 그날 저녁에 알림이 간다.
- 선물함(크리에이터 → 팬)에는 아직 출고 알림이 없다. 화면의 배송 단계(「팬꾹에서 보냈어요」)만 송장 출력 때 바뀐다.

## 엑셀 반자동이 생기면

- 대표 계정만 「엑셀 만들기」를 쓸 수 있다. 상자마다 송장 출력 1회로 센다(상자당 3회 한도 안).
- 파일은 **한 번만** 내려받을 수 있고, 만든 뒤 10분이 지나면 없어진다. 서버에는 남지 않는다.
- 내려받은 파일은 **로지아이에 올린 직후 지운다**(휴지통 비우기까지). 이 파일에는 받는 분의 실명·주소·전화번호가 들어 있다.
  사이트는 대표 PC 의 파일을 지울 수 없다 — 이 단계는 사람이 지켜야 한다(address-protection INV-P21 ②-4).
- 받는 사람 전화 칸은 지금 실제 번호다. 로지아이는 안심번호를 주지 않는다 — 안심번호를 쓰려면 안심번호 업체를 따로 연결한 뒤 설정을 바꾼다.

## 매달 확인

- 운영자 「요금표」 화면의 **월 발송 건수**를 본다. 로지아이 A등급은 월 30건이 기준이다.
- 끝난 달 두 달 연속 30건 미만이면 같은 화면에 「택배 경로 재검토」가 뜬다. 바로 해지되지는 않지만,
  계속 미달이면 집배점 판단으로 집하가 제한·중단될 수 있다(로지아이 답). 뜨면 기본 경로(우체국 창구·로지아이 방문택배 등)를 다시 본다.
