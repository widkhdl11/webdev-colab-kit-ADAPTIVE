### 플레이풀 + 신뢰의 균형
> 🤖: 일러스트·색·말투는 귀엽게, **보안 약속 문구와 절차 설명은 또렷하고 차분하게** 두 층으로 나눈다.
> 이 서비스가 파는 것은 "안심"이라, 귀여움이 보안 약속을 가볍게 보이게 하면 안 된다.

### 메인 페이지 구성 (사용자 확인: "이대로")
1. 첫 화면: "크리에이터가 승인한 선물만 배송" + 선물 보내기 버튼
2. 이용 순서 4단계: 등록 → 승인 → 검수 → 배송
3. 안심 약속 3가지: 승인 없이는 주소를 열지 않음 · 전 건 검수 · 열람 기록 공개
4. 요금: 9,000원, 검수 포함 (서비스료 5,000원 + 배송비 실비)
5. 크리에이터용 안내와 가입 버튼
6. 하단 사업자 정보 (상호 네오코드 · 사업자등록번호 · 고객센터 — 카카오 이용기관 심사 조건)

### 문구 한계 (원본 설계)
- 써도 되는 말: "승인 없이는 저희 시스템이 주소를 열지 않습니다"
- 쓰면 안 되는 말: "절대 유출되지 않습니다"

### 다음 화면들이 물려받을 것
- 상태 화면(일곱 단계: 등록 → 승인 → 입고 → 검수 → 출고 → 배송중 → 수령)은 메인 시안이 승인된 뒤
  같은 언어로 만든다. 팬에게 운송장 번호·검수 사진은 보여 주지 않는다.
