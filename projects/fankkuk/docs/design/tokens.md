# 팬꾹 디자인 토큰 제안 (2026-10-17)

> 사용자 요청 「너무 아마추어스러워서 손봐야 할 것 같아」로 시작한 다듬기의 기준이다.
> **2026-10-17 승인**(카드 d100, 사용자 「이번 제안한걸로 바꾸자」). 시안: `mockups/site/v23-tokens/`. 예외 하나 — 랜딩 약속 구간의 「크리에이터로 가입하기」 버튼은 가운데(사용자 지시).
> 감사 범위: 위계·간격·묶음·정렬·글자 단계·폭·밀도. **색·마스코트·문구·사이드바 동작·DECISIONS.md 의 결정은 바꾸지 않는다.**
> 근거: 실제 화면 실측(42개 페이지 × 1440·390 폭, Playwright). 위반 목록은 `redesign-2026-10-17-audit.md`.
> 값의 자리: 코드는 `src/shared/ui/tokens.css` 하나다(이 프로젝트는 Tailwind 설정 파일이 아니라 CSS 변수로 토큰을 쓴다).
> 승인되면 이 문서의 값이 design-rules 00절의 글자·간격·폭 항목보다 앞선다.

## 지금 상태 (실측)

| 항목 | 지금 | 문제 |
|---|---|---|
| 글자 크기 | 11가지: 11·13·14·15·16·18·20·24·32·36·48 | 13·14·15·16 네 단계가 1px 씩 붙어 있어 눈으로 구분이 안 된다. 16px 보다 작은 글자가 3,972개로 16px(2,703개)보다 많다 |
| 간격 | 레이아웃 간격은 4의 배수가 거의 다 지켜짐(예외 1곳) | 값은 맞지만 「안쪽 간격 < 바깥 간격」 순서가 화면마다 다르다 |
| 공개 페이지 폭 | 랜딩·소개·크리에이터 찾기 1152(시작 x 144) / 약관·고객센터 계열 1200(x 120) | 페이지를 옮기면 왼쪽 시작선이 24px 움직인다 |
| 크리에이터 프로필 폭 | 머리 카드 880 / 그 아래 1152 | 한 페이지 안에서 기둥이 두 개다 |
| 긴 글 한 줄 | 약관·자주 묻는 질문 한 줄 46~69자 | 읽기 편한 한 줄은 한글 35~45자 |
| 카드 반경 | 카드 모양 상자가 16(68개)과 12(43개)로 섞임 | |
| 로그인·가입 폭 | 로그인 528 · 비밀번호 480 · 가입 768 | 기준(480·720)과 다르다 |

## 1. 간격 — 4px 기준, 10단계

| 토큰 | 값 | 쓰는 곳 (안쪽에서 바깥 순서) |
|---|---|---|
| `--space-1` | 4 | 아이콘 ↔ 붙은 글자 |
| `--space-2` | 8 | 라벨 ↔ 값, 카드 안 제목 ↔ 설명 |
| `--space-3` | 12 | 칩·뱃지 사이, 목록 줄 안쪽 위아래 |
| `--space-4` | 16 | 카드 안 묶음 사이, 휴대폰 카드 격자 간격 |
| `--space-6` | 24 | 카드 안쪽 여백, PC 카드 격자 간격, 작은 제목 → 내용 |
| `--space-8` | 32 | 구간 제목 → 내용(로그인 후), 큰 판 안쪽 여백 |
| `--space-10` | 40 | 로그인 후 본문 바깥 여백(기존 승인값) |
| `--space-12` | 48 | 로그인 후 구간 사이, 랜딩 구간 제목 → 내용 |
| `--space-16` | 64 | 휴대폰 랜딩 구간 사이 |
| `--space-24` | 96 | PC 랜딩 구간 사이 |

- **20 은 뺀다.** 지금 47곳이 쓰는데 16 이나 24 로 옮긴다. 16·20·24 가 함께 있으면 서로 구분이 안 된다.
- **묶음 규칙**: 한 묶음 안의 간격은 그 묶음과 바깥 사이 간격의 **절반 이하**로 한다. 예: 카드 안 제목↔설명 8 / 카드 사이 24 / 구간 사이 48.
- 2·6·10·14 같은 값은 테두리 두께나 아이콘 보정 말고는 쓰지 않는다.

## 2. 글자 크기 — 6단계

| 토큰 | PC | 767 이하 | 줄 높이 | 쓰는 곳 |
|---|---|---|---|---|
| `--fs-hero` | 48 | 32 | 1.2 | 랜딩 첫 화면 제목 하나 |
| `--fs-title` | 32 | 24 | 1.25 | 랜딩·소개 구간 제목, 크리에이터 이름 |
| `--fs-page` | 24 | 24 | 1.3 | 페이지 머리 제목, 프로필 아래 구간 제목 |
| `--fs-card` | 20 | 20 | 1.4 | 카드 제목, 로그인 후 구간 제목, 강조 값(숫자·상태) |
| `--fs-body` | 16 | 16 | 1.6 | 본문, 버튼, 상단 메뉴, 리드 문장 |
| `--fs-small` | 14 | 14 | 1.5 | 보조 글: 캡션·날짜·개수·라벨·뱃지·사이드바 메뉴·푸터 |

옮기는 값:

| 지금 | → | 이유 |
|---|---|---|
| 11 (사이드바 묶음 이름·숫자 뱃지) | 14 | 6단계 밖. 11은 너무 작아 읽기 어렵다 |
| 13 (캡션·태그·날짜, 2,135개) | 14 | 6단계 밖 |
| 15 (상단 메뉴·푸터 링크, 1,239개) | 상단 메뉴 16 / 푸터 14 | 15·16 은 구분이 안 된다 |
| 18 (리드·통계 값) | 리드 16 / 통계 값 20 | 18·20 이 한 화면에 같이 있으면 위계가 흐려진다 |
| 36 (팬 홈 얼굴 글자) | 32 | 6단계 밖 |

- **굵기**: 제목 800(둥근 글꼴) · 소제목·버튼 600 · 메뉴 500 · 본문 400. 지금과 같다.
- **위계 규칙**: 바로 위아래 단계는 크기를 한 단계 이상 띄운다. 같은 크기로 위계를 줄 때는 굵기와 색으로만 준다.

## 3. 폭

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--pub-max` | 1200(안쪽 글 1152, 양옆 24) | **로그인 전 모든 공개 페이지**. 약관·고객센터 계열도 1152 기둥으로 맞춘다 |
| `--prose-max` | 680 | 약관·개인정보·안내·자주 묻는 질문 본문, 페이지 머리 설명 한 줄(16px 기준 한 줄 약 42자) |
| `--col-profile` | 880 | 크리에이터 공개 프로필 전체(머리·통계·접는 칸·비슷한 크리에이터를 한 기둥에) |
| `--col-list` | 880 | 로그인 후 목록형·홈(기존 승인값) |
| `--col-form` | 720 | 로그인 후 입력·설정형, 가입(기존 승인값. 가입 768 → 720) |
| `--col-wide` | 1200 | 표·편집+미리보기(기존 승인값) |
| `--col-auth` | 480 | 로그인·비밀번호 찾기 카드(로그인 528 → 480) |
