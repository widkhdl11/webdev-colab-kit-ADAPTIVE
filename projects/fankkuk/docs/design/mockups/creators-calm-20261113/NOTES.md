## 2. 직접 꾸민 개성

- 커버 사진: 그대로 커버에, 2:1. 권장 크기(1200×600)로 올린 사진은 잘리지 않는다. 방송 배너 비율(1200×480, 2.5:1)로 올리면 지금처럼 양옆이 10%씩 잘린다.
- 테마 색: 커버 면(사진이 없을 때) · 프로필 사진 테두리 · 팬덤 뱃지에만. 버튼에는 쓰지 않는다.
- **자동 색과 직접 고른 색을 구분할 수 있다.** 테마 색은 `creators.personal_color` 칸에 크리에이터가 고를 때만 저장되고, 고르지 않으면 비어 있다(로컬 DB 확인). 파스텔은 그 칸이 비었을 때 화면이 크리에이터 ID 로 계산하던 값이라 DB 에 없다. 그래서 저장된 값을 바꿀 필요 없이 「비었으면 회색」으로만 바꾸면 된다.
