## 1. 결론 (화면 구조와 요소의 역할)

화면 종류: **관리형**(6-4) — 요약과 목록. 요약은 위가 아니라 **오른쪽 칸**에 둔다(design-rules 본문 틀 「두 단」: 칸에는 이 화면에 이미 있는 값만).

- 머리: 「승인 내역 N건」(제목 24 — 지금과 같음).
- 왼쪽 주 영역: 달마다 묶은 줄 목록. 한 줄 = 얼굴 40 | 「OO님의 선물」 + 아래 한 줄 「선물 종류 · 상자 N개 · 주문번호」 | 결과 태그 | 처리일(오른쪽 정렬) | 「승인 취소」 칸. 칸 폭이 줄마다 같다(2-6). 버튼 없는 줄에도 빈 칸을 둔다.
- 오른쪽 칸(PC): 「처리한 요청」 + 결과별 건수 넷(태그 + 숫자, 숫자 오른쪽 정렬) + 「최근 처리일」. 스크롤을 따라온다(sticky).
- 맨 아래: 「승인 기한 만료」「팬 차단」 접기(지금과 같음, 해당 건이 있을 때만).
- 확인 창 모양·문구는 지금 BottomSheet 그대로(PC 480 중앙 창, 휴대폰 아래 시트).

## 3. 근거 (요소별 원칙)

- 요약을 오른쪽 칸으로: 6-5(2) 주·보조 영역 폭이 다름(800 : 288), 6-4 관리형, 1-4 시선이 시작하는 왼쪽에 목록, 9-4 큰 「N건」 숫자 판을 빼 머리의 「N건」과 겹침 제거.
- 칸 안 건수 넷은 같은 크기·같은 모양: 6-5(3) 요약 숫자 2~3개 권장이지만 결과 종류가 넷이라 세로 줄 목록으로 둬 크기 차를 만들지 않음. 눌리는 칸이 아니므로 테두리·그림자 없이 선 하나(4-6, 14-7(2)).
- 줄 목록: 8-14 「비교·처리할 데이터 → 표나 줄 목록」. 월 제목(20)과 건수로 3줄 이상 반복을 끊음(6-5(1)). 숫자(처리일)는 오른쪽 정렬(2-18).
- 「승인 취소」 줄 오른쪽 끝: 2-21(11). 휴대폰은 맨 아래 줄 오른쪽 끝, 글자 오른쪽 끝이 태그 오른쪽 끝과 같은 선이 되도록 안쪽 여백 8만큼 당김(2-8, 주석).
- 태그: 점 + 글자 + 색(4-1·4-2). 확인 창: 2-17·2-19·2-21(6)·8-7. 빈 상태: 2-17(메시지 하나 한 줄).

## 4. 양보한 원칙

- 9-2(빈 상태에 다음 행동): 지금 문구 「처리한 요청이 없습니다.」 그대로. 행동을 더하면 새 문구라 확인 필요.
- 6-5(3) 요약 숫자 2~3개: 결과가 4종이라 넷. 세로 줄로 둬 한 줄에 칸을 모으지 않음.
- 1-2 가장 눈에 띄는 요소 하나: 숫자를 모두 같은 20으로 두고 제목 24 가 가장 큼 — 1판처럼 승인 하나를 키우지 않음(적용 규칙 8: 지금 48 판을 줄이는 쪽).

## 5. 확인 필요

- 결과별 건수를 눌러 거르는 칩으로 바꾸는 것은 새 동작이라 하지 않음(지시). 오른쪽 칸의 건수 줄은 눌리지 않는 표시.
- 「승인 기한 만료 7일」·「11월 17일까지」는 가짜 값. 이름·주문번호·선물 종류는 모두 예시.
- 위의 「큰 N건 판」을 뺀 것은 정보 삭제가 아니라 머리의 「N건」과 중복 제거 — 사용자 확인 포인트.

## 6. 적용 규칙 8 — 지금보다 큰 것

- 글자·버튼·얼굴: 모두 지금과 같거나 작음(제목 24=24, 월 제목 24→20, 요약 숫자 큰 판 48 → 20).
- 줄 높이만 56 → 72(PC): 이름 아래에 「선물 종류·상자·주문번호」를 두 번째 줄로 둬 말줄임 없이 다 보이게 함(지금은 한 줄에 이어 붙여 폭이 좁아지면 잘림).

## 7. 배치 진단 (6-5)

화면 종류: 관리형.
- (1) 같은 줄 반복 → 월 제목·건수로 묶음 구분. 줄은 데이터(8-14)라 유지.
- (2) 모든 영역 폭이 같다 → 주 800 : 칸 288 로 다르게(고침: 1판의 전체 폭 7열 표 → 오른쪽 칸 분리).
- (3) 해당 없음(큰 영역 없음). (4) 먼저 읽을 곳 = 제목 → 첫 달 목록. (5) 묶음 안 8~16 / 묶음 사이 32~48. (6) 같은 모양 3곳 이상 → 줄 목록은 한 곳, 요약 칸은 짧은 선 목록 하나뿐 → 해당 없음.

폭마다 배치(14-8): 기둥 1020 이상 = 두 단(칸 오른쪽·sticky), 1020 미만 = 한 단(요약 위: 560 이상 4칸 가로, 미만 2×2), 주 영역 600 미만(휴대폰) = 줄이 3단(이름+태그 / 메타 / 처리일+승인 취소).
