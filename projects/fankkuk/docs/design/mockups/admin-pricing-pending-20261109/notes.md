# 운영자 요금표 — 올린 요금은 30일 뒤 적용 (시안, 2026-11-09)

근거: `docs/ux/pages/admin-pricing.md` 「2026-11-09 바꿀 것」(admin-console INV-K18) · `docs/design/design-prompt.md` · 현재 구현 `src/widgets/admin-pricing`·`src/features/admin-pricing-edit`.
상태(위 막대, 주소 해시): `#pending` 적용 대기 칸 · `#saved-mix` 저장 직후(올림+내림) · `#saved-raise` 저장 직후(올림만).

- 적용 대기 칸: 입력칸에는 지금 적용 중인 값(중형 4,400)을 그대로 두고, 칸 바로 아래 시계 아이콘 + 「4,700원 · 12월 9일 (수) 오후 3:20부터」(글자+아이콘, 4-2). 선물함 서비스료 기본(700)도 같은 모양. 적용 시각 = 저장 시각(11월 9일 오후 3:20) + 30일(서버가 정함, 고르는 칸 없음).
- 저장 직후 줄: 올림+내림이 섞이면 「올린 요금은 12월 9일 (수) 오후 3:20부터 적용됩니다. 내린 요금은 바로 적용됐습니다.」, 올림만이면 앞 문장만. 내림만 있으면 기존 「저장했어요.」(시안 없음).
- 요금 바꾼 기록: 「적용 시각」 칸 추가. 저장 시각과 다를 때만 값(+「적용 대기」 뱃지), 같으면 빈 칸(화면 낭독기용 「저장 시각과 같음」).
- 바뀌지 않는 구역(요금표 구간별 · 택배 원가 경로표 · 월 발송 건수)은 그리지 않았다.
- (가정) 입력칸·버튼 높이 44(지금 구현 36, 프롬프트 8-12). 운영자 본문 14~15·사이드바 232는 업무 화면 예외(design-rules 8)를 따름. 사이드바 메뉴 칸 36은 지금 값 그대로.
- 확인 필요: 같은 칸을 다시 저장하면 기다리던 값을 대신한다는 안내를 따로 보일지 · 원래 값으로 되돌려 저장해 인상을 취소했을 때의 안내 · 기록 표에서 적용된 뒤의 「적용 대기」 뱃지가 사라지는 방식.
- 실측(폭 1440·1280·1100·1024 × 상태 3): 가로 넘침 0 · 글자 대비 미달 0 · 12 미만 글자 0 · 14 미만 글자 화면 0(사이드바 13만) · 누르는 칸 44 미만 화면 0(사이드바 메뉴 36만). 심은 위반(글자 #AAA 11px · 높이 30 버튼 · 3000px 폭)은 모두 검출됨.
