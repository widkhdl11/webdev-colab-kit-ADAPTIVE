# 팬꾹 소개 페이지 시안

2026-11-14 요청한 소개 내용을 바탕으로 만든 독립 HTML 시안이다. 메인에 넣을 소개 콘텐츠의 배치를 확인하는 용도다.

- 순서: 선물 승인과 검수 → 주소 보호 → 팬에게 보내기(선물함 신청 관리 / 모아서 배송) → 페이지 꾸미기 → 감사 기록.
- 처음 방문한 팬도 이해하도록 선물함을 설명하고, 크리에이터가 만드는 공간임을 명시했다.
- 신청과 배송 과정을 각각 그림으로 설명했다. 예시 이름·인원·메시지는 화면에 예시임을 표시했다.
- 기존 하늘색·고양이 그림·제목 글꼴을 재사용했다. 본문은 프로젝트에 있는 Pretendard Medium 파일을 사용한다.
- 문장은 의미와 장점을 살려 간결하게 다듬었다. 비용 절감은 비교 조건을 확인해야 하므로 ‘합리적인 비용’으로 표현했다. 주소 보호는 ‘피해를 줄이도록 설계’로 표현했다.
- 디자인 프롬프트 1절(중요도), 2절(정렬·묶음), 5절(작동 방식 그림), 6절(구역별 구성)을 적용했다.

## 확인

로컬 프로젝트 폴더를 정적 서버로 열고 `/docs/design/mockups/about-20261114/`에서 확인한다. 상대 경로로 기존 그림·글꼴·토큰을 불러온다.

Chrome에서 1440px·390px 폭의 화면을 렌더링했다. 가로 넘침 0, 불러오지 못한 이미지 0. PC와 모바일 전체 캡처는 `desktop.png`, `mobile.png`다.

실제 메인페이지 연결 위치와 이 배치는 사용자 확인 후 적용한다.

## 구역 구분·가독성 보완

- 스크롤 중에도 사용할 수 있는 내용 바로가기를 추가했다. 휴대폰에서는 가로로 밀어 모든 항목을 볼 수 있다.
- 흰 본문과 주소 보호·페이지 꾸미기의 색면을 구분하고, 핵심 문구에 굵기를 더했다.
- ‘팬에게 보내기’ 안의 신청 관리와 선물 배송을 각각 묶고 이름표를 붙였다. 각 과정 설명은 해당 묶음 안에서 이어진다.
- 1440px·390px에서 가로 넘침과 이미지 누락이 없음을 다시 확인했다. ‘팬에게 보내기’ 바로가기를 클릭해 해당 구역으로 이동하는 것도 확인했다.

## 배송 그림 보완

크리에이터 → 팬꾹 → 받는 팬들을 그림 위에 표시했다. 팬꾹에서는 도착한 큰 상자를 열고 작은 상자 셋을 꺼내는 모습, 마지막에는 같은 표식의 상자가 각 팬에게 따로 가는 모습을 그렸다. A·B·C는 받는 팬과 선물의 대응을 보여주는 예시다. PC·모바일 화면에서 확인했고, 배송 부분 캡처는 `delivery.png`와 `delivery-mobile.png`에 저장했다.

## 2026-11-20 배송 그림 변경

사용자 요청에 따라 두 번째 그림을 기존 팬꾹 회사 건물 그림 기반의 「큰 상자가 회사에 도착」 장면으로, 세 번째를 「큰 상자에서 팬별 작은 선물 상자를 꺼내 개별 배송」 장면으로 교체했다. 해당 제목·캡션·대체 텍스트도 그림에 맞췄다. 첫 번째와 다른 소개 구간은 그대로다.

새 파일: assets/company-arrival.png · assets/fan-dispatch.png. 내장 이미지 생성 도구로 기존 에셋을 참고해 만든 설명용 일러스트이며 촬영 사진은 아니다. 생성 프롬프트는 assets/generation-notes.md에 있다.

디자인 프롬프트 2-11(그림칸 높이 통일), 2-13(그림 설명), 5(작동 방식 그림), 14(화면 확인)를 적용했다. PC 1440·휴대폰 390 캡처에서 가로 넘침 없음, 이미지 누락 없음. 배송 구간 캡처에서는 고정 메뉴가 그림을 가리지 않도록 캡처할 때만 메뉴를 숨긴다. 실제 메뉴는 유지한다.
