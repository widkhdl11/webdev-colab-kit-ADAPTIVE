크리에이터 가입 3단계 — 카카오톡 인증 (시안)

가입은 유형 선택 → 정보 입력 → 카카오톡 연결 → 채널 확인, 네 단계입니다. 3단계 서명 한 번으로 휴대폰 확인과 승인 서명 연결이 함께 끝나고, 서명이 확인된 뒤에 계정이 만들어집니다.

아래 다섯 장은 3단계의 상태별 화면입니다. 이름·번호는 화면 예시입니다. 문구는 지금 5단계 화면 문구를 그대로 썼고, 새 문구는 ⑤의 안내 두 문장뿐입니다.
