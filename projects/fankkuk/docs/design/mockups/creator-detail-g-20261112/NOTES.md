f판(1판)은 비교용으로만 봤고 복사하지 않았다. e판까지 사용자가 확정한 요소는 모두 지켰다: 전체 폭·큰 배경 사진 / 진행 중인 선물함 타일 + 상세 창 / 받고 싶은 선물 / 받기 어려운 선물 / 나에게 온 감사 카드 / 상세 내용 여닫기(기본 닫힘, 「상세 정보 펼치기」) / 추천 크리에이터 자동 슬라이드(PC 화살표는 본문 밖 양옆·카드 높이 가운데, 멈춤 단추). 요소·문구·버튼 동작·순서는 바꾸지 않았다(적용 규칙 6).

## f판에서 되풀이하지 않은 문제
- 전체 폭 배경: `width:100vw` 대신 본문 틀 밖의 100% 폭 블록. `html{overflow-x:clip}` 없음. 넘침 검사는 세로 스크롤바가 실제로 있는 브라우저(클라이언트 폭 1425)에서 쟀다.
- PC 추천 화살표 자리 기준: 뷰포트 1200 → **1260**. 본문 1080 + 양쪽 60 = 1200에 세로 스크롤바 폭(최대 17)을 더한 여유. 1200 기준이면 스크롤바 있는 PC에서 화살표가 화면 밖으로 7 나간다.
- 사이드바: 이 화면은 로그인 전에도 열리는 공개 페이지라 상단 바 구조(f판과 같음)이고 사이드바를 그리지 않았다. 로그인한 팬이 열면 사이드바 안 칸 폭으로 줄어드는 경우는 container 쿼리로 이미 처리했다(칸 879 이하 한 열).
