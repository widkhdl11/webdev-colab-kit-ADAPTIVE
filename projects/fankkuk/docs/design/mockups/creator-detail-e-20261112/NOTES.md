상태: needs_follow / open / self / hidden / unsigned / verifying / 저장 실패 2종 — 지난 판과 같은 방식. 선물함 카드의 버튼·뱃지 규칙은 명세 그대로: 신청(신청 전·로그인 전·팔로우 전 포함) / 신청함·대기 N번이면 「신청 보기」 + 뱃지 / 본인은 「신청 관리」. 시안은 카드 하나는 신청 전(1주년 기념 선물함), 하나는 「대기 2번」(연말 선물함)으로 그렸다. 「신청함」 뱃지 모양은 「대기 2번」과 같은 값이라 따로 그리지 않았다.

### 선물함 카드 그림 영역 — 대표색을 옅게 쓰는 방법

- 새 색을 짓지 않았다. 팬덤 뱃지·사진 테두리에 쓰는 `--personal`(시안에서는 `#DCEBFF`, 파스텔 8색 중 하나)을 **흰색과 55:45로 섞는다**: `color-mix(in srgb, var(--personal) 55%, var(--white))` → `#EDF5FF` 가량.
- 이유: 배경 사진 면(`--personal` 그대로, 진함)과 같은 계열이면서 카드 몸통(흰색)과 경계가 보일 만큼 짙다. 흰색을 더 섞어(70% 이상) 옅게 하면 흰 카드와 구분이 안 되고, 덜 섞으면(35% 이하) 배경 사진 면과 같은 비중이 되어 카드 둘이 판처럼 보인다. 55%에서 선물 상자 그림의 하늘색 띠와 대비가 남는다(그림은 원본 색 그대로).
- 그림: `public/images/home/gift-box-small.png`(428×339)·`gift-box-medium.png`(487×499)를 상대 경로로 부른다. **원본이 투명 배경이 아니라 흰 바탕(RGB, 모서리 254~255)이다.** 그대로 올리면 옅은 하늘 면 위에 흰 사각형이 보여, `mix-blend-mode: multiply` 로 얹어 흰 바탕을 면 색에 녹였다(파일은 안 고쳤다). 상자 몸통의 흰 부분도 면 색으로 보이는 부작용이 있다. 투명 PNG 가 따로 생기면 그것으로 바꾸는 편이 낫다. 비율은 원본 그대로(`height: 104; width: auto`, 5-3).

## 4. 양보한 원칙

- **열 구성(6-6 「2가지까지」)**: 두 열(2:1) 아래 3열 그리드가 더해져 한 화면에 세 가지가 보인다(한 열은 휴대폰·머리). 사용자 지시 3 이라 따랐고, 3열은 공용 카드 그리드(17절)와 같은 기준이다.
- **2-22 버튼 순서**: 「팔로우 중」 왼쪽 → 「선물 보내기」 오른쪽은 2-22 를 따랐다. 지금 구현은 반대다 — **사용자 답 대기 중이라 지난 판처럼 두었다.**
- **4-6**: 선물함 카드(선택 대상 + 버튼)와 크리에이터 카드는 카드 테두리 + 그림자(누르는 행동이 든 묶음). 감사 답장·받기 어려운 선물은 면 색만.
- 공용 카드 안 칩(`cchip`)은 운영 카드처럼 흰 면 + 1px 선이 있다(카드가 누르는 칸이라 안의 표시도 같은 면이다).

## 5. 확인 필요

- 버튼 순서(위 4).
- **선물 상자 그림이 투명 배경이 아니다**(위). 로고 PNG 처럼 투명 PNG 로 바꿀지.
- 「신청함」 뱃지 모양·글자는 명세에 이름만 있다(draft). 「대기 2번」과 같은 값으로 그렸다.
- 크리에이터 카드의 「팔로우」 띠는 팔로우 안 한 크리에이터 모양만 그렸다(팔로우 중 카드는 「선물 보내기」 + 취소 아이콘 — 17절).
- 감사 답장 「더 보기」: 시안은 처음 3개 → 누르면 나머지 4개(예시 7개). 구현은 최신 20개 안에서 펼친다(gift-reply INV-G7) — 한 번에 펼칠지 단계별 펼칠지는 정하지 않았다.
- 쉬는 중(hidden) 상태는 받기 어려운 선물 상자가 숨어 보조 열이 짧다(아래 7). `sticky` 로 눈에 덜 띄게 했다.
- 로그인 후는 사이드바 안(칸 폭 기준)이라 상단 바가 없다 — 시안은 로그인 전 모양. 본문은 같은 칸 폭 기준으로 나뉜다.
- 데이터(승인 시간·요금·D-22·N명·답장·물품 목록·다른 크리에이터)는 모두 가짜.
