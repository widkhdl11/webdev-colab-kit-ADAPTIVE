선물은 4단계로 도착해요

팬은 팬꾹으로 보내고, 크리에이터는 승인만 하면 돼요.

  1. 1. 등록

    선물을 등록해요

    결제하면 팬꾹 주소가 바로 나와요. 승인 전에도 먼저 보낼 수 있어요.

  2. 2. 승인

    크리에이터가 승인해요

    크리에이터가 승인한 선물만 배송합니다.

  3. 3. 검수

    모든 선물을 검수해요

    탐지기 반응이 있으면 개봉 검수합니다.

  4. 4. 배송

    팬꾹이 대신 보내요

    승인과 검수를 모두 통과한 선물만 출고합니다.

이제 확인하고 선물을 받으세요

승인 전까지 주소는 노출되지 않습니다.

  1. 01

    주소는 잠긴 채 보관합니다

    승인된 선물의 송장을 출력할 때만 열려요.

  2. 02

    주소가 열린 기록은 모두 공개합니다

    언제, 어느 주문에서 열렸는지 크리에이터가 직접 볼 수 있어요.

  3. 03

    모든 선물을 검수합니다

    탐지기 반응이 있으면 개봉 검수합니다.

  4. 04

    승인은 한 건씩, 카카오톡으로

    한꺼번에 승인하는 버튼은 없어요. 받지 않은 이유는 팬에게 알리지 않아요.
