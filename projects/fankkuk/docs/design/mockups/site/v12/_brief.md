# v12 시안 지시서 — 「더 세련되게」 두 방향 비교 (2026-10-13)

사용자: 「너무 무난해서 좀 더 세련된 느낌으로 하고 싶어」 「레이어드부터 재구성」 「일단 전체적인 느낌을 보고 싶으니까 둘 다 시안으로」.
로컬 시안만 만든다. `projects/fankkuk/src/` 는 건드리지 않는다.

## 출발점 (반드시 먼저 읽기)
- 승인된 기준: `projects/fankkuk/docs/design/design-rules.md` 0절(v11)·1절(색)·3절(그림)·6절(말투)
- v11 시안: `projects/fankkuk/docs/design/mockups/site/v11/landing.html`, `creator.html`, 공통 CSS `v11/v11.css`, 그림은 v11 이 참조하는 경로 그대로
- 내용(문구·구간 순서·버튼)은 v11 과 같게 둔다. 바꾸는 것은 시각 표현뿐이다.

## 두 안
- **A. 겹침과 깊이** (`v12/a/`): 배치는 v11 의 위아래 쌓기 그대로. 대신 층을 만든다 — 페이지 바탕을 아주 옅은 면으로 깔고 카드·판을 흰 면으로 띄우기, 옅고 넓게 퍼진 그림자(여러 겹), 첫 화면 큰 둥근 판 위에 카드가 걸쳐 올라오는 겹침, 구간 경계가 둥근 면으로 넘어가는 처리, 앞뒤 층이 다른 그림 배치. 경계선(1px border) 위주의 납작한 카드 느낌을 없애는 것이 목표. 과한 유리 효과·네온 금지.
- **B. 배치를 다시** (`v12/b/`): 짜임을 바꾼다 — 크기가 다른 타일을 맞물린 격자(벤토), 큰 글자 머리 + 넓은 여백의 잡지형 리듬, 구간마다 다른 너비. 단 사용자가 싫어한 「좁은 칸에 왼쪽 제목 / 오른쪽 설명을 덕지덕지」 분할은 쓰지 않는다. 타일 안 글은 짧게.

## 두 안 공통으로 지킬 것
- 색: 코랄 `--brand #B84F48` 주 색 그대로, 1절 토큰 안에서. 새 색이 필요하면 코랄 계열의 옅은 면만
- 글꼴 티머니 둥근바람 400·800, 로고만 Pretendard. 글자 크기 다섯 단계(PC 40·28·20·18·16 / 767px 이하 30·24·20·18·16), 16px 미만 금지
- 글자 대비 4.5:1 이상(옅은 면 위 회색 글자 주의), 1440px·390px 에서 가로 넘침 0
- 각 안 폴더에 `landing.html`, `creator.html`, 공통 CSS 하나(`a.css`/`b.css`). 상대 경로로 v11 그림·글꼴 참조 가능
- 정적 HTML, 스크립트 최소

## 2단계 — A 확정, 나머지 화면을 A 로 (2026-10-13, 카드 d70 「A로」)

사용자: 「A 형태로. 다만 박스 안에 있는 아이콘 모양은 나중에 바꾸겠다」 → 아이콘 그림은 지금 것 그대로 쓰고 새로 고르지 않는다.

- 기준: `v12/a/landing.html`·`a/creator.html`·`a/a.css` (v11.css 를 불러와 층·그림자만 덧입힌 것). 원본 화면: `v11/<같은 이름>.html`
- 각 v11 화면을 `v12/a/<같은 이름>.html` 로 옮긴다. 내용·문구·구간 순서·배치는 v11 그대로, 시각 표현만 A 언어로: 옅은 코랄 바탕(`--page`) · 테두리 선 대신 흰 카드 + 그림자 · 화면 머리를 옅은 띠 위에 두고 첫 카드가 걸쳐 올라오는 겹침(과하지 않게, 화면 성격에 맞을 때만) · 큰 둥근 면.
- 폼·로그인·「내 팬꾹」 같은 업무 화면은 겹침보다 **띄운 흰 카드 한 장 + 차분한 바탕**이 기본. 장식 그림은 업무 화면에 넣지 않는다.
- **`a.css` 는 고치지 않는다**(세 에이전트가 동시에 작업한다). 묶음마다 공통 CSS 하나를 따로 둔다: 팬 묶음 `a-fan.css`, 크리에이터 묶음 `a-creator.css`, 계정·안내 묶음 `a-account.css`. 각 화면은 `a.css` 다음에 자기 묶음 CSS 를 불러온다. 화면마다 `<style>` 로 복사하지 않는다.
- 공통으로 지킬 것은 위 1단계와 같다(색 토큰·글꼴·크기 다섯 단계·대비 4.5·가로 넘침 0). 휴대폰에서 장식 그림이 글자 뒤에 겹치지 않게.
- 끝나면 각자 1440·390px 에서 넘침·16px 미만만 스스로 확인한다. 대비·눈 확인은 본체가 한다.

### 광고 배너 칸 (2026-10-13 사용자 추가 — 「크리에이터 요청에 의한 광고 배너 운용할 수 있게 배너 칸도 있으면 좋겠다. 너무 크진 않게 귀여운 슬라이드 형식으로」)
- 팬 묶음 에이전트가 만든다. 부품은 `a-fan.css` 에 `.ad-banner` 로 한 번만 정의하고, 슬라이드 동작은 `v12/a/banner.js` 하나(작게).
- 놓는 곳(본체가 정함, 승인 때 확인): 랜딩 첫 화면 바로가기 카드 아래(`a/landing.html` 에 이 칸만 추가) · 팬 메인(`home-fan.html`) 맨 위 · 크리에이터 찾기(`creators.html`) 목록 위.
- 크기: 너무 크지 않게 — PC 높이 120px 안팎, 휴대폰 96px 안팎, 본문 폭 안. 둥근 모서리, 옅은 코랄·민트·노랑 계열 면(대비 4.5 지킴)에 크리에이터 얼굴 그림 + 한 줄 문구(예: 「하루님 생일 주간 — 10월 20일까지 선물 받아요」) + 작은 「보러 가기」.
- 슬라이드: 3장 예시, 아래 점 표시, 이전/다음 버튼, 5초 자동 넘김 + **멈춤 버튼**(자동으로 움직이는 내용은 멈출 수 있어야 한다), 마우스 올리거나 초점이 들어가면 멈춤, 움직임 줄이기 설정이면 자동 넘김 끔. 손가락으로 밀어 넘기기.
- 귀여움: 넘어갈 때 살짝 튀는 움직임 정도. 배너에 「광고」 작은 표시(16px)를 둔다.

## 3단계 — v13 그림을 v12 A 에 합치기 (2026-10-13 카드 d73 「합쳐서 보여줘」)

v13(지금 사이트 위에 그림을 더한 시안) 중 사용자가 고른 구간을 v12 A 화면으로 옮긴다. v12 A 의 바탕·카드·그림자 표현은 그대로, 구간 안의 그림 요소만 v13 것을 가져온다.

| 구간 | 가져올 곳 | 넣을 곳 |
|---|---|---|
| 1. 「주소는 송장을 출력할 때만 열립니다」 | `v13/a/about.html` 의 `#once-title` 구간(마스코트 + 잠김/열림 카드 + 색 채운 단계 아이콘) + `v13/a/a.css` 의 해당 규칙 | `v12/a/about.html` 같은 구간 |
| 2. 선물 보내기 로그인 전 | `v13/b/send.html`(흐린 카드 + 「예시」 + 마스코트) + `v13/b/b.css` 해당 규칙 | 새 파일 `v12/a/send-loggedout.html` (v12 A 머리·바탕) |
| 3. 「이제 확인하고 선물을 받으세요」 | `v13/b/landing.html` 의 `#promise-title` 구간(열람 기록 모형 + 선 아이콘) | `v12/a/landing.html` 같은 구간 |
| 4. 요금 카드 | `v13/b/landing.html` 의 `#price` 구간(크기 다른 선 상자 + 예시 물건) | `v12/a/landing.html` 같은 구간 |

- 가져온 CSS 는 `v12/a/a-v13.css` 한 파일에 모으고, 세 화면이 `a.css`(+ `a-fan.css`) 다음에 불러온다. v13 의 카드 테두리 선은 v12 A 언어(선 없음 + 그림자)로 바꾼다.

- 모형 속 요소는 누를 수 없게(포인터·초점 없음) 유지.
- 공통 규칙(글자 다섯 단계·16px 이상·대비 4.5·넘침 0·옅은 면 위 글자 주의). 끝나면 1440·390 넘침·16px 미만만 스스로 확인. 보고 한국어 10줄 이내.
