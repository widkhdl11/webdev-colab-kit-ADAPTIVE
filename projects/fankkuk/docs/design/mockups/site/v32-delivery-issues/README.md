## 새로 제안하는 부분

- 팬 사이드바 「내 활동」에 「물품 보관소」 메뉴 추가
- 남은 날 알약(5일 이하는 경고색)
- 운영자 확인 요청 표에 「보관 상자」 칸(선반 번호 · 도착일 · 겉모습). 운영자가 선반의 원 송장과 회원이 넣은 번호를 맞춰 보려면 필요해서 넣었다
- 운영자 사이드바에 「물품 보관소」「배송문제 확인」 줄과 건수 알약(메뉴 이름은 예시)

## 확인할 부분

1. 팬 목록에 크리에이터·송장 단서가 없어 줄이 비슷해 보인다. 겉모습 글을 줄 맨 위 굵은 글씨로 올린 구성이 알아보기 편한지.
2. 「내 물품 확인」 창에서 맞았을 때 화면에 입력한 값(택배사·송장번호·찾을 선물)을 다시 보여 주는 것이 필요한지, 제목과 「닫기」만 둘지.
3. 확인 요청을 보낸 뒤 그 줄이 팬 목록에서 어떻게 보이는지(지금은 그대로 두고 따로 그리지 않았다). 「확인 대기」 표시를 줄에 둘지.
4. 배송문제 확인에서 25일 이상 강조 방식(노란 바탕 + 띠)이 충분히 눈에 띄는지.
