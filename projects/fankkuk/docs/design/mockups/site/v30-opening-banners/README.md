# 오픈 배너를 넣은 메인 페이지 시안

2026-10-19 사용자 피드백 반영: 실내 일러스트는 배너 느낌이 아니라는 의견에 따라, 리본·선물 그래픽과 대비 있는 하늘색 면으로 다시 만든 세 장을 실제 메인 페이지에서 확인한다. 제목·설명은 왼쪽, 그림은 오른쪽이며 이동 버튼은 짙은 회색이다.

확인 주소: http://localhost:3000/previews/opening-banners/index.html

- PC: 기존 메인 페이지의 배너 자리를 유지하고, 가로 이미지가 본문 폭 전체를 채운다.
- 휴대폰: 가로 배너를 통째로 줄이면 문구가 작아지므로 오른쪽 그림을 위에, 제목·설명·이동 버튼을 아래에 둔다.
- 소개 → 크리에이터 등록 → 첫 선물 안내 순서다. 아래 점과 화살표로 넘긴다. 비교하기 편하도록 자동 넘김은 멈춘 상태로 시작하며 재생 버튼으로 켤 수 있다.

이 파일은 화면 확인용 시안이다. 실제 배너 등록 내용과 서비스 코드는 바꾸지 않았다. 메인 페이지의 다른 부분은 시안을 만든 시점의 내용을 보여 준다.
