# 팬꾹 아이콘·그림 스타일 (Codex 이미지 생성용 공통 지시)

서비스: 팬꾹 — 팬이 크리에이터(방송인)에게 보내는 선물을 사무실에서 받아 검수한 뒤, 크리에이터 주소를 누구에게도 보여주지 않고 대신 보내 주는 서비스.
사용자가 원한 느낌: 「심플, 세련됨, 귀여움」. 참고 사이트 codeit.kr 의 메뉴 아이콘처럼 — 둥근 회색 칸 안에 들어가는 알록달록하고 통통한 아이콘.

공통 스타일
- 부드러운 3D(클레이/플라스틱 느낌), 둥글둥글하고 통통한 형태, 은은한 하이라이트와 아주 옅은 그림자 한 겹. 귀엽지만 유치하지 않게.
- 배경은 투명(PNG, 알파). 그림 주위에 여백 10% 정도. 정사각형.
- 색: 밝고 맑은 원색 계열을 섞되 채도는 살짝 낮게 — 맑은 초록 #2E7D64 계열, 하늘색, 노랑, 분홍, 주황, 보라 중 아이콘마다 2~3색. 검정 윤곽선 없음.
- 글자·숫자·로고·브랜드 마크를 그림 안에 넣지 않는다(단, 동전에 ₩ 기호는 허용).
- 사람 얼굴·실존 인물·실존 브랜드 없음.
- 같은 세트로 보이게 조명 방향(왼쪽 위), 재질, 두께를 모두 같게.
