# 팬(로그인) 화면 — 그림 교체 목록 (codex 생성용)

HTML 의 해당 요소에 `data-asset="파일이름"` 이 달려 있다. 지금 SVG 는 임시 — 생성된 그림을 `<img>` 로 바꾼다.
크리에이터 얼굴 아바타는 CSS 원이라 목록에 없다.
