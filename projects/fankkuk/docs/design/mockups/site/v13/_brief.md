# v13 시안 지시서 — 「텍스트뿐인 구간에 그림 요소 더하기」 (2026-10-13, 사용자가 준 프롬프트)

v12(겹침과 깊이) 작업과 별개다. 기준 화면은 **지금 사이트 = v11**. 재디자인이 아니라 그림 요소만 더한다.

## 사용자 프롬프트 요지 (원문은 대화에 있음)
- 서비스: 팬 → 크리에이터 선물 대리 배송. 주소는 송장 출력 때까지 잠김, 전 건 검수, 크리에이터가 카카오톡으로 한 건씩 승인. **마스코트: 뻐꾸기.**
- 「구조와 문구는 다 됐는데 거의 모든 구간이 글자뿐이라 비어 보인다. 그림 요소를 더해 달라, 재디자인 말고.」
- 제약: 문구·구간 순서·배치 격자를 바꾸지 않는다 · 지금 색(주 버튼 코랄 #B84F48, 따뜻한 옅은 바탕) 유지 · 그림·아이콘은 인라인 SVG(사진 금지) · 마스코트는 모든 구간에서 같은 선 굵기·같은 색 · 휴대폰 폭에서 동작(그림은 글 아래로 내려가도 됨) · 대비 WCAG AA(이 프로젝트는 모든 글자 4.5:1).

## 이번 단계: 1번 구간만, 두 방향
대상: 「팬꾹 소개」 3번 구간 「주소는 송장을 출력할 때만 열립니다」(`v11/about.html` 의 `#once-title` 구간). 지금 모습: `v13/_now-about-sec1.png`.
- 프롬프트는 「제목 아래 왼쪽 칸이 비어 있다」고 했지만 지금은 다섯 단계가 가로 한 줄이라 그 칸이 없다. 배치를 바꾸지 않으므로 **잠김→열림 카드는 제목·설명 아래, 단계 줄 위(가운데)** 에 둔다.
- 잠김→열림 카드: 주소가 잠긴 상태(가려진 주소 줄 + 자물쇠) → 송장 출력 때만 열린 상태 + 열람 기록 한 줄(예: 「10월 14일 14:02 · 주문 FK-2410 · 송장 출력으로 열림」). 실제 개인정보처럼 보이는 주소는 쓰지 말고 「서울시 ○○구 ○○로 ●●」처럼.
- 단계마다 단순한 아이콘 하나(번호 동그라미는 유지) + 단계를 잇는 선(PC 는 지금 가로선 유지·다듬기, 휴대폰은 세로로 쌓이면 세로선).
- 마스코트 뻐꾸기: `refs/fankkuk-icon-guide.md` 의 확정 심볼(코랄 원·아이보리 얼굴·차콜 눈·코랄 부리·상자, **그라데이션·그림자·입체 없음, 단색 면**)과 같은 그림 언어로. 1번 구간에 꼭 넣을 필요는 없지만, 넣는다면 이 언어. 이후 구간 2~4 에서도 같은 언어를 쓸 수 있게 SVG 를 `<symbol>` 로 정리.
- 기존 3D 아이콘(`v4/img/icon-*.png`)은 쓰지 않는다 — 사용자가 「AI티가 난다」고 했다.

### 두 방향
- **A. 납작한 그림 위주** (`v13/a/about.html`): 단색 면 일러스트(마스코트가 잠긴 상자를 지키는 장면 등) + 단계 아이콘도 같은 그림 언어. 잠김→열림 카드는 그림 속 소품처럼 단순하게.
- **B. 화면 모형 위주** (`v13/b/about.html`): 실제 앱 화면처럼 보이는 작은 카드(주소 칸·자물쇠·「송장 출력」 버튼·열람 기록 줄)로 보여 준다. 단계 아이콘은 선 아이콘(같은 선 굵기). 마스코트는 작게 한 번만.

## 공통
- `v11/about.html` 을 복사해 해당 구간만 바꾼다. 다른 구간은 손대지 않는다. CSS 는 `v11/v11.css` 를 불러오고 추가분만 `a/a.css`·`b/b.css`.
- 글꼴·글자 크기 다섯 단계(PC 40·28·20·18·16 / 767px 이하 30·24·20·18·16)·16px 미만 금지·1440·390 가로 넘침 0.
- 보고 한국어 10줄 이내: 만든 파일, 스스로 정한 것, 확인한 것.
