3파트 v39 — 보내기 세 화면

왼쪽이 지금 사이트, 오른쪽이 v39예요. 시안 위 회색 막대로 단계·상태를 바꿔 볼 수 있어요. 이름·번호·날짜는 예시예요. 기준은 1파트 v35·2파트 v37.

선물 보내기 A — 입력 + 오른쪽 한 칸

  • 시각적 중심: 오른쪽 회색 칸의 합계(48). 4단계에서 같은 칸이 하늘색 결제 칸으로 바뀜
  • 비대칭: 입력 본문 + 오른쪽 288 칸. 크리에이터 고르기는 카드 2열, 상자 수는 한 줄씩
  • 밀도: 여유 = 단계 제목·선물 종류 알약 · 보통 = 크리에이터 카드 · 촘촘 = 접어 둔 선물 사진·나만 보는 메모
  • 뺀 것: 페이지 설명 「누구에게, 무엇을, 몇 상자…」, 상자 안내 중 구간별 기준 세 줄(상자 줄에 이미 있음), 돌려보내는 안내 두 카드의 좌우 나열(회색 칸 하나로). 새로 제안: 1~3단계에서도 요약 칸을 보임

선물 보내기 B — 단계 판 + 한 칸 기둥 (추천)

  • 시각적 중심: 맨 위 하늘 판의 단계 숫자(48)와 이번 단계 제목. 단계 막대가 판 안에 들어감
  • 비대칭: 판(하늘) 위, 흰 입력 판 아래 — 폭 720 한 기둥. 상자 수는 큰 숫자 세 칸
  • 밀도: 여유 = 단계 판 · 보통 = 크리에이터 줄·선물 종류 · 촘촘 = 확인 줄(4단계)
  • 추천 이유: 입력이 한 기둥이라 휴대폰과 읽는 순서가 같고, 지금 사이트에 없는 칸(1~3단계 요약)을 더하지 않으며, 팬에게 보내기 추천안(아래 결제 띠)과 틀이 겹치지 않음

팬에게 보내기 A — 팬 카드 격자 + 아래 결제 띠 (추천)

  • 시각적 중심: 화면 아래에 붙는 하늘색 결제 띠의 「받을 팬 N명」(48)
  • 비대칭: 팬 카드 3열(1040) 위, 긴 결제 띠 아래. 고른 카드만 크기 고르기가 열림
  • 밀도: 여유 = 결제 띠 · 보통 = 팬 카드 · 촘촘 = 회색 칸 하나로 묶은 진행 순서·안내
  • 추천 이유: 팬이 많아도 합계·결제가 늘 아래에 붙어 있고, 선물 보내기 B·보낸 역조공과 틀이 다름. 뺀 것: 페이지 설명 문장

팬에게 보내기 B — 촘촘한 팬 줄 + 오른쪽 결제 칸

  • 시각적 중심: 오른쪽 하늘색 결제 칸(스크롤을 따라옴)의 합계
  • 비대칭: 팬 줄 목록 + 오른쪽 288. 크기는 고른 줄 안에서 바로 고름
  • 밀도: 여유 = 결제 칸 · 보통 = 팬 줄(64) · 촘촘 = 세로 시간선 진행 순서

  • 밀도: 여유 = 상태 띠 · 보통 = 열린 묶음의 팬 줄(64)·받는 주소 · 촘촘 = 접힌 묶음 한 줄·알아 두세요
