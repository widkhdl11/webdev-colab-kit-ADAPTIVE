# 팬꾹 크리에이터 상세 화면 — 재디자인 시안 (Codex 에게)

너는 웹 디자이너다. 팬꾹(크리에이터에게 팬이 선물을 보내는 사이트)의 **크리에이터 상세 화면** 시안을 정적 HTML 로 만든다.
보고와 화면 글자는 한국어로 쓴다.

## 결과물
- 폴더: `projects/fankkuk/docs/design/mockups/site/profile-codex-2026-10-25/` (이 PROMPT.md 가 있는 폴더). 이 폴더 밖의 파일은 **만들거나 고치지 마라**. `src/`·다른 시안 폴더·문서 모두 손대지 마라. git 커밋하지 마라.
- `index.html`(화면 목록 + 각 화면을 PC 1440·휴대폰 390 두 폭 iframe 으로 나란히) + 화면 html 다섯 + css 하나.
- 화면 다섯:
  1. 로그인 전 · 취향 칸 있음
  2. 로그인 전 · 취향 칸 없음 (실제 구현 기준)
  3a. 로그인한 팬 · 팔로우 안 함
  3b. 로그인한 팬 · 팔로우 중
  4. 크리에이터가 쉬는 중

## 사용자가 이미 정한 것 (바꾸지 마라)
1. **디자인은 심플하게.** 쓸데없는 설명 문장·과한 글자를 넣지 않는다. 제목 아래 부연, 버튼 아래 안내 줄, 괄호 설명 금지. 버튼 글자는 짧게.
2. **떠 있는 카드(팝업처럼 보이는 상자) 금지.** 선물 보내기 카드를 배경 위에 띄우지 않는다.
3. **버튼은 소개 아래 왼쪽.** PC·휴대폰 같은 자리. 글자 폭 버튼(높이 44 이상).
   - 팔로우 안 함·로그인 전: 채운 「팔로우」 하나.
   - 팔로우 중: 채운 「선물 보내기」 + 테두리 「팔로우 중」 나란히.
   - 쉬는 중: 버튼 대신 한 줄 「쉬고 있어요. 11월 3일부터 다시 받을게요」.
   - 채운(주) 버튼은 화면에 하나뿐.
4. 뺀 것: 「받는 상태 · 지금 선물을 받고 있어요」 칸, 이름 아래 링크 주소 줄, 버튼 아래 팔로우 안내·주소 약속 줄, 맨 아래 「선물 보내기」 판, 오른쪽 좁은 열, 감사 답장 설명 문장.
5. 「취향」 칸(사진 카드 + 짧은 글 + 태그)은 새 기능이라 1번 화면에만, 제목 옆에 작게 「새 기능 — 아직 없음」. 설명 문장 없이.

## 화면에 들어갈 내용 (위에서 아래, 화면 2 기준)
- 머리: 배경 사진(테마 색 면 + 고양이 그림 자리표시) · 원형 프로필 사진 · 이름 「하늘」 + 팬덤 뱃지 「하늘이네」 + 채널 아이콘 하나(유튜브) · 칩 「채널 소유 확인」(아이콘) 「게임」 「일상」 · 한 줄 소개 「함께 웃는 하루를 만들어요.」 · 감사 문장 「하늘이네 여러분의 마음 늘 감사해요」 · 버튼.
- 받기 어려운 품목(있을 때만 보이는 한 줄 알림): 「받기 어려운 품목」 + 「지금은 부피가 큰 선물을 받기 어려워요 ㅠㅠ 이사 중이라 둘 곳이 없어요」.
- 숫자: 「평균 승인 시간」 2시간 10분 · 「요금」 6,900원부터 · 「기념일」 데뷔 기념일 (11월 9일) D-15.
- 「이번 달 3명의 팬이 마음을 보냈어요」 — **글자 그대로**(규칙 문장).
- 감사 답장 모음: 답장 카드 셋(「선물 잘 받았어요. 덕분에 힘이 났어요.」 별빛님에게 · 2026.10.21 등).
- 보내기 전 안내: 접는 줄 둘 — 「보낼 수 없는 것」(펼치면 목록: 음식물 · 액체류 · 현금·상품권 · 위험물 · 살아 있는 동물과 식물 — 이 목록은 **이 화면에서 펼쳐 보여야** 한다, 다른 페이지 링크로 빼지 마라), 「상자는 이렇게 확인해요」(펼치면 세 줄: 「모든 선물은 팬꾹에서 검수한 뒤 보내요.」 「탐지기에 반응한 상자는 열어서 확인해요.」 「크리에이터가 승인하기 전에는 주소가 공개되지 않아요. 크리에이터 주소는 팬에게 공개하지 않아요.」 — 글자 그대로).
- 「이런 크리에이터도 있어요」: 카드 넷 + 「전체 보기」(휴대폰에서는 목록 아래 오른쪽).
- 위 메뉴(로고 「팬꾹」 · 크리에이터 찾기 · 선물 보내기 · 공지사항 · 고객센터 · 오른쪽 로그인/회원가입 또는 로그인 사용자) · 바닥글(이용약관 · 개인정보처리방침 · 취소·환불 규정 · 고객센터).
- 이 목록에 없는 글자를 새로 지어 넣지 마라.

## 지켜야 할 값
- 색: 사이트 주 색은 하늘색(`--primary`). 참고 사진의 진한 파랑은 쓰지 않는다. 크리에이터 테마 색은 배경 사진 면·프로필 사진 테두리·팬덤 뱃지에만.
- 글자 굵기는 800·600·400 만(500 은 위 메뉴만). 700 금지. 본문 16 이상, 캡션만 13~14.
- 누를 곳은 높이 44 이상, 키보드 초점 테두리.
- 폭: PC 본문 최대 1080 한 기둥. 휴대폰 390 에서 가로 스크롤이 생기면 안 된다(좌우 여백 16).
- 글자 대비 4.5:1 이상.
- 줄바꿈: `word-break: keep-all`, 문단 `text-wrap: pretty`.
