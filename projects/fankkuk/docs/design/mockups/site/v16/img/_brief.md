# 팬꾹 3D 그림 다시 만들기 (Codex 이미지 생성 지시, 2026-10-13)

사용자: 「3D 그림이 싫은 건 아니야. 다만 디자인이 별로였던 거지. 다시 만들어 달라고 해서 우선 적용해.」
예전 그림: `../../v4/img/icon-*.png`, `illust-empty-*.png` (512px 투명 PNG, 스타일 지시는 `../../v4/img/_style.md`). 예전 그림을 열어 보고 무엇이 어색한지 먼저 파악한 뒤 다시 그린다.

## 서비스
팬꾹 — 팬이 크리에이터(방송인)에게 보내는 선물을 사무실에서 받아 검수한 뒤, 크리에이터 주소를 누구에게도 보여 주지 않고 대신 보내 주는 서비스. 마스코트는 뻐꾸기(로고: 코랄 원 안의 아이보리 뻐꾸기 얼굴 + 선물 상자). 사이트 색은 진한 코랄 #B84F48, 옅은 코랄 면 #FFF5F1·#FCECE8, 아이보리 #FFF8F0, 차콜 #343039.

## 예전 그림에서 고칠 점 (본체 판단)
- 아이콘마다 초록·하늘·노랑·분홍·주황·보라를 섞어 사이트 코랄과 따로 논다 → **한 팔레트로**: 코랄(#F58278·#B84F48), 아이보리(#FFF8F0), 차콜(#343039)이 주, 강조색은 세트 전체에서 하나만(옅은 민트 #CDEBDD 또는 버터 노랑 #FFE7A8 중 하나를 골라 일관되게).
- 반짝이는 플라스틱 광택 → **무광 점토(소프트 클레이) 질감**, 하이라이트는 아주 약하게, 바닥 그림자는 옅은 한 겹.
- 형태가 제각각 → 같은 카메라 각도(정면에서 살짝 위, 약 15°), 같은 조명(왼쪽 위), 같은 두께·둥글기. 디테일을 줄여 단순하고 또렷하게.
- 귀엽되 유치하지 않게, 세련되게. 글자·숫자·로고·사람 얼굴 없음.
