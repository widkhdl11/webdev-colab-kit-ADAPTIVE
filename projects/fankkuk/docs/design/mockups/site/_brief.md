# 사이트 전체 시안 브리프 (2026-10-01)

사용자가 메인 시안을 거부했다: "저렇게 좁은 화면이 아니라 일반 사이트같은 사이즈로 생각했는데" /
"애초에 모든 페이지 시안을 보여주고 시작해야지". 그리고 아래 구성을 주며 "부족한건 너가 채워서 시안 만들어줘봐".

## 사용자 구성 원문 (요약하지 말고 이것을 따른다)

- 헤더에는 로그인과 회원가입이 있다. 회원이 선물을 보내는 중이라면 옆에 선물 배송중, 배송완료 같은 아이콘이
  뜨면 좋겠다. 선물을 여러 개 보낼 수도 있으니 각 선물마다 뜨고, 마우스를 올리면 "선물 2개중 1개 배송중" 식으로.
- 사이트에 접속하면 랜딩 페이지. 팬꾹을 소개하면서 내려가고, 아래에 '지금 바로 선물 보내러가기'·'나의 크리에이터 찾으러 가기' 버튼.
- 메인 페이지가 따로 있다. 로그인 된 상태면 바로 메인으로 간다.
- 네비게이션: 크리에이터 찾기(실시간 검색, 검색어에 따라 아래에 리스트) · 선물 보내기 · 공지사항 · 팬꾹 소개 · 고객센터
- 내 정보: 개인정보 확인·수정 / 팔로우한 크리에이터 목록 / 선물 보낸 내역과 보내고 있는 선물들의 상황

## 폭 — 이번 거부의 핵심

- **PC 기준 일반 사이트.** 본문 컨테이너 최대 1200px 중앙, 좌우 여백 24px(PC)·16px(휴대폰).
  1440px 창에서 넓게 보여야 한다. 휴대폰 폭 기둥을 PC 가운데 세우는 레이아웃 금지.
- 반응형: 1024 이상 = 가로 네비·여러 칸 그리드 / 768~1023 = 2칸 / 767 이하 = 햄버거 메뉴·1칸.
- 카톡 안 브라우저(휴대폰)로 오는 사람도 많다 — 휴대폰 폭에서도 깨지지 않게.

## 그대로 물려받는 것 (사용자 승인된 색·모양 — 거부된 것은 폭뿐)

- 색 토큰은 `../main.html` 의 `:root` 그대로 (청록 #32776B 버튼·로고, 아이보리 #FAF9F5 바탕, 흰 카드, 차콜 글자, 살구는 장식만·글자 금지).
- 형태: 카드 반경 12px + 1px 선, 그림자 없음(떠 있는 것만) / 버튼 반경 = 높이÷4 / 배지·칩 알약형 / 원 반복 / 통통한 채움 아이콘 + 옅은 청록 둥근 타일.
- Pretendard(cdn.jsdelivr.net). 본문 16px 이상, 16px 미만 글자 없음. 간격 4px 단위 짝수.
- 무드: 일러스트·말투는 귀엽게("보내 드려요"), 보안 약속·절차는 또렷하고 차분하게.
- 대비 4.5:1 이상. 청록 글자는 옅은 청록 면(#EEF1ED)보다 진한 면 위에 쓰지 않는다.

## 문구 한계 (사실 오류 방지)

- 쓴다: "승인 없이는 저희 시스템이 주소를 열지 않습니다"
- 쓰지 않는다: "절대 유출되지 않습니다", "저희도 열 수 없습니다", "모든 상자를 열어"(검수는 송장 제거·겉면 검사, 걸린 상자만 개봉), 경쟁 서비스 이름
- 요금: 상자마다 배송비 포함 — 소형(세 변 합 100cm·5kg 이하) 6,900원 / 중형(세 변 합 100cm·10kg 이하) 8,900원, 크기·무게 중 큰 쪽. 중형 초과는 받지 않음. 금액 옆 「추적 장치 검수 포함」. 도착 실측이 크면 차액 따로 결제.
- 승인은 크리에이터가 카카오톡 인증서로 건별 서명. "전체 승인" 버튼 없음. 거절 이유는 팬에게 알리지 않음.
- 팬에게 크리에이터행 운송장 번호는 보여주지 않는다. 사무실 주소는 승인 뒤에만 팬에게 보인다.
- 팬 단계: 등록 → 승인 → 입고 → 검수 → 출고 → 배송중 → 수령.
- 예시 데이터는 지어낸 이름(하루·모모·새벽달 등). 실존 크리에이터·회사 이름 금지.

## 부족한 것을 채운 결정 (시안에 반영, 사용자에게 보고할 것)

- 헤더 선물 아이콘: 진행 중인 선물마다 동그란 아이콘 하나(상태별 모양: 승인 대기=모래시계, 이동 중=트럭, 배송 완료=체크).
  최대 3개 + "+N". 마우스 올림·키보드 포커스 모두 말풍선: 「선물 3개 중 1번째 · 하루님께 · 배송중」. 누르면 그 선물 상세.
  배송 완료 아이콘은 3일 뒤 사라진다. 휴대폰에서는 아이콘 대신 「선물 3」 배지 하나 → 누르면 목록이 아래에서 올라온다.
- 로그인 후 헤더: 로그인·회원가입 자리에 선물 아이콘 + 내 정보(닉네임 원 아바타 → 메뉴: 내 정보·팔로우·선물 내역·로그아웃).
- 크리에이터 찾기: 본인 확인(방송 채널 인증)을 마친 크리에이터만 검색된다. 결과 카드 = 이름·채널·평균 승인 시간·팔로우·선물 보내기.
- 크리에이터 페이지(상세)를 하나 더 둔다 — 검색 결과에서 들어가는 곳.
- 크리에이터용 화면(승인 요청·열람 기록·주소와 설정)도 그린다. 운영자 화면은 별도 기준(빽빽한 작업 화면)이라 이번에 뺀다.
- 내 정보의 휴대폰 번호 변경은 카카오 인증을 다시 받아야 한다고 표시. 아이디는 바꿀 수 없음.
