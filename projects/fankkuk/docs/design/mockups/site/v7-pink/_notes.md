상태 면은 성공 `--success-background: #EAF5EE`, 대기 `--warning-background: #FFF5DB`, 오류 `--danger-background: #FEECE9`, 정보 `--info-background: #EDF4FA`다. 표의 상태 대비는 각 글자색과 상태 면 사이의 값이다. 비활성 면 `--disabled-background`는 기존 `#F0E8E4`다. 카드 구분선의 대비는 글자 기준을 적용하는 값이 아니며, 입력창 경계는 기존 색을 유지한다.

분홍 위에는 항상 차콜 글자를 쓴다. 흰색과 분홍의 대비는 2.52:1이므로 흰 글자를 올리지 않는다. 분홍 버튼은 안의 차콜 글자로 행동을 식별한다. 넓은 제목 강조도 분홍 글자 대신 분홍 면에 차콜 글자를 쓴다.

`--primary`·`--brand`는 메인 분홍, `--primary-hover`·`--brand-hover`는 분홍 올림색, `--primary-active`·`--brand-active`는 분홍 눌림색으로 연결했다. `--primary-foreground`·`--on-brand`는 차콜이다. 링크·작은 강조는 `--brand-point`를 직접 사용한다.

로고 네 색과 기존 그림·얼굴의 색값은 그대로다. HTML의 색값만 로고·그림·얼굴 전용 토큰으로 옮겼다. 카카오 버튼의 기존 노란색도 전용 토큰으로 옮겼다. 페이지 바탕에 아이보리는 쓰지 않는다.

# 대비 확인

2026-10-07, 설치된 Edge를 Playwright로 실행했다. `node _audit.tmp.cjs`를 실행한 뒤 임시 검사 스크립트·JSON 결과·스크린샷은 삭제했다. 아래는 실행 결과의 요약이다.

- 27장 × 1440·390px = 54개 화면. 일반 글자 4.5:1, 큰 글자 3:1을 기준으로 계산했다. 큰 글자는 24px 이상 또는 굵기 700 이상인 18.67px 이상이다.
- DOM 글자·입력값·자리표시자·문자형 가상 요소의 실제 계산된 글자색과 부모까지 합성한 배경색을 사용했다. 기본 화면에서 3,975개 글자 항목을 검사했다.
- 숨겨진 단계·탭·메뉴·안내문·접힌 상세를 각각 펼친 222개 경우도 확인했다. 이는 111곳을 두 폭에서 확인한 수이며 모든 입력 조합을 뜻하지 않는다.
- 기본 화면과 펼친 상태에서 마우스 올림·눌림 CSS도 적용했다. 전환 효과를 끄고 최종 색을 계산했다.
- 대비 미달 0건. 전체 최저 **4.55:1**은 차콜 글자와 분홍 눌림색 `#ED766C`의 조합이다. 기본 화면의 가로 넘침도 0건이다.
