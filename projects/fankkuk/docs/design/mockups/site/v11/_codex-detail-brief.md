# v11 시안 세부 다듬기 — Codex 지시

이 폴더(v11)는 팬꾹 사이트 재디자인 시안 28장이다(목록 index.html, 공통 CSS v11.css). 팬꾹은 팬이 크리에이터에게 선물을 보내면 팬꾹이 검수해 대신 배송해 주는 서비스다.
사용자 평가: **「커다란 가닥은 괜찮은데, 디테일한 디자인과 중앙 정렬 등이 부족하다」.** 큰 구조는 유지하고 세부를 채운다.

## 바꾸지 않는 것 (사용자가 정했다 — 어기면 안 된다)
- 글꼴: 티머니 둥근바람("Tmoney Round Wind", 굵기 400·800 둘뿐, font-synthesis:none). 헤더·바닥글의 「팬꾹」 로고 글자만 Pretendard(라이선스상 로고에 티머니 글꼴 금지).
- 글자 크기 단계: PC 40/28/20/18/16 · 767px 이하 30/24/20/18/16. **16px 미만 글자 금지.** 새 크기를 만들지 않는다.
- 색 토큰(v11.css :root)과 그림(../v4/img/). 코랄은 버튼·링크·강조에만. 본문 기본색 --ink.
- **좌우로 나눈 구조를 다시 만들지 않는다**(사용자: 「좁은 공간에 설명을 덕지덕지 붙여놓은 것 같아서 한눈에 들어오지 않고, 설명글 같이만 보여. 그리고 정렬이 맞지도 않아」). 위에서 아래로 쌓기를 유지한다.
- 문구(글 내용)는 바꾸지 않는다. 시안의 화면 구성 요소를 빼지 않는다.
- 정적 HTML·CSS 만. 외부 스크립트·새 라이브러리 금지.

## 할 일
1. **공통 부품을 v11.css 로 모은다.** 지금 화면마다 <style> 에 같은 CSS 가 복사돼 있다(「내 팬꾹」 왼쪽 메뉴 틀 .my-grid 류, 탭 .tabs, 스위치 .sw, 선택 카드 .opt, 얼굴 .face/.avatar, 크리에이터 카드 .ccard, 플랫폼 태그 .ctag, 펼치는 줄 .acc, 라벨·값 줄 .kv, 진행 막대 .dots, 흰 판 .part, 카카오 버튼 .btn--kakao, 인증 화면 .auth, 칩 줄 .chips 등). 같은 이름이 화면마다 다르게 정의돼 있으면 하나로 맞추고, 화면 <style> 에는 그 화면에만 있는 것만 남긴다.
2. **정렬 체계를 세우고 전 화면에 적용한다.**
   - 구간 머리(제목·한 줄 설명)는 기본 가운데 정렬. 그 아래 카드 격자도 가운데 기준으로 균형 있게(카드 수가 열 수로 나누어떨어지지 않으면 마지막 줄 가운데 정렬 또는 열 수 조정).
   - 폼·인증·확인 화면(로그인·가입·비밀번호·메일 확인·역조공 받기·선물 보내기)은 가운데 한 기둥(최대 폭 560~720px).
   - 「내 팬꾹」 안의 본문 머리는 본문 기둥 기준으로 일관되게.
   - 버튼 묶음은 그 구간 정렬을 따른다(가운데 구간이면 가운데).
   - 한 구간 안에서 정렬 기준이 섞이지 않게.
3. **세부 디자인을 채운다.** 예: 카드 안 여백·제목/본문/메타 간격의 일정한 리듬(8px 배수), 카드 높이 맞춤, 아이콘·그림 크기 통일, 상태 배지·진행 단계·숫자 강조의 완성도, 구분선·빈 상태·마우스 올림/포커스 표시, 표·목록 줄 높이, 버튼 크기 일관성, 구간 사이 여백 리듬, 휴대폰 폭에서 여백·줄바꿈 다듬기. 「심플·세련·귀여움」 — 그림·말투는 귀엽게, 보안 약속은 또렷하고 차분하게.
4. index.html 은 목록 페이지로 유지하되 같은 수준으로 다듬는다.

## 끝내기 전 확인
- 모든 화면이 1440px 와 390px 에서 가로로 넘치지 않는지, 16px 미만 글자가 없는지, 글자 대비가 4.5:1 이상인지 스스로 확인할 수 있는 만큼 확인한다(못 하면 못 했다고 쓴다).
- 마지막 메시지는 **한국어**로: 바꾼 것 요약(공통 부품·정렬 규칙·세부), 화면별로 크게 바뀐 곳, 확인한 것/못 한 것. 20줄 이내.
