# 색 배치 원칙

- 페이지와 일반 카드는 흰색으로 비우고, 카드·목록·입력은 경계선으로 구분한다.
- 아이콘 칸·비선택 탭·빈 목록은 아주 옅은 중립색으로 통일한다. 그림 자체의 색은 그대로 둔다.
- 옅은 코랄 면은 랜딩의 주소 보호 약속 구간, 개인정보 안내, 선택 항목, 금액·업무 요약에 모은다.
- 진한 코랄은 주 버튼·링크·강조 문구·작은 숫자 표시에 유지한다. 보조 버튼은 흰 면과 얇은 경계로 구분한다.
- 헤더는 흰색과 아래 경계선, 푸터는 옅은 중립색으로 구분한다. 상태는 완료·승인 초록, 대기·남은 기간 노랑, 거절·문제 빨강, 진행·배송 파랑으로 나눈다.

| 토큰 | 이전 값 | 새 값·역할 |
| --- | --- | --- |
| --surface-neutral | 없음 | #F7F7F8 · 일반 칸·빈 목록·푸터 |
| --surface-hover | 없음 | #F0EFF1 · 일반 항목에 마우스를 올렸을 때 |
| --surface-brand | 없음 | #FFF5F1 · 옅은 코랄 안내 면 |
| --surface-summary | 없음 | var(--surface-brand) · 금액·업무 요약 |
| --surface-privacy | 없음 | var(--surface-brand) · 주소·개인정보 안내 |
| --surface-subtle | #FFF3EE | var(--surface-brand) · 기존 이름 연결 |
| --surface-selected | #FDE9E5 | #FCECE8 · 선택 항목 |

| --border | #EADDD7 | #DFDCE0 · 중립색 경계선 |

페이지·카드·입력은 #FFFFFF, 주 버튼은 #B84F48, 버튼 위 글자는 #FFFFFF를 유지했다. 보조 버튼 글자 #A4433D, 입력 경계 #8C7B76, 네 가지 상태 색도 유지했다. --brand·--ink·--sub·--faint·--white 등 기존 이름은 그대로 연결한다. 밝은 분홍 #F58278은 로고와 로고 색 견본에만 남긴다.

## 대비·크기·넘침 확인

2026-10-07, 설치된 Edge 154를 Playwright로 실행해 HTML 27장(시안 목록·색 견본 포함)을 1440×1000, 390×1000으로 열었다. 실행 명령은 `node _audit.cjs`이며 종료 코드는 0이었다. 검사 스크립트와 상세 JSON 결과는 운영체제 임시 디렉터리에 두고 시안 폴더에서는 제거했다.

- 54회 화면 검사, 보이는 글자·입력값·placeholder 3,879개 확인.
- 일반 글자 최저 4.6078:1: 역조공 만들기의 「배송비와 추적 장치 검수 포함」, #B84F48 / #FFF5F1.
- 전체 최저 4.6078:1. 일반 글자 4.5:1·큰 글자 3:1 미달 모두 0건.
- 16px 미만 0건, 문서 전체 가로 넘침 0건, 깨진 이미지 0건.
- 계산은 브라우저의 최종 글자색과 조상 배경색을 합성한 뒤 상대 휘도로 비교했다. 큰 글자는 24px 이상 또는 굵기 700 이상인 18.667px 이상으로 분류했다.
- 25개 서비스 화면의 본문 구조·문구·인라인 스타일을 v5-white와 비교해 차이 0건. 스타일 블록·색 클래스·CSS 파일명·주석은 비교에서 제외했다.
- 랜딩·크리에이터 홈·보내기 데스크톱, 랜딩·보내기·받은 역조공 모바일의 전체 화면 캡처를 확인했다.
- 숨겨진 탭·모달·모든 입력 단계와 조작 조합, 그림 안에 그려진 글자는 이번 수치 검사에 포함하지 않았다. 외부 글꼴 CDN의 모든 접속 환경도 보장하지 않는다.
