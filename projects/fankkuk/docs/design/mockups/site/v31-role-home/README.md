# 세 가지 홈의 공통 구성 시안

2026-10-20. 로그인 전·팬 로그인 후·크리에이터 로그인 후 화면을 나란히 비교하기 위한 정적 시안이다. 이름과 건수, 선물 목록은 예시이며 실제 로그인이나 데이터를 연결하지 않았다.

미리보기: `http://localhost:3000/images/previews/role-home-unified-v31/index.html`

- `guest.html`: 로그인 전
- `fan.html`: 팬 로그인 후
- `creator.html`: 크리에이터 로그인 후
- `index.html`: 같은 비율로 줄인 세 화면 비교. PC 1440px·모바일 390px 전환, 개별 화면 크게 보기 제공
- `styles.css`: 세 화면 공통 스타일
- `preview.js`: 정적 시안임을 적은 주석. 소개 배너는 사용자가 고른 한 장만 표시

## 세 화면에서 맞춘 부분

히어로 → 그림 바로가기 네 개 → 소개 배너 → 역할별 본문 → 공지사항 순서를 맞췄다. 본문은 880px, 로그인 후 사이드바는 실제 화면과 같은 240px이다. 로그인 전 상단바의 64px 높이만큼 화면 시작점은 다르다. 로그인 후 배경은 사이드바를 제외한 영역 전체에 깔린다.

색은 승인 기준 000절의 하늘색 면과 짙은 회색 글자를 쓴다. 본문 Pretendard와 제목 티머니 둥근바람은 00절, 글자 크기와 간격·반경은 00000절을 따른다. 비눗방울·고양이·배너·바로가기·상자 그림은 현재 사이트 자산을 그대로 쓴다.

## 새로 제안하는 부분

- 세 역할에서 히어로 크기와 바로가기 모양을 맞춘다. 로그인 후에도 비눗방울 배경과 고양이를 쓴다.
- 팬 히어로는 인사와 검색, 크리에이터 히어로는 인사와 작은 프로필·내 페이지·프로필 수정 버튼으로 바꾼다.
- 크리에이터의 세로 바로가기를 공통 그림 카드 네 개로 바꾼다. 승인 버튼은 홈에 넣지 않고 처리할 일 목록으로 연결한다.
- 모바일에서도 바로가기 두 줄 두 칸과 같은 히어로 높이를 유지한다. 역할별 제목 줄 수가 달라도 검색·프로필과 버튼의 세로 위치가 같다.

## 확인할 부분

1. 같은 히어로·바로가기·배너로 세 화면이 충분히 비슷하게 느껴지는지.
2. 로그인 후에도 소개 배너를 같은 크기와 위치로 두는 것이 적절한지.
3. 크리에이터 히어로 안 작은 프로필과 버튼 구성이 필요한 정보를 담는지.
4. 모바일에서 히어로 높이와 바로가기 두 줄 구성이 편한지.

승인된 디자인 기준과 실제 서비스 코드는 수정하지 않았다. 이 시안은 승인 후보이며 구현 완료를 뜻하지 않는다.

## 화면 확인

세 역할을 1440·1024·390px에서 확인했다. 가로 넘침·깨진 이미지 0, 일반 글자 계산 대비 최저 5.64:1이다. 이미지 위 글자는 배경 원본 픽셀을 3px 간격으로 표본 측정했고, 모바일 크리에이터 머리말은 4.35:1에서 8.45:1로 개선했다. 비교 화면 PC/모바일 전환과 크게 보기 링크도 확인했다.
