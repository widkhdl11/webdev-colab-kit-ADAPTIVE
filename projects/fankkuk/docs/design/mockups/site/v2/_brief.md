# 색·포인트 시안 브리프 (2026-10-01)

사용자 원문: 「색감을 바꾸고 싶다. 하얀색에 가까운 바탕으로 해달라. 그리고 AI 디자인이 표준만 고집하다보니
다 비슷한 느낌으로 만들어진다던데. 한두 포인트만 살려서 AI 느낌을 없애줘」

구성·폭(`../site.css` 의 레이아웃·헤더·반응형)은 승인 상태다 — 「전체적으로 마음에 드는거 같다」. 바꾸는 것은 색감과 인상뿐.

## 공통으로 바꾸는 것

- 바탕을 하얀색에 가깝게: 페이지 `#FFFFFF` 또는 아주 옅은 흰색(채도 거의 0). 아이보리·옅은 청록 면을 넓게 까는 것을 줄인다.
- 지금 시안이 「AI가 만든 것 같은」 이유(이것을 없앤다):
  모든 구간이 같은 간격·같은 카드 격자 · 둥근 카드 + 옅은 면 + 아이콘 타일 반복 · 가운데 맞춘 제목+설명 머리 · 모든 것이 같은 무게라 시선이 갈 곳이 없음 · 무난한 녹색 계열 한 가지.
- 방법: **포인트 한두 개만 강하게, 나머지는 조용하게.** 포인트가 아닌 곳은 장식을 빼고(아이콘 타일·옅은 면·그림자 없이) 선과 글자만으로.
  격자를 일부러 깨는 곳 하나(비대칭·크기 대비), 크기 대비가 큰 제목 하나.
- 청록 브랜드색(#32776B)은 유지해도 되고, 안마다 포인트에 맞춰 바꿔도 된다(그 경우 흰 바탕 위 글자 대비 4.5 이상).

## 세 안 — 각각 포인트 하나(많아야 둘)

| 안 | 포인트 | 어디에 쓰나 |
|---|---|---|
| A 도장 | 이름 「팬꾹」의 「꾹」 = 도장을 꾹 누르는 것. 승인·상태 표시를 잉크 도장(살짝 기울고 테두리가 거친 원·사각 도장)으로 | 랜딩 첫 화면의 큰 「승인 꾹」 도장, 상태 배지, 헤더 선물 아이콘 |
| B 송장 라벨 | 택배 송장·라벨의 말투 — 점선 절취선, 굵은 고정폭 주문번호, 바코드 줄무늬, 검정에 가까운 잉크색 + 한 가지 형광 강조 | 선물 카드·결제 요약·단계 표시가 라벨처럼 |
| C 큰 글자 | 아주 큰 굵은 한글 제목 + 손으로 그은 듯한 밑줄·동그라미 표시(형광펜 한 색) | 랜딩 제목, 각 구간 머리, 강조할 숫자(6,900원) |

## 만들 것 (이 폴더 `v2/`)

- `a.css` · `b.css` · `c.css`: `../site.css` **위에 덮어쓰는** 파일. 토큰·바탕·포인트 부품만. (고른 안을 나중에 site.css 에 합친다)
- `a-landing.html` · `a-home.html`, `b-…`, `c-…`: `../landing.html` · `../home.html` 의 마크업을 복사해 `../site.css` + 해당 안 CSS 를 링크. 포인트에 필요한 마크업만 조금 바꾼다.
- `index.html`: 세 안을 나란히 고르는 목록(각 안 한 줄 설명 + 두 페이지 링크).

## 지킬 것

- 문구는 그대로(사실 확인을 거친 문구다). 새 문구를 쓰면 `../_brief.md` 「문구 한계」를 지킨다.
- 대비 4.5:1 이상(형광 강조는 글자 뒤 면으로만 쓰고 글자색으로 쓰지 않는다), 16px 미만 글자 없음, 포커스 표시, 1440px·390px 가로 넘침 없음.
- 외부 이미지·폰트는 Pretendard(cdn.jsdelivr.net)만. 고정폭 숫자가 필요하면 시스템 고정폭 글꼴 또는 Pretendard 의 tabular-nums.
