- `pay-method.html` 결제 수단 고르기 (라디오로 카드·간편결제 / 무통장 두 상태 확인)
- `pay-va-issued.html` 입금해 주세요 (계좌·금액 복사, 남은 시간, 선물 상세 상태 줄 미리보기)
- `pay-refund-account.html` 환불 받을 계좌 입력

스스로 정한 것
- 선택지는 위아래 두 칸이고, 고른 쪽만 아래로 펼친다. 선택 표시는 짙은 회색 2px 테두리(하늘색은 면에만).
- 입력칸 테두리는 흰 바탕 3:1 을 넘기려고 회색 500 을 쓴다. 남은 시간 막대는 하늘색 면 + role=progressbar.
- 입금 안내의 이름-값 줄, 크리에이터 정보 줄은 위아래로 쌓는다(좌우 카드 없음). 새로 만든 글자는 휴대폰 390 에서 한 줄로 쌓인다.
- 예금주 「팬꾹(토스페이먼츠)」·은행 목록·계좌번호·금액은 더미다. 실제 값은 토스 응답에서 온다.
- 홈 「이렇게 도착해요」는 처음 한 번 위아래 4단계 + 「알겠어요」, 그 뒤에는 한 줄 링크로 보였다.
