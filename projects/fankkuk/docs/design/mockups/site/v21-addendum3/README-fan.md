# 팬 화면 시안 (추가 요청 3) — fan-*

파일: fan-home · fan-profile-edit · fan-account-settings · fan-unfollow-modal · fan-gift-register-step · fan-gift-status · fan-action-center (.html), 공통 fan-21.css · fan-shell.js. 사이드바·글꼴·색은 ../v20-rebrand 를 상대 경로로 불러온다.
스스로 정한 것 ① 홈: 프로필이 페이지 머리 자리라 h1 은 닉네임, 「이렇게 도착해요」는 접힘이 기본(?first=1 이면 처음 방문처럼 펼침+「다시 보지 않기」), 광고 배너·새 크리에이터 격자는 뺌. ② 「추가 조치」 이름은 「해야 할 일」(사이드바 「내 활동」 묶음, 숫자 뱃지 2).
③ 프로필 수정: 닉네임(1~12자, 사용 가능 표시)도 이 화면에 둠. 계정 설정: 비밀번호·휴대폰·탈퇴는 「바꾸기」를 눌러야 펼침, 탈퇴만 빨강 글자·테두리. ④ 팔로우 취소 창: 열면 「계속 팔로우」에 초점, Tab 은 창 안에서만, Esc·바깥 누름으로 닫고 누른 버튼으로 복귀. 닫힘/열림은 위 「시안 보기」 버튼이나 ?modal=open.
⑤ 선물 정보 단계: 종류·상자 크기 아래에 「나만 보는 메모」 한 덩어리(이름·내용 모두 선택, 가격·종류는 더미). ⑥ 선물 상세·해야 할 일: 상자마다 「지금 → 다음」 한 줄, 송장번호는 접힘, 알림 한 줄은 「시안 보기」로 있음/없음 확인. 해야 할 일 카드는 위아래 한 줄씩, 빈 상태는 토글.
공통: 선택·초점은 짙은 회색, 하늘색은 면에만, 입력 칸 테두리는 회색 4.8:1로 올림. 실측(1440·390): 가로 넘침 0, 글자 대비 4.5 미만 0, 콘솔 오류 0. 「시안 보기」 점선 상자는 시안 전용이라 구현에 옮기지 않는다.
