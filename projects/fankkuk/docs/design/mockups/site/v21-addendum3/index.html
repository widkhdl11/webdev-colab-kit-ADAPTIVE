시안 v21 — 추가 요청 3

줄 끝 「폭」은 2026-10-15 본문 폭 규칙(넓게 1200 · 가 880/720 · 두 단)이에요. 두 단은 본문 영역 1000 이상에서만, 좁으면 칸이 위로 쌓여요.

PC 와 휴대폰 폭 모두 같은 파일입니다. 브라우저 폭을 줄이면 휴대폰 모양이 됩니다. 점선 「시안 보기」 상자는 상태를 바꿔 보는 시안 전용 버튼입니다.

팬 쪽

  1. 홈 — 위 프로필 구간 · 폭: 가 880
  2. 프로필 수정 · 폭: 가 720
  3. 계정 설정(보안·개인정보·알림) · 폭: 가 720
  4. 팔로우 취소 확인 창 · 폭: 창
  5. 선물 보내기 — 선물 이름·내용 · 폭: 단계 입력(틀 밖)
  6. 보낸 선물 상세 — 진행 상태 한 줄 · 폭: 가 880
  7. 해야 할 일(추가 조치) · 폭: 가 880

크리에이터 쪽

  1. 홈 — 위 프로필·팬덤 뱃지 · 폭: 가 880
  2. 프로필 수정 · 폭: 가 720
  3. 상세 설정 — 팬마크·팬컬러·퍼스널 컬러 · 폭: 가 720
  4. 팬이 보는 크리에이터 페이지 · 폭: 공개 페이지 별도 틀
  5. 보낸 역조공 — 진행 상태 한 줄 · 폭: 두 단 880 + 요약 칸
  6. 해야 할 일(추가 조치) · 폭: 가 880
  7. 처리할 일 B안 — 늦은 상자 몫마다 찾기 · 폭: 가 880
  8. 처리할 일 C안 — 상태별 창(도착하지 않았어요 · 미확인 상자) · 폭: 가 880
  9. 처리할 일 D안 — 할 일 줄(종류·문장·버튼), 가/나 비교 · 폭: 가 880
  10. 선물 현황 — 진행 중인 받는·보내는 선물 · 폭: 가 880
  11. 계정 설정 · 폭: 가 720
