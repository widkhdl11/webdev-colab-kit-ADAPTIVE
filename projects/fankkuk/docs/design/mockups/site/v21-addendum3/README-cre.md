# v21 추가분 3 — 크리에이터 화면 시안 (cre-)

파일: cre-home · cre-profile-edit · cre-detail-settings · cre-public-page · cre-revgift-sent · cre-action-center · cre-account-settings (.html), 공통 cre-21.css · cre-21.js. 색·글꼴·사이드바는 v20-rebrand C안과 v19 사이드바를 그대로 불러온다. 해야 할 일 화면은 주소 끝 #empty 로 빈 상태를 본다.

스스로 정한 것
1. 「해야 할 일」은 사이드바 「기본」 묶음의 홈 바로 아래 — 받기·보내기 양쪽에 걸친 일이라 어느 한쪽 묶음에 넣기 어렵고, 숫자 뱃지가 맨 위에서 먼저 보이게 하려고. 없으면 뱃지도 사라진다.
2. 「내 팬꾹」 묶음은 꾸미기·프로필 수정·상세 설정으로. 주소 관리는 상세 설정(주소와 설정) 안으로 합쳤다. 계정 설정은 아래 계정 메뉴에 둔다.
3. 홈은 프로필 구간이 본문 맨 앞이라 h1 은 공개 이름이다(제목 「홈」 생략). 뱃지 글자는 흰색·#111827 중 대비가 큰 쪽.
4. 프로필 수정은 위쪽 머리 모양이 곧 미리보기다. 보낸 역조공의 송장번호 칸은 묶음마다 접힌 칸 하나.
5. 보낸 역조공의 「늦어지고 있어요」는 상태 글자일 뿐이고, 입력 칸은 해야 할 일 화면에만 있다.
