# 공통(v6.css)에서 바뀐 것

v5-coral의 v5.css와 v6.css, 같은 이름의 HTML 27개를 비교했다. 아래의 ‘왜’는 변경된 표현이 화면에서 하는 역할을 설명한다.

- 옅은 코랄로 채웠던 바로가기 카드 → 흰 바탕과 얇은 안쪽 테두리로 바꾸고, 마우스를 올렸을 때만 옅은 코랄이 된다. 카드가 차지하는 색 면적을 줄이고 클릭할 곳은 구분한다.
- 주 버튼의 짙고 넓은 그림자 → 더 작고 옅은 그림자로 줄였다. 아래 거리 6→4px, 흐림 16→12px, 불투명도 24→16%로 조정해 버튼의 강조를 가볍게 했다. 선택 상태 버튼은 얇은 경계로 표시한다.
- 현재 메뉴와 선택한 탭의 표시 → 옅은 배경과 짙은 글자로 정리했다. 탭에는 안쪽 테두리도 넣어 선택 여부를 구별하고, 데스크톱의 내 정보 메뉴에도 선택 배경을 적용했다.
- 크기가 제각각이던 안내·요약 상자의 모서리 → 주로 20px로 맞췄다. 큰 패널은 32px, 입력용 큰 카드는 데스크톱 32px·모바일 24px 기준을 적용해 용도가 비슷한 상자끼리 형태를 맞췄다. 이미 이 값이던 곳은 유지된다.
- 로고 주변 간격과 크기 → 상단 로고는 기본 36px·모바일 32px, 하단 로고는 32px로 맞추고 글자 간격과 줄 높이를 조정했다. 하단은 흰 배경을 명시하고 저작권 문구를 보조색으로 낮춰 본문보다 덜 두드러지게 했다.
- 제목·태그·구간 사이의 간격 → 구간 제목 아래 16px, 첫 화면 바로가기 위 24px로 정리했다. 태그 좌우 여백은 8px, 줄 높이는 1.5로 맞췄다. 큰 제목에는 줄 길이를 고르게 나누는 설정을 추가하고, 모바일의 내 정보 제목 줄은 필요하면 줄바꿈하도록 했다.
- 주소 보호와 승인 안내 → 짙은 본문색, 옅은 코랄 배경, 방패 아이콘을 함께 사용하도록 정리했다. 강조색만으로 눈길을 끌던 문구를 하나의 안내 영역으로 읽히게 했다.

모든 HTML은 공통 CSS 연결을 v6.css로 바꾸고 화면별 이름을 body에 붙였다. 화면별 조정도 대부분 HTML 내부 스타일이 아니라 이 공통 CSS에서 적용한다.

## 랜딩 — landing.html

주소 보호 문구만 있던 첫 화면 → 방패 아이콘이 있는 옅은 코랄 안내 상자로 바뀌었다. 아래의 주소 보호 설명 제목에도 같은 아이콘을 넣고 강조 글자를 본문색으로 맞춰 두 안내가 같은 약속임을 보여 준다. 바로가기 카드는 흰 바탕으로, 큰 설명 패널의 모서리는 32px로 정리했다.

## 메인 — home.html

옅은 코랄 바로가기 카드 → 흰 카드와 얇은 경계로 바뀌었다. 인사말 아래 카드 간격과 목록 제목 아래 간격을 정리해 검색·바로가기·진행 중인 선물을 구분하기 쉽게 했다.

## 팬꾹 소개 — about.html

큰 설명 패널의 모서리 → 32px로 맞추고 열람 기록 영역의 흰 배경을 명시했다. 설명과 기록을 담는 상자의 표현을 공통 기준에 맞췄다.

## 로그인 — login.html

상단 아이콘 상자 104px·이미지 72px → 각각 88px·64px로 줄였다. 장식이 입력칸과 로그인 버튼보다 과하게 눈에 띄지 않도록 했다.

## 회원가입 — signup.html

기존 3단계 입력 카드 → 구조를 유지하면서 공통 버튼의 그림자와 제목 표현을 적용했다. 카드 모서리는 기존 데스크톱 32px·모바일 24px 값을 유지해 다른 입력 화면과 일관되게 보인다.

## 크리에이터 찾기 — creators.html

기존 검색·목록 화면 → 구성은 그대로 두고 공통 헤더·버튼·태그 표현을 적용했다. 이 화면만의 별도 배치 변경은 없다.

## 크리에이터 페이지 — creator.html

프로필과 아래 내용이 이어지던 부분 → 얇은 구분선과 아래 여백 32px를 추가했다. 주소 보호 안내는 일반 목록 항목에서 방패 아이콘이 있는 옅은 코랄 상자로 바꿔 찾기 쉽게 했고, 요금 안내 모서리는 28→20px로 정리했다.

## 선물 보내기 — send.html

구간 결정·승인 시간 안내 → 방패 아이콘을 붙이고 왼쪽에 아이콘 자리를 마련했다. 안내와 보조 설명은 짙은 본문색으로 읽기 쉽게 했으며, 요약 상자의 모서리는 28→20px로 줄였다. 입력 단계와 이전·다음 이동은 유지했다.

## 내 정보 — my-info.html

왼쪽 메뉴의 현재 위치 표시 → 짙은 글자와 데스크톱의 옅은 선택 배경으로 정리했다. 개인정보 입력·수정 구성은 그대로 두고 현재 보고 있는 메뉴를 구별하게 했다.

## 팔로우한 크리에이터 — my-following.html

메뉴 선택 표시와 제목 아래 간격 → 공통 기준으로 맞췄다. 모바일에서는 제목 줄의 항목이 줄바꿈할 수 있게 해 좁은 화면에서도 여백을 확보했다.

## 선물 내역 — my-gifts.html

선택 탭 → 옅은 배경·짙은 글자·얇은 안쪽 테두리로 표시한다. 내 정보 메뉴와 제목 간격도 함께 정리해 현재 메뉴와 현재 목록 상태를 구분한다.

## 받은 역조공 — my-revgifts.html

선택 탭과 메뉴 표시 → 선물 내역과 같은 표현으로 맞췄다. 제목 아래 간격과 모바일 줄바꿈을 정리해 상태별 목록을 일관되게 읽도록 했다.

## 역조공 받기 — revgift-receive.html

흰 배경의 선물 안내 카드 → 얇은 경계를 추가하고, 안쪽 정보 칸은 흰색에서 옅은 코랄으로 바꿨다. 보조 버튼에도 옅은 코랄 배경과 경계를 적용해 누를 곳을 구분한다. 보안 안내 모서리는 16→20px, 보조 글자는 짙은 본문색으로 바꿔 안내를 또렷하게 했다.

## 선물 상세 — gift.html

주소 영역의 배경 → 흰색을 명시하고, 결제 안내 상자의 모서리는 28→20px로 줄였다. 주소와 비용을 담는 영역을 공통 카드 표현에 맞췄다.

## 선물 상세·상자 여러 개 — gift-boxes.html

주소와 결제 안내 → 단일 상자 상세와 동일하게 흰 주소 영역과 20px 모서리를 적용했다. 상자 수가 달라도 같은 종류의 정보를 같은 형태로 보여 준다.

## 크리에이터 메인 — creator-home.html

승인할 선물을 담은 상자의 모서리 → 28→20px로 줄였다. 상자 안 안내 줄은 별도의 둥근 상자를 겹치지 않고 아래 여백 16px로 구분해 안내와 할 일을 나눠 읽게 했다.

## 승인 요청 — creator-requests.html

상단 안내 줄 → 여백이 있는 옅은 코랄 상자로 바꾸고 아이콘을 48px로 맞췄다. 선택 탭도 공통 표현으로 정리해 승인 안내와 요청 목록을 구별한다.

## 주소 열람 기록 — creator-log.html

월별 요약 상자의 모서리 → 28→20px로 줄였다. 기록 내용과 목록 구성은 유지하면서 요약 상자의 형태를 다른 화면과 맞췄다.

## 주소와 설정 — creator-settings.html

주소 안내 상자의 모서리 → 28→20px로 줄였다. 주소·차단 목록·프로필 구성은 유지하고 안내 상자의 형태만 정리했다.

## 역조공 보내기 — creator-revgift-new.html

결제 요약 상자의 모서리 → 28→20px로 줄이고, 제한 안내 목록의 아이콘은 본문색으로 맞췄다. 입력 카드의 기존 모서리와 절차는 유지하면서 요약·안내 표현을 통일했다.

## 보낸 역조공 — creator-revgift-list.html

상단 안내 줄 → 옅은 코랄 배경과 여백을 갖춘 상자로 바뀌었다. 아이콘은 48px, 설명은 짙은 본문색으로 맞추고 하단 안내 모서리도 20px 기준으로 정리해 목록 주변 설명을 읽기 쉽게 했다.

## 보낸 역조공·송장번호 — creator-revgift-boxes.html

상단·하단 안내 → 보낸 역조공 목록과 같은 배경·간격·모서리 기준을 적용했다. 송장번호를 보여 주는 기존 구성은 유지하면서 관련 화면끼리 안내 표현을 맞췄다.

## 보낸 역조공 다듬기 — revgift-list-cozy.html

묶음·타일 카드 → 얇은 안쪽 경계를 적용했다. 알약 모양 상태 표시는 모서리 6px의 태그로 바꾸고 완료 상태 글자는 성공색으로 맞춰 카드와 상태 표시의 역할을 구별했다.

## 공지사항 — notices.html

펼친 공지 영역 → 흰 배경을 적용하고 항목 좌우에 데스크톱 16px·모바일 12px 여백을 줬다. 펼친 내용을 목록과 같은 흐름에서 여유 있게 읽도록 했다.

## 고객센터 — support.html

펼친 자주 묻는 질문 → 흰 배경과 공지사항과 같은 좌우 여백을 적용했다. 연락처 상자는 모서리를 28→20px로 줄이고 문의 입력 카드는 모바일에서 24px로 맞춰 질문·문의·연락처의 형태를 정리했다.

## 시안 목록 — index.html

v5 제목과 v4 비교 링크 → v6 제목과 v5 비교 링크로 바꿨다. 화면 링크 카드는 흰 바탕과 얇은 경계로 정리하고 마우스를 올리면 옅은 코랄로 표시해 비교할 화면을 찾기 쉽게 했다.

## 색상과 부품 미리보기 — tokens.html

v5 공통 스타일로 보던 부품 → v6 공통 스타일을 연결해 현재 버튼·태그·제목 표현을 확인하도록 했다. 색상 견본과 부품 구성은 그대로다.

## 바꾸지 않은 것

- 기본 색상 값과 코랄 중심의 색상 체계, 글꼴, 화면의 큰 배치와 구성은 유지했다. 색상 자체를 새로 정한 것이 아니라 기존 색을 쓰는 위치와 면적을 조정했다.
- 시안 목록의 버전·비교 문구를 제외한 본문 문구, 기존 이미지 경로, 로고 도형, HTML 안의 스크립트는 유지했다. 새로 추가된 방패 아이콘은 안내를 보강하는 장식이다.
- 회원가입·선물 보내기의 단계, 입력 항목, 상태 전환과 기존 동작은 바꾸지 않았다.
- 이번 정리 작업에서는 HTML과 CSS를 추가로 수정하지 않았다.
