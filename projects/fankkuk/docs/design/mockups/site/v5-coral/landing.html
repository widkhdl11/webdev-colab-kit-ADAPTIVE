네 걸음으로 전해져요

팬은 사무실로 보내고, 크리에이터는 승인만 하면 돼요.

  1. 1. 등록

    선물을 등록해요

    선물 정보와 상자 수를 적고 결제해요.

  2. 2. 승인

    크리에이터가 승인해요

    건마다 직접 승인해요. 승인 뒤에야 사무실 주소가 열려요.

  3. 3. 검수

    사무실에서 검수해요

    원래 송장을 떼어 파쇄하고 겉면을 검사해요.

  4. 4. 배송

    팬꾹이 대신 보내요

    검수가 끝난 선물만 출고해요.

주소를 열지 않습니다

승인한 선물만 사무실 주소가 열려요. 크리에이터의 주소는 팬에게 보이지 않아요.

크리에이터로 가입하기

주소는 승인된 건만 열려요

주소는 암호화해 보관하고, 승인된 건의 송장을 출력할 때만 열어요.

연 기록을 전부 보여 드려요

언제, 어느 주문의 주소를, 누가 열었는지 크리에이터가 확인할 수 있어요.

추적 장치 검수는 기본이에요

모든 상자의 송장을 떼고 겉면을 검사해요. 걸린 상자만 열어 확인해요.

한 건씩 카카오톡으로 서명해요

전체 승인 버튼은 없어요. 거절 이유는 팬에게 알리지 않아요.

상자마다 검수까지 담았어요

배송비를 포함한 금액이에요. 크기와 무게 중 큰 쪽으로 정해져요.
