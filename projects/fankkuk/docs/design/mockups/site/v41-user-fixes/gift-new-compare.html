바뀌는 것

  1. PC — 오른쪽에 따라오는 「보낼 선물」 칸받는 크리에이터 · 선물 종류 · 상자 크기별 개수와 금액 · 합계(32) · 검수 포함. 상자 수를 바꾸면 그 자리에서 합계가 바뀌고, 화면을 내려도 위에 붙어 따라와요. 1단계부터 4단계까지 같은 자리에 있어서 단계를 넘겨도 화면 폭이 흔들리지 않아요.
  2. 휴대폰 — 3단계에서만 화면 아래 합계 줄「상자 3개 · 소형 1 · 중형 2」와 합계를 한 줄로. 상자를 고르는 동안 화면 아래에 붙어 있어요. 4단계에는 결제 칸에 금액 줄이 그대로 있어서 띄우지 않아요. 팬에게 보내기 화면의 아래 결제 띠와 같은 방식이에요(design-rules 25절).
  3. PC 4단계 — 금액 줄은 오른쪽 칸에만같은 합계가 두 군데 나오지 않게 가운데 결제 칸에는 「검수 포함」·동의·결제 버튼만 남겨요. 휴대폰 4단계는 지금 그대로예요.
  4. 문구 「배송비」 → 「택배비」3단계 설명과 결제 칸 아래 줄. 용어집 6절이 팬 화면에서 「배송비」를 쓰지 않는 말로 정해 두었어요.

정해 주실 것

  • 오른쪽 칸을 언제 보일까요? ① 1~4단계 모두 추천 ② 3·4단계만① 은 쇼핑몰 주문서에서 흔한 방식이고, 단계를 넘겨도 입력 칸 폭이 그대로예요. ② 는 1·2단계 화면이 지금과 같지만 3단계로 넘어갈 때 입력 칸이 좁아져요. 승인된 기준(design-rules 25절 「1~3단계에 오른쪽 요약 칸을 새로 두지 않는다」)을 이번 지시로 바꾸는 것이라, 승인되면 그 줄을 고쳐요.
  • 휴대폰 아래 줄에 「다음」 버튼도 넣을까요? ① 합계만 추천 ② 합계 + 「다음」① 은 지금 버튼 자리를 그대로 둬서 바뀌는 게 적어요. ② 는 손가락이 닿기 쉽지만 같은 버튼이 두 군데 생겨요.
