선물 상세 /gifts/{주문번호} — 결제 끝 · 승인 전

「먼저 보내기」를 눌러 팬꾹 주소가 보이는 때가 기본이에요. 이름·번호·날짜는 예시예요.

선물 보내기선물 상세

바뀌는 것

  1. 승인 전이라는 표시를 맨 위에지금은 상태 판 배지가 「보내 주세요」 하나뿐이고, 승인 상태는 회색 「주문 정보」 카드 맨 아래 「출고 전에 받아요」 한 줄이었어요. 바꾼 뒤에는 배지 옆에 「모모님 승인 대기」, 6단계 막대의 「출고」 아래에 「승인 필요」를 붙여 승인이 출고 앞에 필요하다는 게 막대만 봐도 보여요.
  2. 「모모님의 승인 상태」 표선물 정보 카드 안에 노란 칸 하나 — 지금(승인 대기) · 필요한 때(출고 전) · 기한(결제하고 7일, 10월 31일 (토)까지). 기한은 7일 안에 승인하지 않으면 돌려보내는 규칙(승인 스펙 INV-S6)에서 나온 날짜예요. 상자 카드 위 「승인은 출고 전까지만 나면 돼요」 문장은 이 표로 옮겨서 뺐어요.
  3. 팬꾹 주소 6자리를 따로 큰 칸으로지금은 긴 주소 끝에 붙은 20 글자라 눈에 안 띄었어요. 바꾼 뒤에는 「팬꾹 주소 6자리」 이름표 + 글자 한 자씩 흰 칸(32) + 「6자리 보기/가리기」 버튼. 주소 줄 끝의 6자리에도 테두리를 둘러 「이 글자가 저 칸」이라는 게 보여요. 「주소 한 번에 복사」를 주 버튼(하늘)으로 올렸어요.
  4. 주문번호를 상자 이름에서 빼기지금 상자 줄 「FC-R2D8Q-1 · 소형 상자」는 주문번호가 상자 이름처럼 보여서, 바로 아래 6자리와 같은 종류의 코드로 읽혔어요. 바꾼 뒤 상자 이름은 「상자 1 · 소형」. 주문번호는 선물 정보 카드의 「주문번호」 줄에만 보통 글자로 나와요(상태 판 위 줄에서도 뺐어요). 이름표·자리·모양이 셋 다 달라요.
  5. 결제·주문 정보를 「선물 정보」 카드 하나로받는 크리에이터 · 선물 · 상자 크기와 개수 · 주문번호 · 등록 → 승인 상태 → 결제(상자별 금액·결제 금액·검수 포함·취소하기). 내가 보낸 선물의 내용이 한 곳에 모여요. 휴대폰에서는 상자 카드 아래에 와요.
  6. 문구 「구간」 → 「상자 크기」결제 칸의 「재어 보니 구간이 더 크면」. 용어집 6절에서 「구간」은 운영자 화면 말이에요.

정해 주실 것

  • 팬꾹 주소 6자리를 처음부터 보여 줄까요? ① 지금처럼 가려 두고 「6자리 보기」로 열기 추천 ② 처음부터 보이기① 은 받는 주소 스펙(INV-C2 「기본은 가려 두고 눌러야 보인다」 — 화면 공유·어깨 너머로 새지 않게) 그대로라 스펙을 고치지 않아요. 큰 칸이 생겨서 가려져 있어도 「여기에 6자리가 있다」는 건 보여요. 「주소 한 번에 복사」는 가려져 있어도 6자리까지 복사돼요. ② 는 한눈에 보이지만 스펙을 고쳐야 하고, 방송 화면 공유 중에 6자리가 노출될 수 있어요. 시안은 상자 1을 연 모습, 상자 2를 가린 모습으로 그렸어요.
  • 노란 승인 칸 ① 노란 칸으로 띄우기 추천 ② 다른 줄과 같은 흰 표「한 화면에 강조 하나」(design-rules 21절) 기준에서 하늘 면은 상태 판과 주소 칸이 쓰고 있어요. 노란색은 사이트가 「승인 대기」 배지에 이미 쓰는 기다림 색이라 새 강조색이 아니에요. ② 는 더 차분하지만 「잘 안 보인다」는 지적이 다시 나올 수 있어요.
