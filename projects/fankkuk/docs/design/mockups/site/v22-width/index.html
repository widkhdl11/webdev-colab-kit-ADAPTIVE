본문 폭 비교 (v22)

문구·데이터는 v21 그대로이고 폭·배치만 다릅니다. 사이드바 펼침(240) 기준으로 1440·1920·390 에서 열어 보세요.

보낸 역조공 (목록형)

  • 지금 — 제목·해야 할 일 줄·목록 모두 최대 1200 한 폭
  • 가 — 목록형 본문 880, 제목도 같은 기둥, 사이드바 뺀 영역 가운데
  • 가+나 — 880 + 오른쪽 요약 칸 288 (본문 영역 1200 이상, 좁으면 요약이 위)

계정 설정 (입력형)

  • 지금 — 입력 기둥 720, 본문 왼쪽에 붙음
  • 가 — 720 기둥을 본문 영역 가운데로
  • 가+나 — 720 + 오른쪽 목차 칸 280 (스크롤 따라 붙음, 좁으면 목차가 위)
