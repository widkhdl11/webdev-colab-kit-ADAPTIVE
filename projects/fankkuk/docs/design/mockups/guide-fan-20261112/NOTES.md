## 1. 결론: 화면 구조와 요소의 역할

화면 종류는 **문서형**(6-4). 한 열 글 680을 기본으로 하되, 구역마다 내용 성격에 맞는 모양을 골랐다(6-1·8-14).

| 구역 | 모양 | 이유 |
|---|---|---|
| 머리 | 탭 다섯 → 제목·설명 → 핵심 안내(가로 세 칸 흐름) → 검색 | 요약 세 줄은 순서가 있는 흐름이라 가로 세 칸, 칸 전체가 해당 조로 가는 링크(원칙 ④) |
| 1 선물 등록·발송 순서 | 이어지는 세로 단계(번호 원 + 선) | 순서 열 개(5-2) |
| 2 상자별 팬꾹 주소 | 주소 모양 그림(화면 예시) + 점 목록 | 「사무실 주소 끝 6자리」를 글보다 그림이 빨리 전한다(5-1) |
| 3 요금 | 조건 점 목록 + 크기 셋 비교 칸(상자 그림 크기 소·중·대) | 고르는 대상은 카드(8-14). 그림 칸 높이·요금 위치 고정(8-8) |
| 4 보낼 수 없는 물품 | × 표시 줄 · 접수 한도 칸 · 환불 없음 주의 판 | 안 되는 것·한도·결과를 모양으로 가름(4-1, 글자·× 병행 4-2) |
| 5 진행 단계 | 가로 여섯 단계(점 + 선, 휴대폰은 세로) + 점 목록 | 차례로 표시되는 여섯 단계(5-2) |
| 6 선물 거절·반송·환불 | 줄 목록 열네 줄(조용한 번호) | 규칙·안내는 줄 목록(8-14). 내용은 줄이지 않았다 |
| 7 송장번호 비공개 | 약속 한 줄 판(잠금 그림) + 점 목록 | 첫 문장이 이 조의 약속 |
| 8 끝 6자리 누락 | 「닉네임을 썼다면 / 적지 않았다면」 두 갈래 칸 + 착불 반송 주의 판 | 갈래가 글 속에 묻혀 있던 것을 드러냄 |
| 9 차액 결제 | 요청 → 결제 두 단계 + 점 목록 | |
| 10 추가 문의 | 끝 판(하늘 면, 문단 + 글 속 링크) | 지금 그대로(design-rules 28절) |

폭마다 다른 배치(14-8):
- **칸 폭 880 이상(로그인 전 1024~, 로그인 후 1280~)**: 글 680 + 오른쪽 따라오는 목차 200 = 880 선. 지금 읽는 조는 하늘 면 + 굵게(4-3), 「주요」 알약. 위 목차 줄은 숨긴다.
- **879 이하(로그인 전 1023 이하, 로그인 후 1279 이하 포함 390)**: 오른쪽 목차 없음. 지금처럼 화면 위에 붙는 목차 줄(지금 조 · 찾기 · 목차 열기). 본문 글 680 이하 한 열.
- **767 이하**: 가장자리 16, 탭·핵심 안내 칸은 한 줄씩(칸 전체 누름), 요금 칸 가로(그림 왼쪽), 단계 세로, 조 제목 20.
전환 폭 앞뒤(359·360, 767·768, 879·880, 1023·1024)에서 가로 넘침 없음(측정 아래).

## 7. 배치 진단 (6-5)

화면 종류: 문서형. 해당 항목:
- **1)** 조 열 개가 같은 번호 목록으로 연달아 반복 → 구역마다 모양을 달리함(단계·주소 그림·비교 칸·× 줄·가로 단계·줄 목록·잠금 판·갈래 칸).
- **2)** 모든 영역 폭이 같음(글 680, 오른쪽 200 비어 있음) → 넓은 폭에서 오른쪽 200을 따라오는 목차로 사용(680 : 200).
- **5)** 묶음 안·사이 간격 → 16/48로 3배.
- **6)** 줄 목록 모양을 세 영역 이상에 씀 → 줄 목록은 6조 한 곳만, 나머지는 단계·칸·점 목록으로 바꿈.
- 3)·4)는 해당 없음(큰 그림 영역 없음, 첫 읽을 곳 = 핵심 안내).
