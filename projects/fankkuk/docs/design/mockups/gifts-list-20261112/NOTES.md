## 1. 결론 — 화면 구조
화면 종류: **관리형(6-4)** — 위쪽 요약 줄, 아래 목록. 요약은 오른쪽 칸이 아니라 **목록 위**(지시).
위에서 아래로: 머리(「보낸 선물 N」 + 「선물 보내기」 채움 버튼 하나, 설명 한 줄) → **요약 한 줄**(진행 중 · 완료된 선물 · 전달되지 않은 선물, 세 칸 같은 너비·같은 숫자 20) → 「크리에이터별로 보기」 카드 줄(3열, 좁으면 옆으로 넘김) → 탭(진행 중 · 완료) → 선물 카드 2열.
- 요약은 눌리지 않는 표시라 옅은 면(`--surface`) + 칸 사이 선만, 테두리·그림자 없음. 기둥이 600 미만이면 세 줄(이름 왼쪽·숫자 오른쪽).
- 선물은 고르는 대상이라 카드(8-14). 카드 모양·할 일 하늘 면·결제 대기 카드·진행 막대는 지금과 같음.
- 선물 0건이면 요약·크리에이터 줄을 없앰(6-6: 숫자가 없는 영역을 만들지 않음). 안내는 지금 문구와 「선물 보내기 ›」.

## 4. 양보한 원칙
- 9-4(같은 정보 반복): 요약의 「진행 중 N」과 탭의 「진행 중 N」이 같은 수를 두 번 보임. 탭은 지금 동작(분류)이라 지시(동작 유지)에 따라 둠. 줄이려면 요약 칸을 탭으로 합치는 안이 있으나 새 동작이라 하지 않음 — 확인 필요.
- 6-5(1) 같은 구조 3번 이상: 크리에이터 카드(3)와 선물 카드(2열 여러 장)가 모두 카드. 카드 안 내용이 달라(얼굴 큼·최근 선물 / 진행 막대) 그대로 둠. 크리에이터 줄 자체를 접거나 빼는 것은 사용자 승인 필요(2-24).
- 1-2(눈에 띄는 요소 하나): 「선물 보내기」 채움 버튼이 하나, 하늘 면은 할 일이 있는 카드만(지금과 같음).

## 5. 확인 필요 / (가정)
- **요약의 세 칸 구성**은 제안: 진행 중(결제 대기 포함, 탭과 같은 수) · 완료된 선물 · 전달되지 않은 선물(거절·기한 만료). 지금 코드에는 이 세 수가 따로 보이는 곳이 없고 탭의 「진행 중 N」「완료 N」과 완료 안의 두 덩어리 개수에서 나온 값이다. 새 계산 없음.
- 「지금 할 일」(하늘 카드) 수를 요약에 넣는 안은 사이드바 숫자와 겹쳐 넣지 않음.
- 선물 이름·크리에이터·주문번호·날짜는 모두 가짜 값. 사이드바 「지금 할 일 2」는 예시.
- 크리에이터 카드가 1장이면 78% 폭으로 왼쪽에 섬(지금 구현과 같음). 선물 1건이면 2열의 오른쪽이 빔 — 한 장일 때 가운데·넓게 늘리지 않음.
- 구현에 닿는 점: 요약 줄은 새 컴포넌트(`gift-list-page` 안). 데이터는 이미 `ongoing`·`ended`·`notAccepted` 거르기로 구해짐.

## 7. 배치 진단 (6-5) — 관리형
(1) 같은 구조 3번 이상: 선물 카드 2열 연속 → 탭·「완료된 선물」「전달되지 않은 선물」 머리(16 굵게 + 개수)로 묶음을 끊음. 카드 모양은 8-14(고르는 대상)라 유지.
(2) 모든 영역 폭이 같음: 해당 — 요약 면 · 크리에이터 3열 · 선물 2열이 모두 기둥 전체 폭. 열 수(1·3·2)를 다르게 둠. 주·보조 칸 분리(오른쪽 칸)는 지시로 하지 않음.
(3) 큰 영역 아래 같은 크기만: 해당 없음(큰 영역 없음). 요약 줄이 이 자리를 대신하는 작은 정보.
(4) 먼저 읽을 영역: 제목 → 요약 → 첫 카드. 눈에 띄는 것은 「선물 보내기」 하나.
(5) 묶음 안·사이: 카드 안 12~16 / 묶음 사이 32~48. 해당 없음.
(6) 같은 모양 3곳 이상: 요약 면·빈 상태 면·회색 탭 — 면은 옅은 회색 하나로 같으나 역할이 달라(표시·안내·분류) 그대로.

## 8. 현재 화면 대비 (14-7)
1) 더 큰 글자·버튼·사진: 없음(얼굴 56·32, 카드 제목 20, 버튼 48, 탭 44 모두 지금과 같음). 새 요소인 요약은 숫자 20·이름 14.
2) 누를 수 없는 묶음의 테두리·그림자: 요약·빈 상태 면에 없음(빈 상태는 지금 구현의 테두리 그림자를 뺌 — 눌리지 않는 칸). 누르는 카드에만 있음.
3) 한 줄 칸의 너비·글자·아이콘: 요약 세 칸 같음. 크리에이터 카드는 태그 아래에 막대가 늘 같은 줄에 옴(지금은 칸 폭에 따라 한 줄/두 줄로 달라져 「지안」 카드만 한 줄이 되던 것을 세로로 통일 — 고침).
4) 2열 한쪽만 긺: 선물 1건일 때 오른쪽이 빔 — 카드 폭을 지금대로 둠.
5) 떨어진 정보: 진행 중 수가 요약과 탭에 둘(4번 양보).
6) 모양: 고르는 대상 카드 · 요약 표시 면 · 안내 면(8-14).
7) 조작 위치: 「선물 보내기」 머리 오른쪽 끝(지금과 같음), 탭 왼쪽, 카드 전체가 링크.
