팬꾹의 소개

01

선물을 승인하여 받아보세요

팬꾹은 팬이 선물을 보낼 때 마다 승인을 요청해요.

선물에 대한 내용을 먼저 확인하고 받아보세요.

02

크리에이터의 주소를 암호화하여 저장, 팬의 주소는 사용 후엔 폐기 확인 필요: 암호화 저장, 폐기 시점

인증 시스템을 통해 잠시동안만 주소가 보이게 돼요.

팬꾹은 개인 정보의 저장은 최소한으로, 보안은 철저하게, 만일 정보유출이 되더라도 피해가 최소화 될 수 있게 했어요 확인 필요: 안전 보장 표현

03

크리에이터 -> 팬에게 선물을 보낼 땐 팬꾹의 '팬에게 보내기'를 이용하세요.

선물함으로 신청을 한눈에 관리하세요.

팬꾹은 크리에이터가 선물을 보낼 때 '선물함 만들기' 기능을 제공해요.

크리에이터가 선물함을 만들면 팬이 신청을 하고 선물함 마감을 하여 보낼 수 있어요.

신청 현황을 한눈에 쉽게 알아봐요.

팬들에게 보낼 선물, 모아서 보내세요

기존에 팬에게 보낼때는 각각의 선물을 플랫폼을 통해 팬에게 보내거나 별도의 택배서비스를 이용해서 보냈어요.

하지만 그럴경우 높은 이용료(플랫폼 이용의 경우)와 거주지역 노출의 위험성(택배서비스 이용의 경우)이 있어요 확인 필요: 다른 서비스에 대한 서술의 근거

팬꾹은 팬에게 보낼 선물을 큰 상자에 묶음으로 받아 팬꾹에서 직접 분류하여 배송해주는 '팬에게 보내기' 서비스를 제공합니다.

팬꾹을 통해 저렴한 비용으로, 개인정보를 지키면서 마음을 전하세요 확인 필요: 「저렴한 비용」의 비교 대상과 수치

04

나만의 채널 만들기

프로필 사진과 배경 사진, 대표색을 직접 설정할 수 있어요.

팬덤 이름과 뱃지도 등록해 내 채널의 특징을 담아보세요.

05

주고받은 선물과 감사 인사를 남겨보세요

어떤 선물을 주고받았는지, 어떤 감사 인사를 나눴는지 팬꾹에서 다시 볼 수 있어요. 짧은 메시지로 고마움을 전하고 기록으로 남겨보세요.

06

자주 묻는 질문·신뢰 요소

  • 승인 전에는 주소를 열람할 수 없습니다.
  • 주소를 열람할 때마다 기록을 남깁니다.
  • 팬이 보낸 모든 상자를 탐지기로 검사합니다.
  • 선물마다 카카오톡 인증으로 승인합니다.
크리에이터는 선물을 어떻게 승인하나요?
승인 요청이 오면 선물마다 카카오톡 인증서로 서명해 승인해 주세요. 한꺼번에 승인하는 기능은 없습니다. 결제가 끝난 때부터 7일 안에 승인하지 않으면 기한이 지나 받지 않은 선물로 처리됩니다.
크리에이터가 받지 않으면 어떻게 되나요?
크리에이터가 거절하거나 결제 후 7일 이내에 승인하지 않으면 선물은 배송하지 않습니다. 거절 사유는 공개하지 않습니다. • 입고 전·팬꾹 주소 미표시: 전액 환불 • 입고 전·팬꾹 주소 표시: 반송 택배비를 제외한 금액 우선 환불. 결제 후 30일 이내 도착하면 반송하며 추가 환불은 없음. 30일이 지나도 도착하지 않으면 보류한 택배비까지 환불 • 입고 후: 확인한 반송 주소로 보내고, 상자별 결제 금액에서 반송 택배비를 제외해 환불 • 검수 불합격 상자: 환불 금액 없음
크리에이터에게 보낸 상자의 송장번호를 볼 수 있나요?
크리에이터에게 배송하는 상자의 송장번호는 공개하지 않습니다. 배송 조회 시 크리에이터 배송지 일부가 노출될 수 있기 때문입니다. 팬이 선물 상세에 입력하는 번호는 팬꾹으로 보내는 상자의 송장번호입니다.
