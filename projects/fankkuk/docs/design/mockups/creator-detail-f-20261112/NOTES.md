## 출력 형식 (design-prompt 결과물)

### 1. 결론
화면 종류: **프로필 상세형**(6-4) — 위쪽 큰 배경, 아래 주 영역(2) + 보조 열(1). 위에서 아래로: 전체 폭 배경 → **상단 묶음(2:1)** → 여닫는 줄 → 상세 내용(전체 폭 세 줄) → 추천 크리에이터(전체 폭 슬라이드).
- 왼쪽(주) 열: 사진 · 이름·뱃지·채널 · 팬 수 · 기념일 · 칩 · 소개 · 감사 문장 → 아래 24에 「진행 중인 선물함」 타일(이름·소개 글과 같은 왼쪽 선 x 388). 선물함은 프로필의 한 요소(d판 지시 유지).
- 오른쪽(보조) 열: 「팔로우 중」·「선물 보내기」(같은 너비 2개) → 요금·평균 승인 소요 시간(14, 버튼 아래 12) → 받고 싶은 선물(라벨 14/600 + 알약, 「화면 예시」 표시) → 받기 어려운 선물(옅은 하늘 면). 보낼 때 알아야 할 것이 한 열에 모였다.
- 상세 내용(기본 닫힘): 전달 과정(가로 5단계, 소개 문구) → 보내기 전 안내(접는 줄 둘, 보낼 수 없는 물품은 두 열 항목) → 나에게 온 감사 카드(전체 폭 슬라이드).
- **폭마다 바뀌는 곳(14-8)**: 칸 폭 1080(뷰포트 1200 이상) 2:1 두 열 / 칸 폭 879 이하(뷰포트 927 이하) 한 열 — 순서 프로필 → 버튼·요금 → 선물함 → 받고 싶은 선물 → 받기 어려운 선물, 사진 옆 글 열 왼쪽 선에 맞춤(720~879) / 칸 폭 719 이하(휴대폰) 사진이 위, 모든 것이 왼쪽 가장자리 16에서 시작, 전달 과정은 세로 · 선물함 타일·감사 카드·추천 카드는 오른쪽 화면 끝까지 이어짐 · 추천 화살표 없음(손으로 넘김, e판과 같음). 추천 카드 수는 뷰포트 1200 이상 4장 / 768~1199 3장 / 767 이하 2장. 1000 이하 칸에서는 버튼 안쪽 여백 24 → 16(두 버튼이 같은 너비를 유지).

- **12-3 보는 사람이 손대지 않아도 움직이는 것 금지**: 추천 자동 슬라이드는 사용자 지시. 10-4(멈춤 단추 · 올리면 멈춤)·「움직임 줄이기」는 지킴.

### 5. 확인 필요 (5-5)
1. **받고 싶은 선물을 상세 안에서 상단 묶음으로 옮겼다.** 처음에 상세 정보가 닫혀 있어도 보인다. 받기 어려운 선물과 짝이기 때문(14-7 5). 되돌리려면 상세 안 맨 위로 한 줄 이동. 크리에이터 입력 항목 신설(c판에서 올린 것)은 여전히 확인 필요 — 예시 낱말 5개, 비우면 칸째 숨김(「받고 싶은 선물 없을 때」).
2. **요금·승인 시간 위치가 e판 사용자 지시와 다르다.** e판 지시는 「버튼 아래 아무것도 없음 + 요금·승인 시간은 선물함과 같은 높이」였다. f판은 6-5 3(요금은 보내기 버튼 가까이)·14-7 5 를 따라 버튼 바로 아래에 둠. 지시를 그대로 지키려면 요금 줄만 받고 싶은 선물 위 24 아래로 내리면 된다(한 줄 이동).
3. 보내기 전 안내가 닫힌 상세 안에 있다(e판과 같음). 처음 보내는 팬이 닫힌 채 지나칠 수 있다 — CLAUDE.md 문구 규칙 5번과 맞닿는 문제이니 판단 부탁.
4. 나에게 온 감사 카드 영역은 로그인해 팔로우한 팬 + 받은 답장이 있을 때만(e판과 같음). 보는 팬 본인 답장 읽기(공개 읽기 확장)와 선물함 상세 창은 명세(handle.md)와 구현 모두 고칠 일. e판에서 올린 것과 같다.
5. 제목·문구: 기존 e판과 같음. 이번에 새 문구 없음(요소 이름은 e판 그대로).

### 14-7 자기 검토 (캡처로 확인)
1) 글자·버튼·사진 크기: 이름 32 · 버튼 48 · 사진 184 는 운영과 같음. 추천 카드는 e판보다 작게(위 4).
2) 누를 수 없는 묶음의 테두리·그림자: 없음(받기 어려운 선물·감사 카드는 면만).
3) 한 줄 칸 너비·글자·아이콘: 두 버튼 같은 너비(1440 170/170 · 928 137/137), 선물함 타일 128 셋, 전달 과정 5칸 같은 폭. 「대기 2번」 타일만 뱃지 한 줄이 더 있으나 타일 높이는 같다.
4) 2열 한쪽이 비지 않음: 432 대 364 (차이 68, 줄 사이 64 에 흡수).
5) 함께 읽을 정보: 요금 ↔ 버튼, 받고 싶은 ↔ 받기 어려운, 선물함 ↔ 프로필 모두 붙어 있음.
6) 모양과 성격: 선물함 = 카드(타일), 감사 답장 = 글이 주인공인 면, 안내 = 접는 줄, 전달 과정 = 단계 그림, 받고 싶은 선물 = 알약(8-14).
7) 조작 요소 위치: 추천 화살표 본문 밖 양옆(사용자 지시, 넓은 PC만) · 멈춤 단추 제목 줄 오른쪽 · 여닫는 단추 가로 선 가운데 — 모두 e판 확정 그대로. 여닫는 단추는 위·아래 구분선 가운데 알약이 널리 쓰이는 「더 보기」 방식과 다르지 않음.
