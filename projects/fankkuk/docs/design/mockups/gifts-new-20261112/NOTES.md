## 1. 결론 — 화면 구조
화면 종류: **작업형(6-4)** — 한 열 입력 기둥(720) + 오른쪽 「보낼 선물」 칸(288), 합쳐 1040. 본문 칸 880 이상(사이드바 있는 화면에서 폭 약 1184 이상)이면 두 열, 그보다 좁으면 720 한 기둥 + 3단계 아래 합계 줄.

| 항목 | 지금 | 이 시안 |
|---|---|---|
| 1단계 크리에이터 | 한 줄에 한 명(폭 640 줄 5개) | **2열 카드 격자**, 카드 높이 같음, 휴대폰 한 열. 보여 주는 수 5 → 6 (제안) |
| 이전·다음 | 둘 다 오른쪽 | **이전 왼쪽 끝 · 다음(결제하기) 오른쪽 끝**. 휴대폰은 다음 폭 전체, 이전은 그 아래 글자 버튼 |
| 4단계 확인 줄 | 줄 4개 세로 | **2×2**(줄 목록 모양 유지, 수정 누름 칸 44) |
| 휴대폰 단계 판 | 숫자 → 제목 → 설명 → 막대 세로로 쌓임(약 230) | **숫자와 제목 한 줄**로 → 첫 화면에 입력이 더 보임(1-5) |
| 휴대폰 3단계 상자 칸 | 그림·글 아래 −/+ 가 왼쪽 끝에서 시작 | −/+ 가 글 시작선에 맞음 |
| 그대로 | 하늘 단계 판(48 숫자·네 칸 막대), 단계 순서·입력 칸, 「보낼 선물」 칸, 4단계 결제 칸·동의·결제 버튼 글자, 반송 주소 칸 순서(우편번호·기본·상세·받는 사람 이름·휴대폰) |

## 2. 수치
[토큰] 글자 48·24·20·16·14(12는 카드 안 칩), 간격 4·8·12·16·24·32·40, 반경 24(판)·16(카드)·12(버튼·칸)·끝까지(칩), 카드 간격 `--card-gap` 24(휴대폰 16).
[고정] 누르는 칸 44 이상, 글자 대비 4.5:1(큰 글자 3:1). 분기: 본문 칸 880(두 열↔한 기둥) · 입력 판 584(상자 칸 3열↔1열) · 767(휴대폰 단계 판·버튼 배치) · 768(사이드바↔위 막대).

## 3. 근거 번호
1단계 카드 격자 8-14·8-8·6-5 1 / 이전·다음 2-21 3·2-22 / 휴대폰 단계 판 1-5·14-8 / 4단계 2×2 8-14(데이터는 줄 목록)·2-2 / 상자 칸 2-11 / 상태 카드 가운데 정렬 2-17.

## 4. 양보한 원칙
- 1-2(강조 하나): 4단계에 하늘 단계 판과 하늘 결제 칸이 같이 있다. 명세가 단계 판을 「바꾸면 안 되는 것」으로 못박았고 결제 칸은 승인된 모양(design-rules 25절)이라 그대로 둠 → 확인 포인트.
- 9-4(같은 정보 반복): 4단계 확인 줄의 크리에이터·선물 종류가 오른쪽 「보낼 선물」 칸에도 있다. 확인 줄에는 「수정」이 있어 둘 다 둠(명세 승인 사항).

## 5. 확인 필요
- 크리에이터 카드의 이름·태그·승인 시간·팔로우 목록은 모두 화면 예시 값(실존 인물 없음). 결제창의 점선 칸은 토스 위젯 자리 표시.
- 선물 상자 크기·요금(소형 6,900 · 중형 8,900 · 대형 10,900)은 지금 코드의 크기 값과 이전 캡처의 요금표에서 가져온 예시.
- 명세 상태표에 없는 「미리 고르고 왔는데 아직 팔로우 안 함」(코드의 followFirst 안내 칸)은 그리지 않았다.

## 7. 배치 진단 (6-5) — 화면 종류 작업형
① 같은 구조 3번 이상 반복: **해당** — 1단계 한 줄 한 명 5개 → 2열 카드 격자로 바꿈. 3단계 상자 칸 3개는 수량 입력이 달린 한 묶음이라 그대로.
② 모든 영역 폭 같음: 해당 없음(입력 기둥 : 요약 칸 = 720 : 288).
③ 큰 영역 아래 같은 크기만: 해당 없음(단계 판 아래 흰 입력 판 → 입력 칸·카드).
④ 먼저 읽을 영역: 해당 없음(단계 판의 큰 숫자 하나).
⑤ 묶음 안·사이 간격: 해당 없음(카드 안 12·4 / 카드 사이 24, 입력 묶음 안 12 / 사이 32).
⑥ 같은 모양 3곳 이상: 해당 없음(4단계: 줄 목록 = 확인 줄·오른쪽 칸 2곳).
이전·다음 위치(점검표 24·25)는 위 표대로 고침.

## 8. 현재 화면 대비(14-7 자기 검토)
1) 글자·버튼·사진 지금보다 큼: 없음(휴대폰 단계 판 설명 16 → 14, 제목 24 → 20 으로 오히려 작아짐 — 숫자와 한 줄에 넣으려고). 2) 누를 수 없는 묶음의 테두리·그림자: 없음(회색 안내판은 그림자 없이 옅은 윤곽선만 — 지금과 같음). 3) 한 줄 칸의 너비·글자·아이콘: 같음. 4) 두 열 한쪽만 긺: 4단계는 오른쪽 칸이 짧지만 따라오는(sticky) 칸이라 비는 면이 없음. 5) 떨어진 정보: 금액은 오른쪽 칸 하나(휴대폰은 결제 칸 안). 6) 모양: 고르는 대상 = 카드, 확인 = 줄 목록, 안내 = 회색 판. 7) 조작 위치: 이전 왼쪽·다음 오른쪽(표준).
