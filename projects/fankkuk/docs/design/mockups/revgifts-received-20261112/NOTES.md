# 받은 선물 `/me/revgifts` — 둘러보기형 시안 (2026-11-12)

열기: http://localhost:4322/docs/design/mockups/revgifts-received-20261112/index.html (상태는 위쪽 도구 줄 또는 주소 끝 `#list #past #empty #ongoing0 #past0`)
UX 명세(`docs/ux/pages/`)는 이 화면에 없어서 지금 구현(`my-revgifts-panel.tsx`)이 가진 상태를 그대로 그렸다. 상태 5개: 받는 중 여러 건 · 완료 여러 건 · 받은 선물 없음 · 받는 중 없음 · 완료 없음. 불러오는 중(`loading.tsx` 의 공용 뼈대 화면)은 이 화면 고유 모양이 아니라 그리지 않았다.
기준 크기: 글자·버튼·칸은 지금 구현에서 그대로, 더 키운 곳 없음(14-7).

## 1. 결론 — 화면 구조
화면 종류: **둘러보기형(6-4)**. 본문 틀은 지금 구현과 같은 목록형 `--col-list`(880).

- **그 밖**: 왼쪽 상태 문구(「상자 준비 후 발송」 등 지금 코드 문구), 오른쪽 화살표. 카드 전체가 선물 상세 링크.

## 4. 양보한 원칙
- **1-2 강조 하나**: 판(하늘)과 수락 대기 카드(하늘)가 한 화면에 같이 보인다. 판은 시안 지시(creators-r2 방식), 수락 대기 카드는 design-rules 21절 승인 모양이라 둘 다 두었다. 대안: 수락 대기 카드를 흰 카드 + 채움 단추로만 구분.

## 5. 확인 필요 (5-5)
- 탭을 필터 줄 「알약」 모양으로 바꿈(지금은 밑줄 탭). 동작·숫자·이름은 같고 키보드 좌우 이동도 같다. 사이트 다른 화면의 탭이 밑줄 모양이라 어긋나는지 확인 필요.
- 지금 수락 대기 카드의 얼굴은 64(강조 칸) · 그 밖 줄은 48 이었다. 카드 한 줄의 칸을 같게 하려고(2-6) 모두 48 로 통일, 이름 글자도 20 → 16. 남은 날 숫자는 48 → 32.
- 지금 구현의 「하루 이하 남음」 급함 표시(`urgent`)는 화면에 쓰이지 않아 그리지 않았다(1일 남음 카드도 같은 모양).
- 크리에이터 이름·주문번호·날짜는 화면 예시 값. 상태 문구·뱃지 이름은 지금 코드(`received-status.ts`)의 것.
- 코드에는 상태 8종(수락 대기·수락 완료·출고 완료·받지 않음·기한 만료·반송 완료·처분 완료·취소)이 있고 시안에 모두 나온다.

## 7. 배치 진단 (6-5) — 둘러보기형
- ① 같은 카드 연속 3번 이상: **해당, 일부만 풀림.** 대표 카드를 크게 두기는 순위 기준이 없어 안 함(11-1). 대신 데이터 사실로 모양을 가른다 — 「받을지 정해야 하는」 카드는 하늘 면 + 남은 날 + 단추가 있고 맨 앞에 모이므로, 반복이 하늘 카드 2장 → 흰 카드로 끊긴다. 완료 탭 5장은 모두 같은 자격이라 반복이 남는다(양보).
- ② 모든 영역 폭 같음: 해당 없음(판 880 전체 · 카드 2열은 폭이 같지만 판과 격자가 다른 모양).
- ③ 큰 영역 아래 같은 크기만: 판 바로 아래 카드. 판이 낮고(약 129) 카드와 모양이 달라 문제 없음. 결과 개수 줄은 탭에 숫자가 이미 있어(9-4) 만들지 않았다.
- ④ 먼저 읽을 영역: 해당 없음(수락 대기 카드가 앞).
- ⑤ 묶음 안·사이 간격: 해당 없음(카드 안 16 / 카드 사이 24 / 판↔격자 32).
- ⑥ 같은 모양 3곳 이상: 해당 없음.
- 6-4: 한 열로만 쌓이지 않음(판 안 2열 + 격자 2열). 880 화면은 칸이 좁아 1열이 되지만 지금 구현의 틀 폭 때문이다.

## 8. 현재 화면 대비 (14-7)
1) 글자·버튼·얼굴이 지금보다 큼: 없음(이름 20 → 16, 얼굴 64 → 48, 숫자 48 → 32, 확인하기 단추 44 로 지금 `.btn` 48 보다 작음. 제목 24 · 탭 16 · 설명 14 는 같음). 2) 누를 수 없는 묶음의 테두리·그림자: 판에 없음. 수락 대기 카드는 누르는 칸이 아니라 단추만 누르므로 하늘 면 + 윤곽선만(그림자 없음). 3) 한 줄 칸의 너비·글자·아이콘: 같음(수락 대기 카드 아래 줄만 단추가 있음 — 상태가 달라서). 4) 2열 한쪽만 긺: 없음(줄마다 높이를 같게). 5) 떨어진 정보: 남은 날과 기한을 한 묶음으로, 상태 뱃지는 이름 바로 아래. 6) 고르는·확인하는 대상 = 카드(8-14), 줄 목록 아님. 7) 탭 위치: 제목 오른쪽(필터 줄 관례).
