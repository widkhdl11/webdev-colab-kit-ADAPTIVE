주소 공개 없이 전하는 선물

크리에이터가 승인한 선물만 배송합니다.

  1. 팬꾹 주소
    01

    선물 등록·결제

    결제 후 상자별 팬꾹 주소가 발급됩니다. 승인 전에는 ‘먼저 보내기’로 주소를 확인할 수 있습니다.

  2. 02

    크리에이터 승인

    크리에이터가 승인한 선물만 배송합니다.

  3. 03

    팬꾹 검수

    팬이 보낸 모든 상자를 검사하고, 탐지기에 반응한 상자는 개봉해 확인합니다.

  4. 04

    크리에이터에게 배송

    승인과 검수가 완료된 선물을 출고합니다.

  2. 입고
  3. 검수
  4. 출고
  5. 배송 중
