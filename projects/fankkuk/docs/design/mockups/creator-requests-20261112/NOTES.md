## 1. 결론 (화면 구조와 요소의 역할)

화면 종류: **관리형**(6-4) — 위쪽 요약, 아래 목록.

- 머리: 「승인 내역 N건」(제목 32, 휴대폰 24). 지금과 같음.
- 요약: 「처리한 요청」 + 오른쪽 「최근 처리일」, 그 아래 결과별 건수 넷. **승인 하나를 크게(32), 거절·기한 만료·차단은 같은 크기(20)** 로 둔다. 칸마다 결과 태그(점+글자+색)와 숫자.
- 목록: 달마다 묶고(월 제목 + 건수) 그 아래 **표**. 열: 팬 · 선물 종류 · 상자 · 주문번호 · 결과 · 처리일 · 「승인 취소」 칸. 상자·처리일은 오른쪽 정렬(열 제목도 같은 쪽).
- 맨 아래: 「승인 기한 만료」 「팬 차단」 접기(지금과 같음, 해당 건이 있을 때만).
- 「승인 취소」 확인 창 모양·문구는 지금 BottomSheet 그대로(PC 480 중앙 창, 휴대폰 아래 시트).

## 3. 근거 (요소별 원칙)

- 요약 승인 크게 + 나머지 셋: 1-2(눈에 띄는 요소 하나), 6-5-3(같은 종류 숫자 2~3개는 칸 너비·크기 같게), 3-3.
- 요약에 테두리·그림자 없음: 4-6·14-7(2) — 누르는 칸이 아니므로 여백으로만 나눔.
- 표 모양·열 제목·숫자 열 오른쪽: 8-14(비교·처리할 데이터), 2-18, 6-4.
- 줄 오른쪽 끝에 「승인 취소」: 2-21(11). 휴대폰은 글 아래 같은 왼쪽 선(2-21(10), 2-9)에 두고 글자 왼쪽 끝이 맞도록 안쪽 여백 8만큼 당김(2-8).
- 상태: 태그가 색·글자·점 모두 가짐(4-1·4-2). 결과 칸이 없는 줄에도 「승인 취소」 칸을 비워 둬 열이 줄마다 같은 자리(2-6).
- 확인 창: 2-17·2-19(왼쪽 정렬), 2-21(6)(버튼 반씩, primary 오른쪽), 8-7.
- 빈 상태: 2-17(메시지 하나·한 줄), 면은 테두리 없는 옅은 회색.

## 4. 양보한 원칙

- **폭을 넓힘(880 → 1200)**: 표 7열을 한 줄에 두려면 880 이 모자람. 반대로 2-9(정렬선 하나)는 지킴 — 제목·요약·월 제목·표·접기가 모두 왼쪽 같은 선.
- 요약 숫자는 4개(6-5-3 은 2~3개 권장): 승인을 대표로 크게 하고 나머지 셋만 같은 크기로 둬 「같은 종류 2~3개」 규칙에 맞춤.
- 「처리한 요청 N건」 큰 숫자 칸은 뺐다(9-4: 제목 옆 「N건」과 같은 정보).

## 5. 확인 필요

- **명세와 이름 차이**: 요청은 「신청 현황·칩(상태 거르기)」이지만 지금 `/creator/requests` 에는 거르기 칩이 없고 결과별 건수 칸(눌리지 않음)뿐이다. 칩은 11-10 「신청 관리」 모달(선물함)의 것으로 보인다. 시안은 지금 화면 구조(건수 칸 = 표시만)를 따랐다. 건수 칸을 거르는 칩으로 바꾸려면 새 동작이라 적용 규칙 6에 따라 제안만 한다(결정 필요).
- 승인 기한 일수·날짜(「11월 17일까지」「7일 이내」)는 가짜 값. 실제는 서버 값.
- 이름·주문번호·선물 종류는 모두 예시.
- 빈 상태에 다음 행동(9-2)이 없다: 지금 화면 문구 「처리한 요청이 없습니다.」 그대로. 행동을 더하면 새 문구라 사용자 확인 필요.

## 7. 배치 진단

정한 화면 종류: 관리형.

- 6-5-1(같은 구조 3번 이상 반복) **해당**: 고치기 전 = 줄마다 「이름 + 메타 한 줄」 줄 목록을 달마다 반복 / 고친 뒤 = 열 제목이 있는 표로 바꿔 비교 가능하게 하고, 달 제목·접기와 모양을 구분. 줄 목록 자체는 8-14(비교·처리할 데이터)에서 허용되는 모양이라 유지.
- 6-5-2(모든 영역 폭이 같다) **해당**: 위 요약 판(반)+288 숫자 칸 → 요약을 승인 2 : 나머지 1 로 폭·크기 차등. 접기는 680(prose) 폭으로 좁혀 표(1120)와 폭을 다르게 함.
- 6-5-3(큰 영역 바로 아래 같은 크기만 이어짐) **해당**: 고치기 전 = 큰 판(숫자 48 + 96 그림) + 같은 크기 회색 칸 4개 / 고친 뒤 = 승인 32, 나머지 20. 정보 없는 장식 그림(검수 아이콘 96)은 뺌(6-6, 5-6).
- 6-5-4(먼저 읽을 영역) 해당 없음: 제목 → 요약 → 목록 순서가 하나로 정해짐.
- 6-5-5(묶음 안·사이 간격 같음) **해당**: 요약 안 16 / 요약↔목록 48, 월 제목↔표 8, 달 사이 48, 접기 앞 48.
- 6-5-6(같은 모양 3영역 이상) **해당**: 고치기 전 = 숫자 칸·월 줄·접기 모두 회색 카드·줄 / 고친 뒤 = 요약 = 여백 위 태그+숫자, 목록 = 표, 접기 = 접는 목록(8-14 규칙·안내).
