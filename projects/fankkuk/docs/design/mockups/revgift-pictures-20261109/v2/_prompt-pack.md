# 새 그림 지시문 — 선물함 3페이지 「담는 법」 (Codex 이미지 생성용)

공통 스타일은 `../../site/v4/img/_style.md` 를 그대로 따른다. 아래는 이 그림 한 장의 내용이다.

파일 이름: `illust-pack-box.png` (512 x 512, 투명 PNG, 정사각형, 가장자리 여백 10%)

공통 스타일
- 부드러운 3D(클레이/플라스틱 느낌), 둥글둥글하고 통통한 형태, 은은한 하이라이트와 아주 옅은 그림자 한 겹. 귀엽지만 유치하지 않게.
- 배경은 투명(PNG, 알파). 검정 윤곽선 없음. 조명 방향은 왼쪽 위, 재질·두께는 `icon-gift.png`·`icon-truck.png`·`icon-inspect.png` 와 같게.
- 색은 하늘색·노랑·분홍·주황 중 2~3색을 섞고 채도는 살짝 낮게. 큰 택배 상자는 따뜻한 크래프트 갈색.
- 글자·숫자·로고·브랜드 마크, 사람 얼굴, 실존 인물·브랜드는 넣지 않는다.

그림 내용
- 뚜껑이 열린 큰 택배 상자 하나를 약간 위에서 내려다보는 각도로 그린다.
- 상자 안에 작은 선물 상자 서너 개가 위로 솟아 보인다(리본이 있는 둥근 상자, 색은 서로 다르게).
- 작은 선물 상자마다 앞면에 빈 흰 쪽지(작은 사각 라벨)가 붙어 있다. 쪽지에는 아무 글자·선·무늬도 없다.
- 큰 상자 앞면에도 글자를 넣지 않는다. 화살표·손·사람은 그리지 않는다.
