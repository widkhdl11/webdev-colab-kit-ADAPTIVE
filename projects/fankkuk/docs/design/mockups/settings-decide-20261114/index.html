계정 설정 — 정할 것 두 가지

1. 받기 설정의 저장 버튼

받기 설정 칸 안에는 선물 받기 · 받기 어려운 선물, 두 구역이 있습니다.

A. 구역마다 저장추천

구역 끝마다 저장 버튼이 있습니다. 고친 구역의 버튼만 채워져서 무엇을 저장할지 보입니다.

B. 맨 아래 버튼 하나

두 구역을 다 고친 뒤 칸 맨 아래 「받기 설정 저장」으로 한 번에 저장합니다. 위쪽만 고치고 저장하지 않은 채 나가기 쉽습니다.

2. 칸 이름 앞 아이콘

계정 설정의 접힌 칸(주소 설정 · 받기 설정 · 차단한 팬 · 보안 · 회원 탈퇴) 이름 앞에 동그라미 아이콘을 둘지입니다.

A. 아이콘 넣기추천

칸이 많아도 모양으로 먼저 찾을 수 있습니다. 펼친 칸은 동그라미가 하늘색으로 채워집니다.

B. 아이콘 없음

글자만 남아 더 단순합니다. 칸을 이름으로만 찾습니다.
