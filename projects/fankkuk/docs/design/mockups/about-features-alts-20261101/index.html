03

선물 검수 절차

팬이 보낸 선물은 팬꾹에서 검수 후 배송합니다.

  1. 1송장 제거

    상자에 붙어 있던 송장은 떼어 따로 보관하고, 상자를 돌려보내거나 처분할 때 파쇄합니다.

  2. 2겉면 검사

    상자 겉면에 숨겨진 연락처나 의심스러운 부착물이 있는지 확인합니다.

  3. 3추적 장치 탐지

    팬이 보낸 모든 상자를 탐지기로 검사합니다.

  4. 4개봉 검수

    탐지기에 반응한 상자는 개봉해 확인합니다.

04

배송 현황과 지금 할 일
