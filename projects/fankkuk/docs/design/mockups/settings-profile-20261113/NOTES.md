## 상태 8장 (명세 상태표 2 + 요청 상태)

## 지금 화면에서 바뀐 점
1. **저장 방식 차이를 구조로 드러냄** — 회색 「저장 줄」 띠는 글 칸 판(소개 · 태그 · 팬덤) 맨 아래에만 있고, 즉시 저장 판(프로필 사진 · 배경 사진)에는 없다. 선물 링크는 칸 옆 버튼(확인 창). 결과 안내(✓·!)는 띠 왼쪽으로 옮겨 버튼이 오르내리지 않는다. 보조 → 주 순서(취소·되돌리기 → 저장).
2. **판 모양을 내용에 맞게** — 사진 판은 실제 사진 칸 + 버튼 한 줄, 선물 링크는 앞부분 붙은 한 칸 + 결과 줄(복사), 소유자 확인은 한 줄 판(확인 완료 뱃지), 확인 전은 번호 흐름(① ② → 요청). 같은 모양 판이 5번 이어지던 것을 끊음(6-5-1·8-14).
3. **미리보기** — 오른쪽 열 연한 하늘 무대 안에 탭마다 하나(프로필 머리 / 찾기 카드 실제 크기 300), 따라옴. 1100 이하·휴대폰은 입력 위(휴대폰은 띠 72·사진 56).

## 새로 제안한 것 (design-rules 에 없음 — 승인 시 후보)
- 「저장 줄」 회색 띠(`--surface`) + 결과 안내 띠 왼쪽 배치.
- 미리보기 하늘 무대(`--tint` + `--tint-line`, 반경 24, 안쪽 24). 사이드바 하늘과 같은 색이라 하늘 면이 둘이 된다.
- 닉네임 칸 240(41절 값. 지금 코드는 360).
- 주소 칸을 앞부분 「fankkuk.com/」이 안에 붙은 한 칸으로(380).
- 확인 전 흐름의 세로 번호 줄. 확인 요청 버튼을 칸 폭 전체가 아니라 왼쪽 정렬 자동 폭으로(휴대폰은 전체 폭).
- 링크 주소 변경·등록 버튼을 채움이 아니라 선 버튼으로(채움은 저장·요청에만).

## 판단이 필요한 것
- 즉시 저장 판에는 「바로 저장돼요」 같은 문구를 안 넣었다(새 문장 금지). 띠 유무만으로 구분이 충분한지.
- 채널 확인 전에는 소유자 확인 판이 맨 아래라 눈에 안 띈다. 구조(순서) 변경이라 안 바꿨다 — 맨 위로 올릴지.
- 사진 예시는 마스코트·그라데이션이다(화면 예시). 기본 배경은 지시대로 `--primary-50` 한 면(44절은 그라데이션).
- 휴대폰 저장 줄은 판 아래에 붙는 sticky 유지(전체 화면 캡처에선 중간에 떠 보이지만 스크롤하면 판 끝에 붙는다).
