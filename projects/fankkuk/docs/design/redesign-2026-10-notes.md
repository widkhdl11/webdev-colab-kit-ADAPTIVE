# 전체 재디자인 메모 (2026-10-12 시작 — 시안 승인 전 입력, 승인되면 design-rules.md 로 옮긴다)

참고 사이트: sopodam.com · fanbox.kr — 따라 하지 않고 필요한 요소만 가져온다(정찰: refs/scout-sopodam.md · refs/scout-fanbox.md, 지금 사이트 실측: refs/current-type-audit.md).

## 사용자가 말한 문제
1. **글자** — 「용도별 텍스트의 글자 크기와 색감, 글씨체 차이가 큰 것 같다」. 지금 크기 35가지·굵기 5가지·글 대부분 회색. 기존 4절 「크기 차이를 크게」를 뒤집는다.
2. **좌우 분할 구조** — 「그런 구조가 무조건 싫다는 건 아닌데 최대한 지양하고 싶어. 좁은 공간에 설명을 덕지덕지 붙여놓은 것 같아서 한눈에 들어오지 않고, 설명글 같이만 보여. 그리고 정렬이 맞지도 않아」(예: 팬꾹 소개의 왼쪽 제목 / 오른쪽 설명). → 위에서 아래로 쌓고, 설명은 같은 크기 카드 격자로 짧게. 한 구간 안 정렬 기준은 하나.

## 진행
- 시안 v10-type: 랜딩 글자 체계 A(차분)·B(또렷) — 글자 + 좌우 분할 해소만 비교
- v10-type 실측(2026-10-12, 본체 Playwright, 1440·390px): A·B·type.html 모두 가로 넘침 0 · 16px 미만 0 · 대비 4.5 미만 0(최저 4.94) · 글씨체 Pretendard 하나. 한 화면 크기 A 5가지(PC 40/28/20/18/16 · 휴대폰 30/24/…) · B 5가지(48/32/… · 34/26/…), 굵기 A 700·600·400 / B 800·700·400. 지금 사이트는 크기 35가지·굵기 5가지.
- 남은 점: 휴대폰 아이콘 칸 3열이라 8칸 중 마지막 줄이 2칸만 찬다(4열이면 「크리에이터 찾기」가 16px 로 안 들어감).
- 2026-10-12 카드 d65 「A로」 — 글자 체계는 A 차분. 이어서 사용자 「글꼴 변경. 더 나은 거 찾아봐. 너무 궁서체다 디자인이 없다」(Pretendard 가 밋밋하다는 뜻).
- 글꼴 후보 비교 v10-type/fonts.html(같은 문장·A 체계로 일곱 후보), 랜딩 전체는 landing-a.html?font=<suit|wanted|nsneo|nsround|paperlogy|gmarket>. 실측: 일곱 글꼴 모두 로드 확인 · 16px 미만 0 · 대비 최저 4.94 · 넘침 0.
  - 나눔스퀘어 네오·라운드는 같은 700 이어도 획이 가늘어 제목·버튼을 800 으로 맞춰 비교했다.
  - 나눔스퀘어 네오는 네이버 배포 서버가 다른 사이트의 글꼴 파일 요청을 막아(CORS) 시안은 fonts-archive 사본을 쓴다. 실제 사이트에 쓰면 글꼴 파일을 사이트 안에 직접 두어야 한다.
  - 사용 조건: SUIT·Wanted Sans·나눔스퀘어 네오/라운드·페이퍼로지는 OFL(상업 사용 무료), G마켓 산스는 자체 무료 라이선스(상업 사용 가능, 글꼴 판매 금지).
- 사용자 「더 귀여운 글꼴은 없어?」 → 귀여운 쪽 일곱 추가(fonts.html?set=cute): 카페24 써라운드+에어 · 티머니 둥근바람 · 쿠키런+나눔스퀘어 라운드 · 배민 주아+라운드 · 배민 한나 Pro+라운드 · 학교안심 둥근미소 · 메이플스토리. 굵기가 하나뿐인 글꼴은 가짜 굵게를 막았다(font-synthesis:none). 실측: 모두 로드 · 16px 미만 0 · 대비 최저 4.94 · 넘침 0. 고르면 실제 사이트 반영 전 라이선스 원문을 확인하고 파일을 사이트 안에 둔다.
