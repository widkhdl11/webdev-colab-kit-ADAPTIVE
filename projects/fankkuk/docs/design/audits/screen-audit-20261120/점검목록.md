# 팬꾹 전체 화면 디자인 점검 목록 (2026-11-20)

이번에는 아무것도 고치지 않았다. 화면을 캡처하고, design-prompt.md 「검토할 때」 1~35번으로 미통과 항목만 적었다.

- 캡처: 로컬 개발 서버(로컬 DB 시험 데이터)에서 역할마다 로그인 화면으로 로그인해 1440·390 폭 전체 페이지를 찍었다. 시험 계정 별빛(팬)·하루(크리에이터)·팬꾹 운영(운영자 대표).
- 기계 측정(가로 넘침·12 미만 글자·44 미만 누르는 칸·글꼴)은 일부러 작은 글자와 낮은 링크를 심어 잡히는 것을 확인했다.
- 판정은 서브에이전트 여섯이 같은 지시문(BRIEF.md)으로 나눠 했고, 「여러 화면 공통」은 아래 요약에서 원인별로 다시 묶었다. 캡처에서 확인한 사실만 적었고 추측은 「확신 낮음」으로 표시했다.
- 캡처의 한계: 전체 페이지 캡처라 화면 아래에 붙어 있는 줄(크리에이터 꾸미기·프로필의 「취소/저장」 줄)이 페이지 중간에 겹쳐 찍힌 장이 있다. 실제 화면 문제가 아니라서 항목에서 뺐다. 팬·크리에이터 1440 캡처는 사이드바가 열리는 중간에 찍혀 한 번 다시 찍었다(사이드바 폭 240 확인).
- 운영자 화면은 휴대폰 폭(1023 이하)에서 전부 「PC에서 써 주세요」 안내로 막힌다(승인 시안대로). 그래서 운영자 390 캡처는 모두 같은 안내 화면이다.
- 항목 번호: 화면은 S01…, 항목은 S01-1… — 메모에 이 번호로 적으면 된다.

**세 종류**: 흐름·구조 21건 · 여러 화면 공통 93건 · 한 화면 겉모양 39건 (화면 71개)

## 흐름·구조가 바뀌는 것 — 모아 보기

고치면 할 일·입력·순서·구역 구성이 바뀌므로 바로 고치지 않고 제안으로 둔 것이다.

- **S01-3** 로그인 전 `/` — 첫 화면 히어로: 헤드라인과 검색(행동)은 보이지만 가치 문장이 없다. 위 작은 글 「크리에이터에게 선물을 보낼 때」는 누구에게·무엇을·어떻게를 담지 않는다 → 제안: 헤드라인 아래에 「주소를 몰라도 크리에이터가 승인한 선물을 팬꾹이 검수해 전달합니다」 같은 가치 문장 한 줄(문구는 문구 규칙 확인 후)
- **S02-1** 로그인 전 `/about` — 페이지 끝(「주고받은 선물과 감사 인사를 남겨보세요.」 구역 뒤): 긴 페이지인데 끝 행동(가입·크리에이터 찾기)이 없고 바로 바닥글이다. 첫 화면 행동도 아래로 내리는 「팬꾹 알아보기 ↓」뿐이다. 승인된 시안 about-20261114 가 끝 행동을 뺐다 — 승인값과 충돌 → 제안: 끝에 「회원가입」 채움 버튼 + 「크리에이터 찾기」 보조 버튼 묶음
- **S03-1** 로그인 전 `/pricing` — 첫 화면과 문서 끝: 첫 화면과 끝 어디에도 행동(선물 보내기·크리에이터 찾기)이 없다. 문서 끝은 안내 글 세 줄로 끝난다 → 제안: 문서 끝에 「크리에이터 찾기」 버튼 하나
- **S05-2** 로그인 전 `/guide/fan` — 첫 화면과 문서 끝 「추가 문의」: 행동 버튼이 없다(첫 화면은 안내 카드 링크, 끝은 문의 안내 글) → 제안: 첫 화면 또는 끝에 「크리에이터 찾기」 버튼
- **S06-2** 로그인 전 `/guide/creator` — 01~13 구역 전체: 13개 구역이 모두 「번호 목록 + 점 목록」 같은 구조로 그림·예시 없이 이어진다(팬 이용 안내는 화면 예시·요금 카드·단계 그림이 섞여 있다) → 제안: 승인·주소 열람처럼 핵심 구역에 화면 예시나 단계 그림을 넣어 구조를 바꿈
- **S06-3** 로그인 전 `/guide/creator` — 첫 화면과 문서 끝: 행동 버튼(크리에이터 가입 등)이 없다 → 제안: 끝에 「크리에이터로 가입」 버튼
- **S10-2** 로그인 전 `/report` — 버튼 위 「버튼을 누르면 작성한 내용을 이메일 앱으로 전달합니다. … 파일은 이메일 앱에서 첨부할 수 있습니다.」: 버튼 가까이의 문구가 한 줄 사실이 아니라 사용 방법을 설명하는 두~세 줄 문장이고, 아래 「받는 이메일 …」 줄까지 버튼 하나에 두 줄이 붙어 있다(8-16·9-3) → 버튼 가까이에는 한 줄(예: 받는 이메일 주소)만 남기고 사용 방법 문장은 줄이거나 뺀다 — 문구 변경이므로 제안
