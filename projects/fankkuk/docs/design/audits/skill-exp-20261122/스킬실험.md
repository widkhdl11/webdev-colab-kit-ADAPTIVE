한 화면에서만 나온 지적은 design-prompt 규칙으로 만들지 않는다. 화면 코드는 그대로 둔다.

- **큰 프로필 사진 옆 글자 간격**(옛 2-25): 「큰 프로필 사진 옆에 글자(이름 등)를 둘 때는 사진 테두리에서 `--space-6` 이상 띄운다.」 — 크리에이터 상세만. 화면 명세 `docs/ux/pages/handle.md` 「2026-11-23 사진↔이름 간격」에도 적었다.
- **체크가 커지며 등장**(옛 12-8 앞 문장): 「고른 표시(체크)는 작게 시작해 커지며 나타나게 한다(`--dur-check`, `--ease-out`).」 — 선물 보내기만. 같은 규칙의 「튀는 곡선 금지」는 체크 표시와 팔로우 버튼 두 곳에서 나와 규칙으로 남겼다.

## 실험 중 드러난 것

- **움직임 줄이기 끄는 규칙이 안 이기는 실수 2건**: 끄는 규칙의 선택자가 켜는 규칙보다 약해서 누름 크기 변화가 남았다. 계산된 스타일로 재서 찾았고 `2404422a`·`b1b4ea40` 로 고쳤다.
- **main 개발 서버(3000)는 크리에이터 상세에서 500**(「Jest worker encountered 2 child process exceptions」)이었다. 다른 세션이 그 서버로 시험을 돌리는 중이라 재시작하지 않았다. 이 실험의 캡처는 전부 실험 폴더 서버(3100)에서 찍었다. 「지금」 캡처는 고치기 전 커밋(`3e2b5086`)과 같은 코드다.
