## 2. 형태

- **테두리 대신 안쪽 1px 그림자**(`--hair: inset 0 0 0 1px rgba(51,61,57,.06)`). 입력창만 또렷한 경계(`--field: inset 0 0 0 1px #8A938F`, 흰 바탕 위 3.3:1)
- **떠 있는 그림자는 주 버튼에만**(`--lift`). 말풍선·메뉴·바텀시트는 `--float`, 뒤 가림막은 `--scrim`
- **반경은 크기별로 다르게**: 큰 판 32 · 아이콘 칸 28 · 카드 20 · 버튼 12(작은 버튼 10) · 태그 6. 동그란 알약 모양은 검색창·탭·칩에만
- 아이콘 칸: 회색 면(`--surface`) 위 반경 28, 안에 컬러 그림(PC 88px · 767px 이하 64px) + 아래 라벨. 한 줄에 PC 8칸(6칸 묶음은 6), 767px 이하 4칸(6칸 묶음은 3)
- 주 버튼: 넓고 각진 직사각형, 높이 52, 반경 12, 글자 17 굵게. 보조는 흰 면 + 테두리(`btn--line`) / 회색 면(`btn--soft`) / 글자만(`btn--text`). 작은 버튼 높이 44
- 목록(받은·보낸 선물, 공지, 열람 기록)은 **한 줄에 하나**, 줄 사이 얇은 구분선. 카드 격자로 늘어놓지 않는다
- 팔로우 크리에이터 가로 줄은 **어느 폭에서도 한 줄** — 좁으면 줄 안에서 옆으로 민다(사용자 「두~세 줄 되면 이상해」)
- 얼굴(프로필) 동그라미 48px, 큰 것 72px
- 수량 조절(−/+)은 44px 회색 원 버튼 + 가운데 숫자. 끝에 닿으면 흐리게만 하고 포커스는 남긴다
- 단계 입력(선물 보내기, 4단계): 한 화면에 한 단계, 입력과 「이전」「다음」이 한 카드 안. 「다음」은 카드 오른쪽 아래, PC 에서는 1~3단계 카드 높이를 같게 해 같은 높이에. 767px 이하는 버튼 두 개가 1:2 폭. 화면 아래 고정 줄은 쓰지 않는다(「어색하고 좁아 보인다」로 거부됨)

## 3. 그림

- Codex 이미지 생성으로 만든 PNG(`mockups/site/v4/img/`). 공통 지시는 `v4/img/_style.md` — 부드러운 3D(클레이 느낌)·통통한 형태·왼쪽 위 조명·투명 배경·검정 윤곽선 없음·그림 안에 글자 없음

## 5. 레이아웃

- **PC 기준 일반 사이트.** 본문 최대 1200px 중앙, 좌우 여백 24px(PC) · 16px(767px 이하). 휴대폰 폭 기둥을 PC 가운데 세우지 않는다
- 기준점 셋: 1024px 이상 = 가로 네비·3~4칸 그리드 / 768~1023px = 2칸 / 767px 이하 = 햄버거 메뉴·1칸
- 구간 위아래 여백은 넉넉하게(72~128px). 흰 바탕을 비워 두는 것이 이 방향의 핵심이다
- 헤더 세 상태(같은 구조): 비로그인 = 로그인·회원가입 / 팬 = 선물 상태 아이콘 + 내 정보 메뉴 / 크리에이터 = 승인 요청 수 + 내 정보 메뉴
- 네비: 크리에이터 찾기 · 선물 보내기 · 공지사항 · 팬꾹 소개 · 고객센터 (크리에이터는 승인 요청 · 열람 기록 · 주소와 설정 + 공지사항 · 고객센터). 현재 페이지는 `aria-current`
- 헤더 선물 아이콘: 진행 중인 선물마다 원 아이콘(승인 대기 · 이동 중 · 배송 완료), 최대 3개 + 「+N」, 마우스 올림·포커스 둘 다 말풍선 「선물 4개 중 1번째 · 하루님께 · 배송중」, 배송 완료는 3일 뒤 사라짐. 767px 이하는 「선물 N」 배지 하나 → 바텀시트 목록
- 내 정보 화면: PC 왼쪽 세로 메뉴(개인정보 · 팔로우한 크리에이터 · 선물 내역), 767px 이하 위 탭
- 입력 + 요약 화면(선물 보내기): PC 오른쪽 요약, 767px 이하 요약이 아래로
- 간격 4px 단위, 짝수 px만
- 운영자 작업 화면만 예외로 빽빽하게(그때 별도 기준)
- 접근성: 포커스 테두리 3px 본문색(초록 면 위는 흰색), 본문 바로가기 링크, 움직임 줄이기 설정을 따른다
- **실측 (v4 시안 18장 × 1440·390px)**: 가로 넘침 0 · 16px 미만 0 · 대비 4.5 미만 0, 최저 4.60
