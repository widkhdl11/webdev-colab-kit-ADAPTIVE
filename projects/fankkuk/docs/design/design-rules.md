## 2. 형태

- **테두리 대신 안쪽 1px 그림자**(`--hair: inset 0 0 0 1px var(--border)`, `--border` #DFDCE0 불투명 — 흰 바탕 위 흰 카드 가장자리가 보이게). 입력창만 또렷한 경계(`--field: inset 0 0 0 1px #8C7B76`, 흰 바탕 위 4.0:1). 입력창 바탕은 흰색, 안내 글자(placeholder)는 `--faint`
- 선택된 면(현재 메뉴·선택 탭·체크된 항목)은 `--surface-selected`(#FCECE8) + 글자 `--brand-ink` — 일반 칸(`--surface` 옅은 중립)·마우스 올림(`--surface-hover`)과 구분한다. 코랄 글자는 옅은 코랄 면(#FFF5F1) 위 4.6:1 경계선이라, 더 진한 면(#FCECE8) 위의 글자는 `--brand-ink`
- **떠 있는 그림자는 주 버튼에만**(`--lift`). 말풍선·메뉴·바텀시트는 `--float`, 뒤 가림막은 `--scrim`
- **반경은 크기별로 다르게**: 큰 판 32 · 아이콘 칸 28 · 카드 20 · 버튼 12(작은 버튼 10) · 태그 6. 동그란 알약 모양은 검색창·탭·칩에만
- 아이콘 칸: 옅은 코랄 면(`--surface`) 위 반경 28, 안에 컬러 그림(PC 88px · 767px 이하 64px) + 아래 라벨. 한 줄에 PC 8칸(6칸 묶음은 6), 767px 이하 4칸(6칸 묶음은 3)
- 주 버튼: 넓고 각진 직사각형, 높이 52, 반경 12, 글자 17 굵게. 보조는 흰 면 + 테두리(`btn--line`) / 옅은 코랄 면(`btn--soft`) / 글자만(`btn--text`). 작은 버튼 높이 44
- 목록(받은·보낸 선물, 공지, 열람 기록)은 **한 줄에 하나**, 줄 사이 얇은 구분선. 카드 격자로 늘어놓지 않는다
- 팔로우 크리에이터 가로 줄은 **어느 폭에서도 한 줄** — 좁으면 줄 안에서 옆으로 민다(사용자 「두~세 줄 되면 이상해」)
- 얼굴(프로필) 동그라미 48px, 큰 것 72px, 크리에이터 페이지 머리만 96px. 바탕은 `--face-1`~`--face-6` 을 돌려 쓴다
- 수량 조절(−/+)은 44px 옅은 코랄 원 버튼 + 가운데 숫자. 끝에 닿으면 흐리게만 하고 포커스는 남긴다
- 단계 입력(선물 보내기, 4단계): 한 화면에 한 단계, 입력과 「이전」「다음」이 한 카드 안. 「다음」은 카드 오른쪽 아래, PC 에서는 1~3단계 카드 높이를 같게 해 같은 높이에. 767px 이하는 버튼 두 개가 1:2 폭. 화면 아래 고정 줄은 쓰지 않는다(「어색하고 좁아 보인다」로 거부됨)

## 5. 레이아웃

- **PC 기준 일반 사이트.** 본문 최대 1200px 중앙, 좌우 여백 24px(PC) · 16px(767px 이하). 휴대폰 폭 기둥을 PC 가운데 세우지 않는다
- 기준점 셋: 1024px 이상 = 가로 네비·3~4칸 그리드 / 768~1023px = 2칸 / 767px 이하 = 햄버거 메뉴·1칸
- 구간 위아래 여백은 넉넉하게(72~128px). 흰 바탕을 비워 두는 것이 이 방향의 핵심이다
- 헤더 세 상태(같은 구조): 비로그인 = 로그인·회원가입 / 팬 = 선물 상태 아이콘 + 내 정보 메뉴 / 크리에이터 = 승인 요청 수 + 내 정보 메뉴. 내 정보 메뉴(닉네임 버튼)를 펼치면 「내 팬꾹」 메뉴 항목이 그대로 나온다
- 네비: 크리에이터 찾기 · 선물 보내기 · 공지사항 · 팬꾹 소개 · 고객센터 (크리에이터도 같다 — 다른 크리에이터를 찾아 선물을 보낸다. 크리에이터의 일하는 화면은 「내 팬꾹」 안에만). 현재 페이지는 `aria-current`
- 헤더 오른쪽 끝은 글자 중심이다(2026-10-07 시안 v9-header, 사용자 「아동사이트 같은 느낌」 → 「B에다가 선물배송 아이콘만」). 면·동그라미·알약을 두지 않는다. 로그인 전 = 「로그인 | 회원가입」 글자 둘(16px 600, 로그인은 `--sub` — 시안의 15px 는 16px 하한에 맞춰 올림), 내 정보 = 「닉네임님 ⌄」 글자 버튼(이름 첫 글자 동그라미 없음), 크리에이터 = 상자 그림 + 「승인 대기」 + 차콜 숫자 알약(24px 높이, 숫자 16px). 오른쪽 묶음 사이는 세로 1px 구분선. 마우스 올림만 `--surface` 면
- 헤더 선물 아이콘: 진행 중인 선물마다 가는 선 그림(선 두께 1.6 — 승인 대기 시계 · 이동 중 트럭 · 배송 완료 체크 원) + 오른쪽 위 8px 상태 점(대기 `--warn-ink` · 이동 중 `--info` · 완료 `--success`), 최대 3개 + 「+N」, 마우스 올림·포커스 둘 다 말풍선 「선물 4개 중 1번째 · 하루님께 · 배송중」, 배송 완료는 3일 뒤 사라짐. 767px 이하는 상자 그림 + 「선물」 + 숫자 알약 하나 → 바텀시트 목록
- **「내 팬꾹」**(마이페이지, 2026-10-04 이름을 「내 정보」에서 바꿈): PC 왼쪽 세로 메뉴, 767px 이하 위 탭. 페이지 제목은 「내 팬꾹」(h1), 메뉴마다 본문 머리는 h2 28px
  - 팬: 개인정보 · 팔로우한 크리에이터 · 선물 내역 · 받은 역조공
  - 크리에이터: 승인 요청 · 보낸 선물 · 보낸 역조공 · 열람 기록 · 주소와 설정 — 헤더 가로 메뉴에 두지 않는다(사용자 「왼쪽 사이드바로 보는거면 좋겠어. 내 정보 페이지로 들어가서 보게」 · 「페이지 구성 자체가 일반적이지 못한거 같아」)
