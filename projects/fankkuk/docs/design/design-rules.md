## 2. 형태

- **테두리 대신 안쪽 1px 그림자**(`--hair: inset 0 0 0 1px var(--border)`, `--border` #DFDCE0 불투명 — 흰 바탕 위 흰 카드 가장자리가 보이게). 입력창만 또렷한 경계(`--field: inset 0 0 0 1px #8C7B76`, 흰 바탕 위 4.0:1). 입력창 바탕은 흰색, 안내 글자(placeholder)는 `--faint`
- 선택된 면(현재 메뉴·선택 탭·체크된 항목)은 `--surface-selected`(#FCECE8) + 글자 `--brand-ink` — 일반 칸(`--surface` 옅은 중립)·마우스 올림(`--surface-hover`)과 구분한다. 코랄 글자는 옅은 코랄 면(#FFF5F1) 위 4.6:1 경계선이라, 더 진한 면(#FCECE8) 위의 글자는 `--brand-ink`
- **떠 있는 그림자는 주 버튼에만**(`--lift`). 말풍선·메뉴·바텀시트는 `--float`, 뒤 가림막은 `--scrim`
- **반경은 크기별로 다르게**: 큰 판 32 · 아이콘 칸 28 · 카드 20 · 버튼 12(작은 버튼 10) · 태그 6. 동그란 알약 모양은 검색창·탭·칩에만
- 아이콘 칸: 옅은 코랄 면(`--surface`) 위 반경 28, 안에 컬러 그림(PC 88px · 767px 이하 64px) + 아래 라벨. 한 줄에 PC 8칸(6칸 묶음은 6), 767px 이하 4칸(6칸 묶음은 3)
- 주 버튼: 넓고 각진 직사각형, 높이 52, 반경 12, 글자 17 굵게. 보조는 흰 면 + 테두리(`btn--line`) / 옅은 코랄 면(`btn--soft`) / 글자만(`btn--text`). 작은 버튼 높이 44
- (2026-10-13 0절에서 선물 내역·받은 역조공·승인 요청은 카드 격자로 바뀜) 목록(받은·보낸 선물, 공지, 열람 기록)은 **한 줄에 하나**, 줄 사이 얇은 구분선. 카드 격자로 늘어놓지 않는다
- 팔로우 크리에이터 가로 줄은 **어느 폭에서도 한 줄** — 좁으면 줄 안에서 옆으로 민다(사용자 「두~세 줄 되면 이상해」)
- 얼굴(프로필) 동그라미 48px, 큰 것 72px, 크리에이터 페이지 머리만 96px. 바탕은 `--face-1`~`--face-6` 을 돌려 쓴다
- 수량 조절(−/+)은 44px 옅은 코랄 원 버튼 + 가운데 숫자. 끝에 닿으면 흐리게만 하고 포커스는 남긴다
- 단계 입력(선물 보내기, 4단계): 한 화면에 한 단계, 입력과 「이전」「다음」이 한 카드 안. 「다음」은 카드 오른쪽 아래, PC 에서는 1~3단계 카드 높이를 같게 해 같은 높이에. 767px 이하는 버튼 두 개가 1:2 폭. 화면 아래 고정 줄은 쓰지 않는다(「어색하고 좁아 보인다」로 거부됨)
