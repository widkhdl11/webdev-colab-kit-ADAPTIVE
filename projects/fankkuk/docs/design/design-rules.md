## 2. 형태 (2026-10-01 교체 — 「한두 포인트만 살려서 AI 느낌을 없애줘」)

- 기본은 **선과 글자.** 구간·카드는 위쪽 굵은 선(`--rule`) 하나로 나눈다. 상자로 두르는 것은 묶음이 꼭 보여야 하는 곳만 — 입력 단계 카드, 요약 카드, 목록 상자, 로그인 카드
- 상자로 두를 때: 1px `--field-line` 테두리, 반경 12px(목록 상자 8px), 그림자 없음. 그림자는 떠 있는 것(바텀시트·모달)에만
- 아이콘 타일·옅은 색 면을 반복해서 깔지 않는다
- 버튼 반경 12px(높이 48px). 배지·칩은 도장 말투(테두리 원·사각, 살짝 기울기)
- 번호·아바타는 정원 테두리
- 랜딩은 격자를 깨는 곳이 있다 — 첫 화면의 서류 + 종이 밖으로 삐져나온 큰 도장
- 수량 조절(−/+)은 44px 정원 버튼 + 가운데 숫자 칸. 끝에 닿으면 흐리게만 하고 포커스는 남긴다
- 단계 입력(선물 보내기): 한 화면에 한 단계, 입력과 「이전」「다음」이 한 카드 안. 「다음」은 카드 오른쪽 아래, PC에서는 1~3단계 카드 높이를 같게 해 같은 높이에 (사용자 「다음 버튼 위치 통일」 · 「카드 느낌으로」 — 화면 아래 고정 줄은 「어색하고 좁아 보인다」로 거부됨)

## 4. 레이아웃 (2026-10-01 사이트 전체 시안으로 교체 — 「일반 사이트 같은 사이즈」)

- **PC 기준 일반 사이트.** 본문 컨테이너 최대 1200px 중앙, 좌우 여백 24px(PC) · 16px(767px 이하). 휴대폰 폭 기둥을 PC 가운데 세우지 않는다
- 기준점 셋: 1024px 이상 = 가로 네비·3~4칸 그리드 / 768~1023px = 네비가 둘째 줄로, 2칸 / 767px 이하 = 햄버거 메뉴·1칸
- 헤더 세 상태(같은 구조): 비로그인 = 로그인·회원가입 / 팬 = 선물 상태 아이콘 + 내 정보 메뉴 / 크리에이터 = 승인 요청 수 + 내 정보 메뉴
- 네비: 크리에이터 찾기 · 선물 보내기 · 공지사항 · 팬꾹 소개 · 고객센터 (크리에이터는 승인 요청 · 열람 기록 · 주소와 설정 + 공지사항 · 고객센터). 현재 페이지는 `aria-current`
- 헤더 선물 아이콘: 진행 중인 선물마다 원 아이콘(승인 대기 = 모래시계, 이동 중 = 트럭, 배송 완료 = 체크), 최대 3개 + 「+N」, 마우스 올림·포커스 둘 다 말풍선 「선물 4개 중 1번째 · 하루님께 · 배송중」, 배송 완료는 3일 뒤 사라짐. 767px 이하는 「선물 N」 배지 하나 → 바텀시트 목록
- 내 정보 화면: PC 왼쪽 세로 메뉴(개인정보 · 팔로우한 크리에이터 · 선물 내역), 767px 이하 위 탭
- 입력 + 요약 화면(선물 보내기): PC 오른쪽 고정 요약, 767px 이하 요약이 아래로
- 단계 표시 두 가지: 라벨 있는 단계(상세·랜딩, 767px 이하 세로) / 막대(카드 안, `role="progressbar"`)
- 간격 4px 단위, 짝수 px만
- 운영자 작업 화면만 예외로 빽빽하게(그때 별도 기준)
- 입력창 테두리 `--field-line: #7F8C87`(흰 면 위 3:1 이상) — 시안에서 새로 정함
- 카카오 인증 버튼만 카카오 노란색(#FEE500)·글자 #191919 — 사이트 색 밖이지만 카카오 버튼으로 알아보게
- **실측 (2026-10-01, 사이트 시안 18장 × 1440·390px)**: 가로 넘침 0 · 16px 미만 0 · 대비 4.5 미만 0, 최저 4.63. 작은 회색 글자·2000px 상자를 심어 세 가지 모두 잡히는 것 확인

## 5. 무드와 말투

- 플레이풀·귀여움. 단 **두 층**: 일러스트·색·말투는 귀엽게("보내 드려요"), 보안 약속·절차 설명은 또렷하고 차분하게
- 문구 한계: "승인 없이는 저희 시스템이 주소를 열지 않습니다"(참) / "절대 유출되지 않습니다"·"저희도 열 수 없습니다"(쓰지 않음)
- 검수는 "모든 상자의 송장 제거·겉면 검사, 걸린 상자만 개봉" — "모든 상자를 열어"라고 쓰지 않는다
- 경쟁 서비스 이름은 쓰지 않는다
