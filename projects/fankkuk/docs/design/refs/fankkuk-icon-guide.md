# 팬꾹 아이콘 형태·구현 가이드

첨부된 `fankkuk-icon-final.png`는 팬꾹(fankkuk)의 확정된 소셜 링크 아이콘이다. 이 디자인을 기준으로 기존 프로젝트에 사용할 아이콘 에셋과 컴포넌트를 구현해줘.

팬꾹은 팬의 선물을 대신 받아 검수하고, 크리에이터의 개인정보를 보호하며 재배송하는 서비스다. 친근하고 귀엽지만 믿고 맡길 수 있는 인상을 지향한다.

## 확정 디자인

- 코랄색 원형 배경 위에 뻐꾸기 얼굴과 선물 상자가 결합된 심볼.
- 아이보리색 둥근 얼굴, 오른쪽으로 기운 작은 머리 깃털 하나.
- 짙은 차콜색 원형 눈 두 개와 아래를 향하는 코랄색 삼각형 부리.
- 얼굴 아래에는 얇고 모서리가 둥근 아이보리색 상자 뚜껑.
- 상자 몸통은 아래 모서리가 둥근 아이보리색 사각형.
- 몸통 위에 진한 코랄색 십자 리본을 배치한다.
- **뚜껑과 몸통 사이에는 가로로 끊김 없는 빈틈이 있어야 한다. 세로 리본은 몸통의 윗변에서 시작하며, 빈틈을 가로질러 뚜껑까지 이어지면 안 된다.**
- 얼굴, 뚜껑, 상자, 리본의 비율과 위치는 첨부 이미지를 따른다.
- 글자, 날개, 꼬리, 하트 등 추가 장식은 넣지 않는다.

## 색상

| 용도 | 색상 |
| --- | --- |
| 원형 배경 | `#F58278` |
| 얼굴·뚜껑·상자 | `#FFF8F0` |
| 눈 | `#343039` |
| 부리·십자 리본 | `#BE514A` |

첨부 PNG에는 생성 과정의 미세한 색 변화가 있으나, SVG로 구현할 경우 위 색상의 단색 면을 사용한다. 그라데이션, 그림자, 질감, 입체 효과는 넣지 않는다.

## 구현

1. 기존 프로젝트의 구조와 기술 스택을 먼저 확인한다.
2. 첨부 PNG를 원본 참조 에셋으로 보관한다. 파일은 512×512px이며 원 바깥은 투명하다.
3. 가능하면 디자인을 충실하게 재현한 SVG와 재사용 가능한 아이콘 컴포넌트를 만든다. PNG를 SVG 안에 삽입하는 방식이 아니라 벡터 도형으로 구현한다.
4. 크기를 조절해도 비율이 유지되며, 원 바깥은 투명해야 한다.
5. 24·32·40·48px에서 밝은 배경과 어두운 배경으로 확인할 수 있는 미리보기를 만든다.
6. 링크로 사용할 때 접근성 이름은 “팬꾹에서 선물 보내기”로 제공한다. 링크와 내부 이미지의 이름이 중복해서 읽히지 않도록 구성한다.
7. 첨부 이미지와 비교해 형태와 간격이 유지되는지 확인한다. 임의로 새로운 디자인으로 바꾸지 않는다.
