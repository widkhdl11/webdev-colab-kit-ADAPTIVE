# 팬꾹 사이트 색상 가이드

팬꾹(fankkuk) 사이트 전체에 아래 브랜드 색상 체계를 적용해줘. 기존 프로젝트의 스타일 구조를 확인하고 공통 디자인 토큰으로 관리해줘.

## 브랜드 방향

팬꾹은 팬의 선물을 검수하고, 크리에이터의 주소와 개인정보를 보호하며 배송하는 서비스다. “팬과 크리에이터의 프라이빗한 사이”라는 방향으로 따뜻하고 친근하면서도 신뢰할 수 있는 분위기를 만든다.

확정 아이콘의 코랄·아이보리·차콜 조합을 사이트로 확장한다. 코랄은 주요 버튼과 강조에 사용하고, 본문과 입력 화면은 차분하고 읽기 편하게 유지한다.

## 적용 규칙

1. **주요 CTA:** “선물 보내기”, “승인하기”, “저장하기” 등은 `#B84F48` 배경과 흰색 텍스트를 사용한다. 밝은 브랜드 코랄 `#F58278` 위에 작은 흰색 글씨를 사용하지 않는다.
2. **보조 버튼:** 흰색 또는 옅은 코랄 배경에 진한 코랄 텍스트를 사용한다. 취소·뒤로 가기는 차콜 텍스트와 중립 테두리를 사용한다.
3. **헤더·카드:** 기본은 흰색이다. 브랜드 코랄은 로고, 주요 버튼, 작은 강조 요소에 집중하고, 소개 배너나 안내 영역에 옅은 코랄 배경을 사용한다.
4. **폼·입력창:** 흰색 배경, 차콜 텍스트, 입력창용 테두리를 사용한다. 포커스는 진한 코랄 링으로 표시한다. 오류는 안내 문구와 아이콘으로도 전달한다.
5. **상태 배지:** 승인·검수 완료는 성공 색상, 승인 대기·검수 중은 대기 색상, 거절·배송 문제는 오류 색상을 사용한다.
6. **개인정보 보호 안내:** 보조 배경과 차콜 텍스트로 차분하게 표현한다. 자물쇠나 방패 아이콘과 설명 문구를 함께 사용한다.

## 구현·확인

- CSS 변수의 이름과 값은 `fankkuk-design-tokens.md`를 기준으로 관리한다.
- 기존 컴포넌트의 색상을 의미에 맞는 토큰으로 연결한다.
- 기존 Tailwind·shadcn/ui 등이 있다면 해당 테마 구조를 활용한다.
- 아이콘 내부의 원래 색상과 형태는 `fankkuk-icon-guide.md`를 따른다.
- 일반 텍스트 대비 4.5:1, 큰 텍스트 및 식별에 필요한 주요 UI 경계 대비 3:1을 구현 시 확인한다. 이 팔레트의 모든 조합이 검증된 것으로 간주하지 않는다.
- 기본 구분선은 장식용이다. 식별에 필요한 입력창 경계 등이 대비 기준에 미달하면 해당 경계 토큰을 더 진하게 조정하고 문서에도 반영한다.
- hover·active·focus·disabled 상태를 함께 적용한다.
- 버튼·카드·폼·배지·안내 영역을 한 화면에서 확인할 수 있는 미리보기를 만든다.
- 기존 레이아웃과 기능을 유지하면서 색상 체계를 일관되게 적용한다.

이 문서는 라이트 테마 기준이다. 다크 배경에서 아이콘을 확인하는 것은 별도의 다크 테마 팔레트 확정을 의미하지 않는다.
