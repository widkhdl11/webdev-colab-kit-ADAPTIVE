## 모든 영역에 걸치는 원칙

1. **크리에이터 개인정보가 가장 먼저다.** 크리에이터 주소는 팬에게 절대 보이지 않고, 주소에 닿는 크리에이터의 동작은 매번 카카오 서명을 받는다. 이를 위해서는 번거로움을 감수한다.
2. **팬 정보도 지키되, 큰 문제가 없으면 팬을 번거롭게 하지 않는다.** 그래서 팬의 역조공 받기는 로그인만으로 된다. 계정을 빼앗겨 역조공을 가로채이는 일은 감수한다(팬 주소 자체는 암호화돼 크리에이터도 못 본다). _(2026-10-09 카드 d56)_
3. **업계 표준이 있으면 그대로 쓴다.** 특수한 경우만 따로 정한다. _(2026-10-08 사용자 지시)_
4. **알림 본문에는 선물 내용·보낸 사람·주소·금액이 들어가지 않는다.** 화면을 열어야 보인다.
