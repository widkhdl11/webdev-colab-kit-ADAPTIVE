# 취소·환불 규정 UX 명세 — `/refund`

> 2026-10-23 문서형 페이지 1단계. **지금 구현된 그대로**를 적었다(코드 수정 없음). 바꿀 것은 `_diff-policy.md` 에 따로 있다.
> 그리는 코드: `src/app/(site)/refund/page.tsx` → `src/widgets/legal/ui/policy-page.tsx`(+ `policy-toc.tsx`, `policy-page.module.css`), 글은 `src/widgets/legal/model/refund-doc.ts`, 버전은 `legal-versions.ts`.
> 화면 틀은 이용약관과 같다 — 다른 점만 따로 적었다.

## 페이지 브리프

1. 목적: 선물을 취소하거나 반송될 때 얼마를 돌려받는지와 방법을 로그인 없이 확인한다. 이용약관 제9조를 풀어 적은 글이다(`refund-doc.ts:18`).
2. 주 사용자 / 부 사용자: 팬 / 크리에이터(사정으로 취소할 때), 결제대행사 심사 담당자
3. 사용자가 와서 하려는 일: 내 선물이 지금 어디쯤인지(입고 전·입고 후·출고 후)에 맞춰 지금 취소하면 얼마 돌려받는지 찾는다. 다음으로 취소하는 방법(3절)을 찾는다.
4. 방문 빈도: 취소를 생각할 때, 거절·반송 알림을 받았을 때 한두 번
5. 페이지 유형: 문서형 — 읽기만 하고 입력이 없다
6. 같은 유형의 다른 페이지: 이용약관·개인정보처리방침(같은 틀), 요금 안내(같은 요금 표), 이용 안내(팬)
7. 이 페이지만의 특이점: 절이 다섯 개뿐이고, 사용자가 찾는 답은 거의 2절 「상태별 환불 금액」 상자 하나(9줄)에 있다. 이 상자는 입고 전 → 입고 후 → 사유별(크리에이터 사정·팬 입고 후 취소·검수 불합격·차액 미결제·30일 미도착) → 출고 후 순서로 놓였다(`refund-doc.ts:62-116`). 요금·반송 택배비 숫자는 DB 요금표에서 읽는다(`page.tsx:20`).
8. 바꾸면 안 되는 것: 글 내용(`refund-doc.ts` 문장)·버전 기록·요약 세 줄·고객센터 안내, 전액 초록·없음 빨강 꼬리표 규칙(design-rules 14절), 탭 이름 「취소·환불 규정」
