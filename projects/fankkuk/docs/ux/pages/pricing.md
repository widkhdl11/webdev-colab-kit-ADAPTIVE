# 요금 안내 UX 명세 — `/pricing`

> 2026-10-22 새 화면(사용자 「요금 안내 페이지 만들어줘. 심사받을때 필요한것 같아」). 안내 글 틀(`LegalPage`)을 그대로 써서 만들었고, 이 명세는 **만든 그대로**를 적었다. 문서형 페이지 정돈(UX 명세 → 공통 부품) 때 다른 안내 글과 함께 다시 본다.

## 페이지 브리프

1. 목적: 상자 하나에 얼마를 내는지와 따로 결제하는 경우를 로그인 없이 한 주소에서 확인한다. 결제대행사 가맹 심사에서 상품·가격 공개 화면으로 쓴다.
2. 주 사용자 / 부 사용자: 가입 전 팬 / 크리에이터(역조공 요금), 결제대행사 심사 담당자
3. 사용자가 와서 하려는 일: 내 상자 크기의 요금을 찾는다, 나중에 돈이 더 드는 경우가 있는지 본다
4. 방문 빈도: 처음 보내기 전 한두 번
5. 페이지 유형: 문서형 — 읽기만 하고 입력이 없다
6. 같은 유형의 다른 페이지: 이용 안내(팬·크리에이터)·검수 기준·보안 안내·분쟁 처리 안내·자주 묻는 질문·약관 세 글
7. 이 페이지만의 특이점: 숫자는 결제와 같은 DB 공개 요금표를 읽는다(운영자가 요금을 바꾸면 바로 바뀐다). 문장은 이용 안내 두 글에 이미 있는 것을 그대로 쓴다.
8. 바꾸면 안 되는 것: 요금 숫자를 코드에 쓰지 않는다. 검수비·서비스료는 숫자로 쓰지 않는다(이용 안내·환불 규정과 같은 규칙).

UX 기준 문서(`docs/ux/principles.md` · `docs/ux/document-pages.md`)가 아직 없어 번호로 대조하지 못했다 — 문서형 페이지 정돈 때 함께 대조한다.

- 환불 금액: 스펙 대신 취소·환불 규정 글로 안내한다.
