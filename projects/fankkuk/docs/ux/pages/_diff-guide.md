# 안내 글 여섯 — 2단계 차이 목록 (legal-page 몫)

> 2026-10-23. 대상: `/guide/fan` · `/guide/creator` · `/inspection` · `/security` · `/dispute` · `/pricing`.
> 여섯 화면은 모두 같은 틀 `src/widgets/legal/ui/legal-page.tsx`(+ `legal.module.css`)로 그린다. 그래서 위반이 거의 전부 틀 하나의 문제다 — 틀을 고치면 여섯이 같이 바뀐다.
> 판정 근거는 각 페이지 명세(`guide-fan.md` 등)의 「적용한 규칙」 표. 실측은 2026-10-23 localhost(1440·1280 로그인·390).

## 1. 사용자 항목 9 판정 — 「legal-page 에는 sticky 목차·탭 없음, 맨 위 목차 카드뿐」

**맞음.**

- 목차는 본문 앞 구간 안의 `nav.card` 하나다(`legal-page.tsx:145~160`). `legal.module.css` 에 `position: sticky`·`fixed` 가 한 곳도 없다 — 스크롤하면 목차가 화면 밖으로 나간다. 실측도 여섯 화면 모두 「nav.card, 고정 아님」.
- 탭이 없다. policy-page 는 세 글을 오가는 탭(`policy-page.tsx:161~165`)과 따라오는 왼쪽 목차(`policy-toc.tsx`, `policy-page.module.css:38`)를 갖지만, legal-page 는 둘 다 쓰지 않는다. 글 모양의 `tocGroups`(`legal-doc.ts:45`)도 legal-page 는 읽지 않는다.
- 덧붙임: 구조는 다르지만 **지금 폭에서 화면에 보이는 결과는 같다.** policy-page 의 따라오는 목차는 글 자리가 976 이상일 때만 나오는데, 공개 기둥이 880 이라 로그인 전·후 모두 접는 칸으로 바뀐다(`policy-page.module.css:35·48`, 실측 1280 로그인에서도 `details [closed]`). 그래서 기준 1(고정 탐색) 위반은 두 틀이 같고, 고치는 방법만 다르다.

## 2. 공통 항목 1~8 이 legal-page 에도 해당하는가

| 항목 | 판정 | 이유 |
|---|---|---|
| 1. 왼쪽 목차 접힘 기준 976px | **해당 안 됨** | legal-page 에는 왼쪽 목차도, 접는 기준도 없다. 다만 고정 목차가 없다는 결과(기준 1 위반)는 같다 — 아래 A-1 |
| 2. 접힌 목차 summary 에 펼침 표시·hover 없음 | **해당 안 됨** | legal-page 목차는 접히지 않는 카드다. 링크에는 hover 색·밑줄이 있다(`legal.module.css:14`). 대신 다른 약점이 있다: 평소에는 밑줄 없는 본문색 글자라(`base.css:21`, `legal.module.css:13`) 누를 수 있는지가 hover 전에는 드러나지 않는다(기준 2 「약함」) |

| 6. 자주 찾는 조 구분 없음 | **공통** | 조가 모두 같은 모양(`legal.module.css:18~20`). `/pricing` 만 해당 없음(조 셋이 모두 요금) |
| 7. anchor 복사 없음 | **공통** | 조마다 `id` 는 있다(`legal-page.tsx:165`, 실측 anchors 4~14). 복사 수단만 없다 |
| 8. 요약이 조로 연결되지 않음 | **공통** | 요약 세 줄이 글자만(`legal-page.tsx:107~111`) |

## 5. 승인된 방향(design-rules 28절)과 부딪히는 곳 — 결정 필요

28절은 안내 글 다섯(`/pricing` 제외)을 「머리 → 「먼저 알아 두세요」 판 → **글 위 접는 목차** → 조」로 정하고 「탭 · **사실 한 줄** · 버전 기록은 쓰지 않는다」고 했다. 이것을 그대로 구현하면:

- A-1(기준 1): 글 위 접는 목차만으로는 스크롤한 뒤 다른 조로 가는 수단이 화면에 없다 — 기준 1 위반이 남는다.
- A-8(기준 11): 「사실 한 줄을 쓰지 않는다」와 「안내 글에 최종 수정일」이 맞서는지, 날짜만은 다른 자리(머리 아래 한 줄 등)에 둘 수 있는지 정해야 한다.
- A-10(기준 10)은 28절의 「접는 목차」로 풀린다.
