# 크리에이터 이용 안내 UX 명세 — `/guide/creator`

> 2026-10-23 문서형 페이지 1단계. 코드를 읽고 **지금 구현된 그대로** 적었다. 고칠 점은 `_diff-guide.md` 에 따로 있다.

## 페이지 브리프

1. 목적: 크리에이터가 가입부터 선물 승인·답장·역조공까지의 순서를 화면 이름 그대로 가입 전에도 확인한다.
2. 주 사용자 / 부 사용자: 크리에이터(가입 전 포함) / 고객센터 답변에서 이 글을 가리키는 운영자
3. 사용자가 와서 하려는 일: 본인 확인과 채널 소유 확인을 어떻게 하는지 본다, 내 주소가 어떻게 보호되는지 본다, 선물 승인·받지 않기·쉬는 중을 어떻게 하는지 찾는다. (지시 표의 「정산」은 글에 없다 — 크리에이터는 받는 데 돈을 내지도 받지도 않는다. `guide-creator-doc.ts` 에 「정산」 0회)
4. 방문 빈도: 가입 전후 한두 번, 기능을 처음 쓸 때 한 번씩
5. 페이지 유형: 문서형 — 읽기만 하고 입력이 없다
6. 같은 유형의 다른 페이지: 팬 이용 안내·검수 기준·보안 안내·분쟁 처리 안내·요금 안내(같은 안내 글 틀), 약관 세 글(policy-page), 자주 묻는 질문(faq-page)
7. 이 페이지만의 특이점: 조가 13개로 안내 글 중 가장 길다(실측 1440 높이 8505, 390 높이 12927). 역조공 조의 금액은 DB 공개 요금표를 읽는다(`page.tsx:16`).
8. 바꾸면 안 되는 것: 글 내용(문장), 요약 세 줄, 화면 이름을 그대로 적은 표기(「내 팬꾹」「상세 설정」 등)
