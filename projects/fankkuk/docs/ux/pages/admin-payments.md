# 결제·환불 관리 UX 명세 — `/admin/payments` (환불 칸만)

> 2026-10-24 「직접 환불함」을 넣으며 처음 만들었다. 이 화면 전체가 아니라 **환불 칸(표의 마지막 칸)과 그 확인 창**만 적는다 — 나머지는 승인된 시안
> `docs/design/mockups/site/v4/admin/payments.html` 이 기준이다. 보이는 조건은 카드 d126(사용자 「수정안으로」)에서 정했다.
> 역조공 관리(`/admin/revgifts`)의 환불 칸도 같은 규칙이다(사람 칸 이름이 「팬」, 금액이 목록에 없음).
> UX 기준 문서 중 `principles.md`·`admin-pages.md` 가 아직 없고, `states.md` 에도 환불 상태가 없다 — 상태 이름은 지금 화면의 배지(payments-panel 의 STATUS_TAG)를 그대로 옮겼다.

## 페이지 브리프

- 목적: 결제 내역을 보고, 돌려줄 돈을 환불하거나 결과를 적는다
- 주 사용자: 대표 / 부 사용자: 직원(보기만)
- 와서 하려는 일: 환불 대기·실패 줄을 찾아 환불하거나, 팬꾹 밖에서 돌려준 것을 완료로 적는다
- 방문 빈도: 환불이 생길 때마다
- 페이지 유형: 관리형(주) · 목록형(부)
- 같은 유형의 다른 페이지: 역조공 관리, 문의 관리
- 이 페이지만의 특이점: 돈이 나가는 버튼이 있다 — 누르는 사람은 대표뿐이고 금액은 서버가 정한다
- 바꾸면 안 되는 것: 금액 입력 칸이 없다(INV-K7) · 직원에게는 버튼 자체가 없다(INV-K2)

## 상태표 (환불 칸)

| 상태 (코드 · 화면 표기) | 조건 | 보이는 요소 | 가능한 동작 | 다음 상태 |
|---|---|---|---|---|
| `none` · 환불 없음 | 돌려줄 돈 없음 | 없음 | — | — |
| `due` · 환불 대기 | 돌려줄 돈이 있고 아직 누르지 않음 | 「환불」 | 환불 실행 | requesting → done / failed |
| `requesting` · 처리 중 | 눌렀고 결과를 아직 모름 | 「직접 환불함」 (지금 바뀌는 것) | 직접 환불 적기 — 누른 지 2분 안이면 거부 문구 | done |
| `failed` · 환불 실패 | 결제사 취소가 실패, 처음 누른 지 14일 안 | 「다시 시도」·「직접 환불함」 | 다시 시도 · 직접 환불 적기 | requesting / done |
| `failed` · 환불 실패 (14일 지남) | 결제사 취소가 실패, 처음 누른 지 14일이 지나 다시 시도가 막힘 | 「직접 환불함」만 | 직접 환불 적기 | done |
| `done` · 환불 완료 | 결제사 취소 성공 또는 직접 환불로 적음 | 없음 | — | — |

직원(`staff`)과 확인 필요 줄(`needsReview`)에는 어느 상태에서도 버튼이 없다.

## 요소 목록

| 요소 | 보이는 상태 | 경로 | 근거 |
|---|---|---|---|
| 「환불」 / 「다시 시도」 버튼 | due / failed 14일 안 (대표) | 정상 경로 | INV-K7, 시안 refund 창 |
| 「직접 환불함」 버튼 | failed / requesting (대표) | 예외 경로 — 결제사 취소가 안 된 때만 | INV-K7 S7d, 카드 d126 |
| 직접 환불 확인 창: 주문번호·사람·기록된 금액 | 버튼을 눌렀을 때 | 예외 경로 | 환불 창과 같은 모양 |
| 확인 창 안내: 결제사 관리 화면에서 먼저 확인 · 되돌릴 수 없음 | 같음 | 예외 경로 | INV-K7 (결제사에 닿지 못한 실패는 실제로 취소됐을 수 있음) |
| 메모 칸(1~200자, 글자 수) + 「이름·연락처·계좌번호는 쓰지 마세요.」 | 같음 | 예외 경로 | INV-K7, 개인정보 격리 |
| 거부 문구(메모 길이·숫자 10자리 이상·처리 중·이미 완료) | 서버가 거부했을 때 | 예외 경로 | S7e |

## 적용한 규칙

- 상태 이름은 지금 화면 배지(환불 대기·처리 중·환불 실패·환불 완료) 그대로다 — states.md 에 없어 「제안」에 해당한다.
- 예외 경로 요소(「직접 환불함」)는 기본 상태(due·none·done)에 보이지 않는다.
- 카드 d126 의 「14일이 지나 다시 시도가 막힌 기록은 직접 환불함만」은 목록이 그 줄을 알려 주게 해서 맞췄다(2026-10-24, S7f).
