# 차이 목록 — 약관 세 글(`/terms` · `/privacy` · `/refund`)

> 2026-10-23 문서형 페이지 2단계 중 약관 세 글 몫. 지금 모습은 `terms.md` · `privacy.md` · `refund.md` 의 「적용한 규칙」 표, 기준은 `docs/ux/document-pages.md`.
> 세 글은 한 부품(`src/widgets/legal/ui/policy-page.tsx` · `policy-toc.tsx` · `policy-page.module.css`)이 그린다. 그래서 대부분이 **공통 부품 문제**이고, 글마다 다른 것은 아래 「페이지 고유」에 따로 적었다.
> 「크기」: 추가 = 없던 요소를 새로 둠 · 숨김 = 있던 요소를 상태에 따라 감춤 · 구조 = 배치나 데이터 모양을 바꿈.
