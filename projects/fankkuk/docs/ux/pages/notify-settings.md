# 알림 설정 — 「선물 소식 바로 받기」 스위치

## 페이지 브리프

- 목적: 이 문서는 팬 계정 설정과 크리에이터 계정 설정의 「알림」 묶음에 스위치 하나를 더하는 것만 다룬다(나머지는 지금 그대로).
- 주 사용자: 팬 / 부 사용자: 크리에이터
- 하려는 일: 선물 소식(상자 도착·출고·배송·답장)을 바로 받을지, 하루 한 번 모아 받을지 고른다
- 방문 빈도: 드묾(설정)
- 유형: 관리형
- 같은 유형: 같은 묶음의 카카오톡·이메일 알림 스위치
- 특이점: 기본값이 꺼짐(하루 묶음)이다
- 바꾸면 안 되는 것: 카카오톡·이메일 스위치와 「끌 수 없는 알림」 안내, 저장 방식(팬은 아래 「저장」, 크리에이터는 누르는 즉시 저장 — 지금 화면 그대로)

## 지금 상태 (역진단)

- 팬(`src/widgets/my-info/ui/my-info-page.tsx`): 「알림」 묶음에 스위치 둘 — 「카카오톡 알림」(승인·배송 등 선물 관련 알림톡 수신), 「이메일 알림」(영수증·안내 메일 수신). 아래 「저장」으로 보낸다.
- 크리에이터(`src/widgets/creator-account/ui/creator-account-page.tsx`): 「알림」 묶음에 같은 두 칸, 누르는 즉시 저장, 실패하면 되돌림.
