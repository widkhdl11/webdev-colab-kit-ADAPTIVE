# 고객센터 UX 명세 — `/support`

## 페이지 브리프

1. 목적: 자주 묻는 질문을 먼저 찾아보게 하고, 없으면 1:1 문의를 남기게 한다.
2. 주 사용자 / 부 사용자: 로그인한 팬·크리에이터 / 로그인하지 않은 방문자(질문만 읽는다)
3. 사용자가 와서 하려는 일: 질문 분류를 골라 답을 읽는다 → 없으면 문의를 남기고, 나중에 「내 문의」에서 답변을 본다
4. 방문 빈도: 가끔 — 막혔을 때
5. 페이지 유형: 작업형(주 — 1:1 문의 양식) · 문서형(부 — 질문 묶음)
6. 같은 유형의 다른 페이지: `/report`(같은 칸 모양의 양식) · `/faq`(질문 묶음 — 두 곳 합치기는 BACKLOG)
7. 이 페이지만의 특이점: 문의는 로그인해야 남길 수 있다(결정 d25). 문의 제한이 걸린 회원은 양식 대신 안내를 본다(INV-K12)
8. 바꾸면 안 되는 것: 질문 분류 다섯과 질문 문장, 로그인 뒤 고객센터로 돌아오는 링크(`/login?next=/support`, session-login INV-L13), 문의 제한 안내, 연락처 값

## 상태표

| 상태(코드 식별자 / 화면 표기) | 조건 | 보이는 요소 | 가능한 동작 | 다음 상태 |
|---|---|---|---|---|
| `signed_out`(제안) / 로그인 전 | 쿠키 없음 | 머리 · 질문 탭 줄과 답 · 1:1 문의 크림 띠(제목·안내 한 줄·**「로그인하고 문의하기」 버튼 하나** — 입력 칸은 그리지 않는다) · 연락처 한 줄 | 질문 읽기, 버튼 → 로그인 화면 | 로그인 → `signed_in` |
| `signed_in`(제안) / 로그인 후 | 팬·크리에이터 로그인, 문의 제한 없음 | 위와 같고 크림 띠 안에 문의 양식(분류·주문번호(선택)·제목·내용·「문의 남기기」)과 「내 문의」 | 문의 남기기, 내 문의 펼치기 | 보냄 → 같은 상태(완료 안내 + 내 문의에 추가) |
| `restricted`(제안) / 문의 제한 | 로그인 + 문의 제한(INV-K12) | 크림 띠 안에 양식 대신 제한 안내, 「내 문의」 | 내 문의 펼치기 | — |
| 내 문의 없음 | 로그인 + 남긴 문의 0 | 「아직 남긴 문의가 없어요.」 | — | 문의를 남기면 목록 |
