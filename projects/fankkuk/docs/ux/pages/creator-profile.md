# 크리에이터 프로필 수정 — 프로필 · 채널 두 탭 (2026-11-13 같은 날 고침: 계정 탭 없앰)

## 페이지 브리프

- 목적: 크리에이터가 바꾸는 설정을 「남에게 보이는 나(프로필)」「내 채널(채널)」로 나눠 찾기 쉽게 한다 — 비밀번호·휴대폰·회원 탈퇴는 「계정 설정」(옛 상세 설정)에 둔다
- 주 사용자: 크리에이터 / 부 사용자: 없음
- 하려는 일: 프로필 사진·닉네임·소개를 고친다 · 채널의 모양(배경·색·팬덤)과 주소를 정한다
- 방문 빈도: 드묾(설정)
- 유형: 관리형
- 같은 유형: 계정 설정(옛 상세 설정) · 알림 설정
- 특이점: 구역마다 저장 방식이 다르다(사진은 고르는 즉시, 글 칸은 「저장」, 주소는 확인 창) — 옮겨도 그대로 둔다
- 바꾸면 안 되는 것: 각 구역의 입력 칸·저장 방식·안내 문구·확인 창, 팬 쪽 「프로필 수정」, 링크 미리보기 이미지 고르기의 즉시 저장

## 적용한 규칙

- 관리형 화면 — 구역마다 저장 방식을 바꾸지 않는다(브리프 「바꾸면 안 되는 것」).
- 탭을 주소에 실어 이름 메뉴·다른 화면 안내 링크가 원하는 탭을 바로 연다(되돌리기 쉬운 본체 결정).
