# 크리에이터 페이지 UX 명세 — `/[handle]` · `/creators/[id]`

이번에 바꾸는 것은 **탈퇴한 크리에이터의 상태 하나**다. 선물을 받는 크리에이터의 화면(지금 모습)은 건드리지 않아서, 그 상태는 한 줄로만 적었다.

## 페이지 브리프

1. 목적: 팬이 링크 주소로 들어와 그 크리에이터에게 선물을 보내기 시작한다
2. 주 사용자 / 부 사용자: 팬 / 크리에이터 본인(자기 페이지 확인)
3. 사용자가 와서 하려는 일: 이 크리에이터가 맞는지 보고 「선물 보내기」를 누른다
4. 방문 빈도: 크리에이터가 링크를 올릴 때 몰려서, 팬마다 선물 보낼 때 한 번
5. 페이지 유형: 상세형 — 크리에이터 한 명의 정보와 그 사람에게 하는 동작 하나
6. 같은 유형의 다른 페이지: 보낸 선물 상세(`/gifts/[orderNo]`)
7. 이 페이지만의 특이점: 링크 주소(`/아이디`)와 옛 주소(`/creators/ID`) 두 길로 같은 화면이 열린다
8. 바꾸면 안 되는 것: 선물 받는 크리에이터의 화면 구성

## 상태표

| 상태(코드 식별자 / 화면 표기) | 조건 | 보이는 요소 | 가능한 동작 | 다음 상태 |
|---|---|---|---|---|
| `default` / (표기 없음) | 본인 확인을 마친 크리에이터 | 지금 화면 그대로 | 지금 그대로 | — |
| `withdrawn` / 활동 종료 (제안) | 그 링크 주소·ID 의 크리에이터가 탈퇴함 | 상단 바 · 제목 「활동 종료」 · 「홈으로」 버튼 · 바닥글 | 홈으로 | 끝 |
| `not_found` / 페이지를 찾을 수 없어요 | 없는 주소, 본인 확인 전 | 지금 「없는 페이지」 화면 그대로 | 홈으로 · 고객센터 | — |

## 요소 목록 (`withdrawn` 만)

| 요소 | 보이는 상태 | 정상 경로 / 예외 경로 | 근거 |
|---|---|---|---|
| 제목 「활동 종료」 | withdrawn | 예외 | 사용자 지시(2026-10-23), 승인된 상태 화면 부품(용어집 13절과 같은 틀) |
| 「홈으로」 버튼 | withdrawn | 예외 | 없는 페이지 화면과 같은 첫 버튼 |
| 크리에이터 이름·사진·소개·「선물 보내기」 | 없음 | — | 탈퇴 때 지운 정보(my-account INV-A15)라 보일 것이 없고, 선물을 보낼 수 없다(approval-signature INV-S15) |
| 설명 문장 | 없음 | — | 시안에 없는 안내 문장을 덧붙이지 않는다 |
