# 자동 처리 현황 UX 명세 — `/admin/automation` (배송 조회 칸만)

> 2026-11-09 배송 조회 서비스 연결(DECISIONS 「배송 현황 표시·조회 연동」 ⑨ — 「웹훅이 24시간 갱신 없으면 운영자 화면 경고, 운영자 화면에 수동 조회 버튼」)을 넣으며 처음 만들었다.
> 이 화면 전체가 아니라 **새로 생긴 「배송 조회」 칸**만 적는다. 나머지 칸은 시안 `admin/automation.html` 과 지금 코드가 기준이다(바뀌지 않음).
> 사용자 결정(⑨)을 받아적은 것이라 승인 카드는 열지 않는다.
> 지금 모습(역진단): 맨 위부터 「승인 서명 없이 열린 주소」 경보 → 알림 보내기 → 보내지 못한 알림 → 기한 묶음 넷. 칸마다 제목 줄(건수 꼬리표) + 한 줄 설명 + 표.
> 바뀌는 것: 「승인 서명 없이 열린 주소」 바로 아래에 「배송 조회」 칸이 생긴다 — 경보 칸과 같은 모양(경고면 빨간 줄, 아니면 한 줄 설명).
> UX 기준 문서 중 `principles.md`·`admin-pages.md`(관리형)가 아직 없다 — 같은 화면의 경보 칸 모양을 따른다.

## 페이지 브리프

- 목적: 정해진 때에 저절로 도는 일이 제대로 도는지 보고, 막힌 것을 손으로 돌린다
- 주 사용자: 대표 / 부 사용자: 직원
- 와서 하려는 일: 경보·경고가 있는지 보고, 있으면 그 줄에서 바로 처리한다
- 방문 빈도: 하루 한두 번
- 페이지 유형: 관리형(주)
- 같은 유형의 다른 페이지: 결제 관리, 배송문제 확인
- 이 페이지만의 특이점: 경보·경고가 없을 때는 칸마다 한 줄만 보인다
- 바꾸면 안 되는 것: 송장번호 전체·배송 이력(대리점·기사·수령인)은 운영자 화면에도 내지 않는다(delivery-status INV-DS10)

## 상태표 (배송 조회 칸)

| 상태 (코드 · 화면 표기) | 조건 | 보이는 요소 | 가능한 동작 | 다음 상태 |
|---|---|---|---|---|
| `none` · 살펴볼 송장 없음 | 아직 배달 완료가 아닌 송장 중 구독 대기도, 24시간 넘게 멈춘 것도 없음 | 제목 「배송 조회」 + 「0건」, 「살펴볼 송장이 없어요.」 | 없음 | — |
| `pending` · 구독 대기만 | 구독을 기다리는 송장만 있음 | 「24시간 넘게 상태가 멈춘 송장은 없어요.」, 「구독을 기다리는 송장 N건 — 10분마다 다시 보내요.」, 표(조회 버튼 없음) | 없음(예약 작업이 보낸다) | none · stale |
| `stale` · 경고 | 구독한 송장 중 마지막 수신이 24시간 넘음 | 제목 줄 「경고 N건」 꼬리표, 빨간 경고 줄, 2건 이상이면 「경고 N건 모두 조회」, 표의 그 줄에 「24시간 넘음」·「수동 조회」 | 줄마다 수동 조회 · 모두 조회(50건까지) | none(배달 완료·상태 들어옴) |

## 요소 목록

| 요소 | 보이는 상태 | 경로 | 근거 |
|---|---|---|---|
| 경고 줄(빨간, `role=alert`) | stale | 예외 경로 | INV-DS14 |
| 「경고 N건 모두 조회」 | stale, 2건 이상 | 예외 경로 | INV-DS14(한 번에 50개까지) |
| 표: 종류 · 송장 끝 4자리 · 택배사 단계 · 구독 · 마지막 수신 | pending · stale | 정상 경로 | INV-DS10(끝 네 자리만) |
| 줄의 「수동 조회」 | 구독한 줄(stale 이 아니어도 목록에 있으면) | 예외 경로 | INV-DS14 |
| 조회 결과 한 줄(「N건 받음」 / 실패 문구) | 수동 조회 뒤 | 예외 경로 | INV-DS14 — 수만, 송장번호 없음 |

## 적용한 규칙

- 같은 화면 「승인 서명 없이 열린 주소」 칸과 같은 모양: 경고가 있을 때만 빨간 줄, 없으면 설명 한 줄.
