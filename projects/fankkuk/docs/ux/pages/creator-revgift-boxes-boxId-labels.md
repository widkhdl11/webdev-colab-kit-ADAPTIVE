# 번호 라벨 UX 명세 — `/creator/revgift-boxes/[boxId]/labels`

근거: 선물함 흐름 명세 `creator-revgifts-new.md` 「3페이지」(번호 라벨 PDF 받기)·「정한 것 ⓒ」. 2026-11-09 선물함 3부 구현 때 새로 적었다.
「PDF」는 인쇄 화면으로 했다 — 브라우저 인쇄 창에서 PDF 로 저장할 수 있다. 사용자 승인 전이다 — 승인되면 approved.

## 페이지 브리프

1. 목적: 담길 팬마다 붙일 번호 라벨(닉네임 + 바코드)을 인쇄한다
2. 주 사용자 / 부 사용자: 선물함 주인 크리에이터 / 사무실(라벨을 스캔해 팬을 찾고 그대로 사무실 라벨로 쓴다)
3. 사용자가 와서 하려는 일: 3페이지에서 들어와 인쇄하고 선물에 붙인다
4. 방문 빈도: 선물함 하나에 한 번
5. 페이지 유형: 문서형(인쇄물)
6. 같은 유형의 다른 페이지: 검수 완료 카드 인쇄(`/admin/work/inspection-card`)
7. 이 페이지만의 특이점: 인쇄용이라 사이트 머리·바닥이 없다. 인쇄할 때는 돌아가기 링크·제목·인쇄 버튼도 빠지고 라벨만 찍힌다
8. 바꾸면 안 되는 것: 라벨에는 닉네임과 바코드(신청 번호)뿐 — 주소·받는 분 이름·전화·6자리가 없다(INV-GB9)

|---|---|---|---|---|
| `labels`(제안) / 번호 라벨 | 선물함 주인 · 팬꾹으로 배송하기부터 | 돌아가기(선물함 이름) · 「번호 라벨」 · 「인쇄」 · 라벨 칸(닉네임 · 바코드 · 신청 번호 글자) 담길 팬마다 | 인쇄 | — |
