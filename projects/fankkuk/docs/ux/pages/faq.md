# 자주 묻는 질문 UX 명세 — `/faq`

> 2026-10-23 문서형 페이지 정돈 1단계. 코드를 읽고 **지금 구현된 그대로** 적었다. 바꿀 것은 `docs/ux/pages/_diff-faq-report.md` 에 따로 있다.
> design-rules 28절(2026-10-22 승인 시안 — 「먼저 알아 두세요」 판·펼친 답 680·첫 줄 펼침)은 아직 코드에 들어가지 않았다. 이 문서의 「지금」은 그 이전 모습이다.

## 페이지 브리프

1. 목적: 팬꾹을 쓰다 막힌 사람이 고객센터에 묻기 전에 자기 질문과 같은 항목을 찾아 답을 읽는다.
2. 주 사용자 / 부 사용자: 팬(가입 전 포함) / 크리에이터 — 11문항 중 크리에이터 질문은 둘(승인 방법·역조공 요금)뿐이다
3. 사용자가 와서 하려는 일: 내 질문과 같은 항목을 찾아 펼쳐 읽는다
4. 방문 빈도: 처음 보내기 전, 또는 거절·환불·주소 문제가 생겼을 때 한 번
5. 페이지 유형: 문서형 — 입력 없이 읽기만 하고, 질문 줄을 펼쳐 답을 찾는다
6. 같은 유형의 다른 페이지: 이용 안내(팬·크리에이터)·검수 기준·보안 안내·분쟁 처리 안내·요금 안내·약관 세 글. 같은 질문 묶음이 고객센터(`/support`)에도 따로 있다(탭 5분류 15문항 — BACKLOG 346줄)
7. 이 페이지만의 특이점: 조(섹션) 대신 접기 줄이 단위다. 요금 숫자는 DB 공개 요금표를 읽는다(`src/app/(site)/faq/page.tsx:16`). 답 두 개에 「[확인 필요: …]」 글자가 그대로 보인다(`faq-doc.ts:32`·`:64` — 글 내용이라 이번 범위에서 고치지 않는다)
8. 바꾸면 안 되는 것: 질문·답 문장, 요약 세 줄(`faq-doc.ts:20-24`), 요금 숫자를 코드에 쓰지 않는 규칙
