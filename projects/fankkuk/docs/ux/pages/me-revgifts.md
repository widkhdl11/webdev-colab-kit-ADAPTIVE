# 받은 선물 UX 명세 — `/me/revgifts`

> 2026-11-18 작성. 이 화면의 명세가 없어서 코드(`src/widgets/my-revgifts/ui/my-revgifts-panel.tsx`)를 읽어 지금 모습을 먼저 적고(역진단), 같은 날 사용자가 시안 비교에서 고른 배치(작은 타일, design-rules 45절)를 「바뀌는 것」에 적었다. 2026-11-18 사용자 승인(타일에서 주문번호·상자 크기·기한 날짜를 빼는 것 포함).

## 페이지 브리프

1. 목적: 크리에이터가 내게 보낸 선물(역조공)을 받을지 정하고, 받은 선물이 어디까지 왔는지 본다.
2. 주 사용자 / 부 사용자: 팬 / 없음(크리에이터는 크리에이터 홈으로 보냄)
3. 사용자가 와서 하려는 일: 받을지 정해야 하는 선물을 찾아 「확인하기」로 들어간다 · 진행 중인 선물의 상태를 본다 · 끝난 선물을 다시 찾는다
4. 방문 빈도: 크리에이터가 선물을 보냈다는 알림을 받은 뒤 며칠 동안(받을지 정하는 기한 안)
5. 페이지 유형: 목록형 — 같은 종류 항목(받은 선물)을 상태로 나눠 고르게 한다
6. 같은 유형의 다른 페이지: 보낸 선물(`/gifts`), 물품 보관소
7. 이 페이지만의 특이점: 받을지 정하는 기한이 있어 「남은 날」이 가장 중요한 값이다. 사진이 거의 없다(크리에이터 기본 얼굴만).
8. 바꾸면 안 되는 것: 탭 이름 「받는 중」·「완료」와 나눔, 상태 8종 문구, 「확인하기」가 상세의 지금 할 일 칸으로 가는 것, 완료 탭 아래 안내 문단
