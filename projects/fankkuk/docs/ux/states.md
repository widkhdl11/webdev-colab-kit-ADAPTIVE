# 상태 정의 — UX 정돈 시범 (2026-10-22)

**범위: 시범 세 화면만.** 보낸 선물(목록 `/gifts`·상세 `/gifts/{주문번호}`), 지금 할 일(`/me/actions`), 선물 보내기(`/gifts/new`).
다른 화면(받은 선물·함께한 시간·크리에이터 화면)에 나오는 상태는 적지 않았다.

- 「마이꾹(보낸 선물)」은 코드를 따라가 보니 `/gifts`(목록)와 `/gifts/{주문번호}`(상세)다. `/me` 는 「내 정보」(계정·받을 주소) 화면이라 이번 범위에서 뺐다.
- 크리에이터 쪽 `/creator/actions` 는 팬 화면과 다른 위젯(`widgets/creator-action-center`)이라 이 문서에 넣지 않았다. 크리에이터 계정이 보낸 선물의 줄(추가 결제·도착하지 않은 상자·결제 미완료)은 팬과 같은 상세 칸을 쓰므로 아래 표가 그대로 맞는다.
- 상태 이름이 코드·DB 에 있으면 그 이름을 그대로 쓰고 출처를 적었다. 없으면 「(제안)」이다. 한글 라벨은 `docs/copy/glossary.md` 표기이고, 지금 화면 글자와 용어집이 다르면 둘 다 적었다.
- 「보이는 요소」는 지금 코드 기준이다. 바꿀 점은 `diagnosis-2026-10-22-pilot.md` 에 있다.

## 4. 지금 할 일 항목 (팬)

항목은 저장된 목록이 아니라 DB 읽기 함수 `my_action_items` 가 원천 상태에서 매번 계산한 줄이다(`src/entities/action-item/model/action-items.ts:4`). 종류 칸은 `kind`(같은 파일 8~27줄).
항목 자체의 상태는 둘뿐이다: **줄이 있음(해야 함)** / **줄이 없음(끝남 또는 기한 지남)**. 줄은 누른 기록이 아니라 원천 상태가 바뀌어야 사라진다.

|---|---|---|---|---|---|
