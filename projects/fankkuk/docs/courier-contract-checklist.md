# 택배사 계약 확인 항목

택배사와 계약을 협의할 때 받아야 하는 것들이다. 항목마다 그것이 없으면 사이트에서 무엇이 안 되는지를 옆에 적었다.
흩어져 있던 「택배사 계약 뒤」 메모를 2026-11-06 한곳에 모았다.
2026-11-09 로지아이 답을 받아 표의 「로지아이 답」 칸과 아래 「로지아이 답 (2026-11-09)」을 채웠다(DECISIONS 2026-11-09 「로지아이 답 반영」).

| # | 확인 항목 | 없으면 | 근거 | 로지아이 답 (2026-11-09) |
|---|---|---|---|---|
| 1 | 송장 발급 API — 운송장 번호와 라벨 내용을 API 로 받기 | 지금처럼 사무실이 화면 인쇄로 라벨을 붙인다. 운송장 번호는 개발용 생성값이다 | first-release-overview 12번 | 없음 — 송장출력 페이지·엑셀 일괄 예약접수만. 출력 방식은 수동 입력, 다음은 엑셀 반자동 |
| 2 | **수취인 안심번호 제공** — 송장의 받는 사람 번호를 050 등 안심번호로 찍어 주기(운송장 발급과 함께 받기) | 라벨에 받는 사람의 실제 번호가 찍힌다. 계약에 들어가면 설정값을 「안심번호」로 바꾼다 — 바꾸기 전에 안심번호 받기 연결이 있어야 한다(없으면 송장 출력이 시작되지 않는다) | address-protection INV-P19 · `src/shared/config/courier.ts` | 발급 없음. 이미 받은 안심번호를 엑셀에 넣는 것은 된다 — 엑셀 전화 칸 설정값(실제 번호 / 안심번호 API 결과), 지금 실제 번호 |
| 3 | 집하 확인 — 기사가 상자를 가져간 시각을 API 로 받기 | 출고 뒤 재출력 잠금과 주소 복사본 지우기를 「출고·반송 확정 + 72시간」으로 대신한다 | address-protection INV-P5·P18 | 답 없음(API 없음). 배송 상태는 택배API(송장번호 조회·웹훅)로 받는다 |
| 4 | 배송 상태(배송중·수령) 받기 | 상태 화면의 배송중·수령이 바뀌지 않는다. 오래 안 바뀐 상자를 「배송문제 확인」에 띄울 수 없다 | first-release-overview 10·19번 · BACKLOG 「배송이 완료되지 않는 경우」 | 답 없음(API 없음). 택배API 로 받는다(DECISIONS 2026-11-09 「배송 현황 표시·조회 연동」) |
| 5 | 크기 구간별 단가(소형·중형·대형) | 요금표의 「택배 원가」 칸이 가정값(소형 4,000 · 중형 5,000 · 대형 6,500원)이다. **2026-11-07 로지아이 CJ 소호사업자택배 A등급 기준값 2,990(80cm·2kg) / 3,490(100cm·5kg) / 4,390(120cm·10kg) / 5,500(140cm·15kg)으로 요금을 정했다 — 계약서의 실제 등급·단가로 확인 필요** | DECISIONS 2026-11-07 「요금 11-07 최종」 | 월 30건 기준·최초 A등급 — 2,990 / 3,490 / 4,390 / 5,500. 기본 경로 확정, 값은 대표가 /admin/pricing 에서 확인 |
| 6 | 반송 택배 단가와 선불 반송 처리 | 반송 택배비를 가정값으로 뺀다 | DECISIONS 2026-10-17 | 답 없음 — 다시 물어볼 것 |
| 7 | 방문수거 가능 여부·원가 | 합포장 중계·집에서 보내기를 설계할 수 없다 | BACKLOG 「역조공 합포장 중계」 | 답 없음 — 다시 물어볼 것 |
| 8 | 송장 출력 방식 — API 를 주는지, 엑셀 일괄 업로드·송장번호 엑셀 내려받기를 지원하는지 | 어댑터 설정값을 「수동 입력」(건별)으로 둔다. 엑셀 반자동은 주소 보호 스펙 개정 뒤 | DECISIONS 2026-11-07 송장 출력 어댑터 | 엑셀 일괄 예약접수 있음 — 양식 파일은 대표가 준다. 당일 03시까지 예약분 당일 집하, 토요일 집하 가능 |
