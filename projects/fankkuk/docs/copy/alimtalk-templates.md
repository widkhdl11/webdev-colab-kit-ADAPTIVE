# 카카오 알림톡 템플릿 — 솔라피에 올릴 본문 (2026-10-29 초안)

솔라피 콘솔 → 카카오 알림톡 → 템플릿 등록에 이 본문을 **그대로** 붙여 넣는다. 알림톡은 등록한 본문과 글자 하나·줄바꿈 하나까지 같아야 나가므로,
코드는 아래 `#{변수}` 자리만 채워 보낸다(notifications INV-N1·N7). 본문을 고치면 이 문서와 코드(`src/features/notification-dispatch/lib/alimtalk-body.ts`)를 같이 고치고 다시 검수받는다.

- 템플릿 유형: 기본형(정보성). 인증번호만 「인증」 분류 + 보안 템플릿.
- 버튼은 모두 「웹 링크」. 모바일·PC 주소 둘 다 같은 값.
- 검수 승인 뒤 받은 템플릿 ID: 인증번호는 Vercel 환경 변수 `SOLAPI_PHONE_CODE_TEMPLATE_ID`, 나머지는 DB 표 `notification_kakao_templates` 에 종류(`kind`)별로 넣는다.
  넣지 않은 종류는 지금처럼 이메일로만 간다.

---

## 1. 인증번호 (`SOLAPI_PHONE_CODE_TEMPLATE_ID`)

- 분류: 인증 · 보안 템플릿 체크
- 변수: `#{인증번호}` — 6자리 숫자
- 버튼: 없음

```
[팬꾹] 인증번호 #{인증번호}

3분 안에 입력해 주세요.
```

알림톡이 실패하면 같은 번호가 문자로 간다: `[팬꾹] 인증번호 123456 (3분 안에 입력해 주세요)` (signup INV-U15).

## 2. 승인 요청 도착 (`approval_request`) — 크리에이터

- 변수: `#{닉네임}` 받는 크리에이터 · `#{보낸사람}` 보낸 팬 닉네임 · `#{선물종류}` 목록 값 · `#{개수}` 상자 수 · `#{주문번호}` · `#{기한}` 자동 반려 예정 시각(「10월 8일 오전 10시」 꼴)
- 버튼: [승인 화면 열기] → `https://fankkuk.com/creator/actions?order=#{주문번호}`
- 세 차례(결제 직후 · 첫 상자 입고 · 72시간 뒤) 모두 이 템플릿 하나다. 이메일 제목만 차례마다 다르다.

```
#{닉네임}님, 승인 요청이 도착했어요.

보낸 사람: #{보낸사람}
선물: #{선물종류} #{개수}개
주문번호: #{주문번호}

#{기한}까지 승인하지 않으면 자동 반려됩니다.

서비스 이용에 필요한 필수 알림으로, 수신 설정과 관계없이 발송됩니다.
```

## 3. 상자 도착 (`box_arrived`) — 보낸 팬 (역조공이면 보낸 크리에이터)

- 변수: `#{닉네임}` · `#{주문번호}` · `#{경로}` (팬 `/gifts/FC-…`, 역조공 `/creator/revgifts`)
- 버튼: [상자 확인하기] → `https://fankkuk.com#{경로}`

```
#{닉네임}님,
보내신 상자 하나가 팬꾹에 도착했습니다.
주문번호 #{주문번호}

선물 상세 정보는 알림에 표시하지 않습니다. 로그인 후 아래 버튼에서 확인해 주세요.
알림 수신 여부는 ‘계정 설정 > 알림’에서 변경할 수 있습니다.
```

- 버튼: [선물 보기] → `https://fankkuk.com/gifts/#{주문번호}`

## 5. 배송 중 (`in_transit`) — 보낸 팬

- 변수: `#{닉네임}` · `#{주문번호}`
- 버튼: [선물 보기] → `https://fankkuk.com/gifts/#{주문번호}`
- 택배사 연결 전이라 아직 이 알림이 생기는 사건이 없다(INV-N12). 미리 검수만 받아 둔다.

```
#{닉네임}님,
보내신 선물이 배송 중입니다.
주문번호 #{주문번호}

선물 상세 정보는 알림에 표시하지 않습니다. 로그인 후 아래 버튼에서 확인해 주세요.
알림 수신 여부는 ‘계정 설정 > 알림’에서 변경할 수 있습니다.
```

## 6. 수령 완료 (`delivered`) — 보낸 팬

- 변수: `#{닉네임}` · `#{주문번호}`
- 버튼: [선물 보기] → `https://fankkuk.com/gifts/#{주문번호}`
- 택배 배송 완료 사건이다(택배사 연결 뒤 생긴다). 크리에이터가 「받았어요」를 누를 때 가는 알림(`gift_received`)은 따로 있다 — 같은 틀에 둘째 줄만 「크리에이터가 선물 수령을 확인했습니다.」로 바꿔 하나 더 올리면 된다.

```
#{닉네임}님,
보내신 선물의 배송이 완료되었습니다.
주문번호 #{주문번호}

선물 상세 정보는 알림에 표시하지 않습니다. 로그인 후 아래 버튼에서 확인해 주세요.
```
