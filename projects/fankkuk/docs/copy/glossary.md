# 팬꾹 용어집 (docs/glossary.md)

화면에 보이는 한국어 문구를 쓰기 전에 반드시 읽는다. 개념 하나에 표기 하나다. 보는 사람이 다르면 표기가 달라도 되지만, 같은 열 안에서는 한 가지만 쓴다.

## 읽는 법

- **코드 식별자**: 이번에는 바꾸지 않는다. 식별자를 한국어로 옮기지 말고 이 표의 화면 표기를 쓴다.
- **팬·크리에이터 화면**: 해요체. 풀어 쓴 말을 쓴다. 단 가입·로그인·계정 화면(문구 2)과 팬 화면(문구 3 — 선물 보내기·보낸 선물·선물 상세·함께한 시간·할 일·팔로우·받은 선물, 2026-10-26 다듬은본 적용)은 결과·제한 안내 「~습니다」, 행동 요청 「~해 주세요」, 확인 질문 「~할까요?」 — 아래 문장 규칙의 2026-10-26 줄.
- **운영자 화면**: 사무실에서 쓰는 짧은 말. 한자어 허용.
- **약관·방침**: 공정위 표준약관 문체. 「회사」「회원」「~합니다」.
- **쓰지 않는 말**: 어느 열에서도 쓰지 않는다. 금지어 검사의 대상이다.
- 짧은 라벨(배지·표 머리·단계 이름)은 한자어 허용, 문장은 풀어 쓴다. 예: 라벨 「반송」, 문장 「돌려보내 드려요」.
- 「(결정 필요)」가 붙은 행은 Howlyn이 정한 뒤 고친다.

### 문장 규칙 (다른 문서에서 옮김)

- 문구는 두 갈래다. **보여주는 문구**(랜딩·팬꾹 소개·메인 큰 판·검색 설명·공유 미리보기·크리에이터 페이지 상단·요금 카드)는 권유 한 문장 + 보장 한 문장, 방법·절차는 쓰지 않거나 한 구절로 끝낸다. **쓰는 문구**(폼·버튼·오류·상태 이름·알림·고객센터 답)는 해요체로 짧게. (v2 1절)
- 약속 문장 세 개(승인·주소·검수, 보조 문장 포함)는 어느 화면에서나 같은 글자로 쓴다. 풀어 쓰지 않는다. 글자는 `shared/config/site-copy.ts` 상수가 정본이다. (v2 1·2절)
- 문체는 업계 표준을 따른다: 화면·안내 글·고객센터·알림은 해요체, 약관·개인정보처리방침·환불 규정만 「~합니다」. 약속 문장도 해요체다. 약관류는 약속 문장 상수를 끌어 쓰지 않고 자기 문체로 따로 적는다. (2026-10-24 사용자 「해요/합니다 체는 업계 표준에 맞게」 — 그 전에는 약속 문장만 합니다체였다)
- 2026-10-26 사용자가 화면별 다듬은본 다섯 묶음(1 공개 · 2 가입·로그인·계정 · 3 팬 · 4 크리에이터 · 5 공통)을 주고 「문구2 만 교체, 1·3·4·5 는 나중에」. 다듬은본 문체는 결과·제한 안내 「~습니다」, 행동 요청 「~해 주세요」, 확인 질문 「~할까요?」다. 지금은 2·3번 묶음 화면이 이 문체이고 나머지는 해요체(3번 안에서도 크리에이터가 골라 보내는 감사 답장은 해요체) — 묶음이 적용될 때마다 이 줄을 고친다. 문구의 정본은 그 다듬은본(`external-material-box/문구다듬기v2/`)이다.
- 한 문장에 주어를 둘 두지 않는다. 「팬꾹도 ~, 팬에게는 ~」처럼 주체를 나누면 설명조가 된다. (v2 1절)
- 화면 문구는 흔한 쇼핑·배송 사이트가 그 자리에 쓰는 짧은 말로 쓴다. 스펙·DB 용어(몫·잇다·매칭)를 화면으로 옮기지 않는다. (design-rules 6-1)
- 상태는 설명하는 문장 대신 짧은 이름으로 보여 준다. (design-rules 6-1)
- 시안에 없는 안내 문장은 덧붙이지 않는다(예: 프로필 수정의 「모두에게 보여요」 같은 공개 범위 안내). (design-rules 6-1)
- 화면에서는 기술 용어(「브라우저」「인증서」「서명」 등)를 빼고 쉬운 말로 쓴다 — 약관·방침은 처리 방식을 정확히 적는 자리라 예외. (v2 3-3 흐름 1·3)
- 확인 표시는 확인한 사실만 말한다. (design-rules 6절)
- 경쟁 서비스 이름은 쓰지 않는다. (design-rules 6절)
- 존댓말, 짧은 문장, 한 문장에 한 가지. 번역투·과장 금지. 버튼은 동사(「~하기」)로 끝낸다. (copy-review 「판단 기준」 — 사용자가 준 톤 기준 요약)

|---|---|
| ~의 모양이 다르다 | ~의 형식이 다르다 |

| 응답 꼴 | 응답 형식 |
| DB 가 ~를 거부했다 | DB 가 ~를 받지 않았다 |
| ~ 줄(DB 행을 뜻할 때) | ~ 기록 |
| ~ 판(버전을 뜻할 때) | ~ 버전 |

## 10. 결정 필요

Howlyn이 정하면 표와 금지어 목록을 고친다.

1. 운영자 화면 이름을 「운영자」로 바꾸면 메뉴·탭 제목이 모두 바뀐다. 「관리자」를 남길지. (이 용어집은 「운영자」로 통일)
2. 팬 화면 6단계 라벨(등록→입고→검수→출고→배송 중→수령)을 그대로 둘지, 「도착·배송 중·받음」으로 풀어 쓸지. → **정함(2026-10-16 사용자 「추천대로」): 라벨은 그대로 두고 문장만 풀어 쓴다.**
3. 약관의 「거절·자동 반려」 같은 한자어는 그대로 둔다. 약관 문체를 해요체로 바꾸지 않는다.
