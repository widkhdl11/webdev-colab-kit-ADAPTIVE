# 사이트 문구 수정안 v2 — fankkuk

> copy-review.md(2단계)를 사람이 한 번 더 다듬은 판. (2026-10-12 사용자 작성, 「문구들을 이렇게 바꿔보자」로 전달)
> **이 파일에 있는 줄은 copy-review.md의 같은 위치 줄을 덮어쓴다.** 여기에 없는 줄은 copy-review.md 수정안을 그대로 따른다.
> 승인 표시는 copy-review.md와 같다: ✅ · ✏️ + 고칠 말 · ❌. 비워 둔 줄은 반영하지 않는다.
> 위치의 줄 번호는 작성 시점 기준이다 — 코드가 그 뒤 바뀌어 몇 줄 밀린 곳이 있다(예: 랜딩 요금 카드 배지는 지금 185줄).

## 1. 톤 기준 — 두 갈래로 나눈다

| 갈래 | 어디 | 말투 | 쓰는 법 |
|---|---|---|---|
| **보여주는 문구** | 랜딩, 팬꾹 소개, 메인 큰 판, 검색 설명(metadata), 공유 미리보기, 크리에이터 링크 페이지 상단, 요금 카드 | 마케팅 톤 | 권유 한 문장 + 보장 한 문장. 방법·절차는 쓰지 않는다. 쓰더라도 한 구절로 끝낸다 |
| **쓰는 문구** | 폼, 버튼, 오류, 상태 이름, 알림, 고객센터 답 | 해요체, 짧게 | copy-review.md 수정안을 따른다 |

공통 규칙:

1. 아래 2절의 **약속 문장 세 개는 어느 화면에 나오든 같은 글자로 쓴다**(합니다체). 약속 문장을 해요체로 바꾸거나 다른 말로 풀어 쓰지 않는다.
2. 약속 문장 밖의 문장은 해요체로 쓴다.
3. 한 문장에 주어를 둘 두지 않는다. 「팬꾹도 ~, 팬에게는 ~」처럼 주체를 나눠 설명하면 설명톤이 된다.
4. 「팬꾹도 주소를 열지 않아요」, 「저희 시스템이」 같은 말은 사이트 어디에도 쓰지 않는다. 약속 문장 2로 바꾼다.

## 2. 약속 문장 — 고정 문구

| 약속 | 문장 (그대로 씀) | 짧은 꼴 (배지·제목 옆) |
|---|---|---|
| 1. 승인 | 크리에이터가 승인한 선물만 배송합니다. | 승인한 선물만 배송 |
| 2. 주소 | 승인 전까지 주소는 노출되지 않습니다. | 승인 전 주소 비공개 |
| 2-팬 | 크리에이터 주소는 팬에게 공개되지 않습니다. | — |
| 3. 검수 | 모든 선물은 팬꾹에서 검수한 뒤 보냅니다. | 모든 선물 검수 |
| 3-보조 | 탐지기 반응이 있으면 개봉 검수합니다. | — |

- 약속 2는 디자인 기준 6절(「절대 유출되지 않습니다」·「저희도 열 수 없습니다」 금지)과 부딪히지 않는다. 「승인 전까지」로 범위를 정했고, 승인 뒤 송장 출력 때 열리는 것과 어긋나지 않는다.
- 약속 2-팬은 팬 화면에서만 약속 2 뒤에 붙이거나 대신 쓴다.
