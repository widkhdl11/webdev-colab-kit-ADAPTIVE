# 팬꾹 알림톡 템플릿 문구 수정안

작성일: 2026-10-29

솔라피 등록을 준비하기 위한 문구 수정안이다. 기존 등록용 문서와 발송 코드에는 아직 반영하지 않았다. 실제 등록·발송에 사용하기 전에 등록 본문, 버튼 문구, 버튼 주소와 발송 설정을 함께 맞춘다.

## 공통 안내

- 아래 코드 블록이 템플릿 본문이다. 제목과 설명은 본문에 포함하지 않는다.
- `#{변수}` 표기는 그대로 두고, 발송할 때 해당 값을 채운다.
- 버튼이 있는 템플릿은 웹 링크를 사용하며, 모바일·PC 주소를 동일하게 설정한다.
- 선물 내용, 보낸 팬의 닉네임, 상대방의 이름과 주소는 본문에 넣지 않는다. `#{닉네임}`은 알림을 받는 사람 자신의 이름이다.
- 승인 요청은 알림 수신 설정과 관계없이 보내는 필수 알림이다. 나머지 선물 알림에는 수신 설정 안내를 넣는다.

## 1. 인증번호

- 설정 항목: `SOLAPI_PHONE_CODE_TEMPLATE_ID`
- 변수: `#{인증번호}` — 6자리 숫자
- 버튼: 없음

```text
[팬꾹] 인증번호 안내

인증번호: #{인증번호}

3분 안에 입력해 주세요.
```

알림톡 발송 실패 시 보내는 문자의 기존 문구는 다음과 같다. 알림톡과 같은 인증번호를 사용한다.

```text
[팬꾹] 인증번호 123456 (3분 안에 입력해 주세요)
```

## 2. 승인 요청

- 종류: `approval_request`
- 받는 사람: 크리에이터
- 변수: `#{닉네임}`, `#{주문번호}`, `#{반려시각}`
- `#{반려시각}`: 서울 시간 기준 자동 반려 예정 시각. 예: `10월 29일 오전 10시`
- 버튼: **승인 요청 확인**
- 버튼 주소: `https://fankkuk.com/creator/actions?order=#{주문번호}`

```text
#{닉네임}님,
승인 대기 중인 선물이 있습니다.
선물을 확인하고 승인 여부를 선택해 주세요.

주문번호: #{주문번호}
승인 기한: #{반려시각}

기한까지 승인하지 않으면 자동 반려됩니다.
선물 상세 정보는 로그인 후 확인할 수 있습니다.

이 알림은 서비스 이용에 필요한 필수 알림으로, 알림 수신 설정과 관계없이 발송됩니다.
```

처음 승인 요청이 생길 때, 첫 상자가 도착할 때, 결제 완료 72시간 뒤의 재알림에 같은 본문을 사용한다. 보낸 팬의 닉네임, 선물 종류와 개수는 승인 화면에서 확인한다.

## 3. 상자 도착

- 종류: `box_arrived`
- 받는 사람: 보낸 팬. 역조공이면 보낸 크리에이터
- 변수: `#{닉네임}`, `#{주문번호}`, `#{경로}`
- 버튼: **상자 확인**
- 버튼 주소: `https://fankkuk.com#{경로}`
- `#{경로}`: 팬은 `/gifts/주문번호`, 역조공을 보낸 크리에이터는 `/creator/revgifts`

```text
#{닉네임}님,
보내신 상자 1개가 팬꾹에 도착했습니다.

주문번호: #{주문번호}

상자 도착 현황은 로그인 후 확인해 주세요.

알림 수신 여부는 ‘계정 설정 > 알림’에서 변경할 수 있습니다.
```

상자 하나의 도착을 알리는 문구다. 여러 상자를 보냈더라도 모두 도착했다는 뜻은 아니다.

## 4. 출고

- 종류: `shipped`
- 받는 사람: 보낸 팬
- 변수: `#{닉네임}`, `#{주문번호}`
- 버튼: **선물 보기**
- 버튼 주소: `https://fankkuk.com/gifts/#{주문번호}`

```text
#{닉네임}님,
보내신 선물이 팬꾹에서 출고 처리되었습니다.
택배사에 인계되면 배송이 시작됩니다.

주문번호: #{주문번호}

선물 진행 상황은 로그인 후 확인해 주세요.

알림 수신 여부는 ‘계정 설정 > 알림’에서 변경할 수 있습니다.
```

팬꾹의 출고 처리와 택배사의 배송 시작을 구분한다.

## 5. 배송 중

- 종류: `in_transit`
- 받는 사람: 보낸 팬
- 변수: `#{닉네임}`, `#{주문번호}`
- 버튼: **선물 보기**
- 버튼 주소: `https://fankkuk.com/gifts/#{주문번호}`

```text
#{닉네임}님,
보내신 선물이 배송 중입니다.

주문번호: #{주문번호}

선물 진행 상황은 로그인 후 확인해 주세요.

알림 수신 여부는 ‘계정 설정 > 알림’에서 변경할 수 있습니다.
```

현재는 택배사 연결 전이므로 이 알림을 발생시키는 배송 정보가 들어오지 않는다. 연결 후 발송에 사용할 문구다.

## 6. 배송 완료

- 종류: `delivered`
- 받는 사람: 보낸 팬
- 변수: `#{닉네임}`, `#{주문번호}`
- 버튼: **선물 보기**
- 버튼 주소: `https://fankkuk.com/gifts/#{주문번호}`

```text
#{닉네임}님,
보내신 선물의 배송이 완료되었습니다.

주문번호: #{주문번호}

선물 상세 정보는 로그인 후 확인해 주세요.

알림 수신 여부는 ‘계정 설정 > 알림’에서 변경할 수 있습니다.
```

택배사가 제공하는 배송 완료 정보를 기준으로 한다. 택배사 연결 뒤 사용할 문구이며, 크리에이터가 ‘받았어요’를 눌러 수령을 확인하는 알림과는 구분한다.

## 7. 답장 도착

- 종류: `gift_reply`
- 받는 사람: 보낸 팬
- 변수: `#{닉네임}`, `#{주문번호}`
- 버튼: **답장 보기**
- 버튼 주소: `https://fankkuk.com/gifts/#{주문번호}`

```text
#{닉네임}님,
보내신 선물에 답장이 도착했습니다.

주문번호: #{주문번호}

로그인 후 답장을 확인해 주세요.

알림 수신 여부는 ‘계정 설정 > 알림’에서 변경할 수 있습니다.
```

## 적용할 때 확인할 사항

- 이 문서의 본문과 버튼 문구는 수정안이다. 기존 등록용 문서 `alimtalk-templates.md`와 차이가 있다.
- 인증번호 템플릿 ID는 `SOLAPI_PHONE_CODE_TEMPLATE_ID`에, 선물 알림 템플릿 ID는 `notification_kakao_templates`의 해당 `kind`에 설정한다.
- 크리에이터의 ‘받았어요’ 확인 알림인 `gift_received`는 현재 알림톡 발송 지원 목록에 없다. 템플릿을 등록하는 것만으로 발송되지 않으며, 코드 반영도 필요하다.
- 솔라피의 분류·보안 템플릿 등 등록 옵션은 등록 시 콘솔과 공식 안내에서 확인한다. 이 문서는 문구 수정안이며 검수 승인을 보장하지 않는다.
