# 카카오 알림톡 등록 가이드 — 팬꾹 참고용

확인일: 2026-11-03

전체 규정을 옮긴 문서가 아니라, 팬꾹 등록 작업에 필요한 요약이다. 공식 기준과 개별 반려 회신, 팬꾹 작업 제안을 구분했다.

## 1. 공식 가이드 요약

출처: [카카오 알림톡 심사 가이드](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit)

### 본문

- 신청·거래에 따른 정보 전달이 목적이어야 한다. 광고를 섞지 않는다.
- 일정한 발송 조건과 정형화된 본문이 필요하다.
- 변수마다 실제 형태의 예시를 제공한다. 변수만으로 본문을 구성하지 않는다.
- 변수 40개 초과, 버튼명·미리보기의 변수 사용은 반려 사유다.
- 링크 안의 설명으로 본문의 부족한 정보를 대신할 수 없다. 심사는 고정 문구와 변수 예시를 기준으로 한다.
- 반려 후에는 수정하여 재심사를 요청한다.

### 이미지

| 유형 | 표현 대상 |
| --- | --- |
| 로고형 | 채널의 가로형 로고 |
| 텍스트 혼합형 | 주요 안내 문구와 보조 이미지 |
| 아이콘형 | 상태를 나타내는 아이콘과 짧은 문구 |
| 배송 상태 안내형 | 배송 단계 |

이미지는 본문과 직접 관련되어야 한다. 광고나 개인정보가 담긴 이미지는 사용할 수 없다.

아이콘 포인트에는 브랜드 대표 색상 하나를 권장한다. 생성형 AI를 활용한 소재에는 이용자가 알아볼 수 있는 표시가 필요하다.

제공 아이콘은 카카오 소유이며, 알림톡 외 무단 사용·2차 가공 사용 제한이 명시되어 있다. 웹사이트용 공용 자산으로 전용하지 않는다.

### 상세 도면 확인

[아이콘형 포맷·배치·예시](https://kakaobusiness.gitbook.io/main/ad/infotalk/audit#id-3-3)

현재 확인에서는 삽입된 상세 도면을 불러오지 못했다. 따라서 최신 픽셀 규격·용량·배경색·안전 여백은 확정하지 않았다. 등록 전에 원본 도면과 솔라피 등록 화면을 대조한다. 기존에 제작한 800×400px 파일도 최신 세부 규격까지 검증한 결과물은 아니다.

## 2. 팬꾹이 받은 반려 회신

아래 내용은 사용자가 공유한 개별 검수 회신을 정리한 것이다.

### 발송 상황과 수신 대상 불명확

- 누가 어떤 행동을 했을 때 받는 메시지인지 본문에 추가하도록 요청받았다.
- 제3자가 보내는 선물 도착 안내라면 보내는 사람과 받는 사람의 이름 또는 전화번호를 명시하도록 요청받았다.
- 모든 선물 알림에 두 사람의 이름이 무조건 필요하다는 뜻으로 확대하지 않는다. 실제 알림의 수신 대상과 발생 조건부터 설명한다.

### 아이콘형에 일러스트 사용

- 제출한 이미지가 아이콘이 아닌 일러스트로 판단됐다.
- 브랜드 대표 색상 하나를 포인트로 사용하도록 수정 요청을 받았다.
- 일반 가이드에는 색상 하나가 ‘권장’으로 적혀 있지만, 이번 재심사에서는 개별 수정 요청도 충족해야 한다.

## 3. 팬꾹 적용안

이 절은 공식 규정이 아니라 팬꾹 작업을 위한 제안이다.

### 알림별로 구분하기

| 알림 | 받는 사람 | 재심사에서 설명할 내용 |
| --- | --- | --- |
| 상자 도착 | 선물을 보낸 회원 | 본인이 선물 보내기를 신청한 주문의 상자가 팬꾹에 도착했음을 안내 |
| 출고·배송 중·배송 완료 | 선물을 보낸 팬 | 본인이 신청한 주문의 진행 상황을 안내 |
| 승인 요청 | 선물을 받을 크리에이터 | 팬의 신청으로 발생하는 승인 요청임을 설명하고 허용 조건 문의 |

승인 요청에 보내는 사람의 이름을 추가하면, 앞서 정한 ‘보낸 팬의 닉네임은 로그인 후 승인 화면에서만 표시’ 방침과 충돌한다. 문구 수정으로 임의 변경하지 않고 솔라피에 가능 여부를 먼저 확인한다.

### 이미지 제작

- 팬꾹 포인트 색상: **하늘색 `#89CFF0`**.
- 기존 리소스의 색상만 바꿀 때는 원본 픽셀을 치환한다. 이미지 생성 도구로 다시 그리지 않는다.
- 원본 크기·글자·윤곽·투명도를 보존하고 PNG로 저장한다.
- 리소스 모음 전체가 아니라 해당 알림에 필요한 아이콘을 골라 등록용 이미지로 구성한다.
- 새로 생성한 추가 아이콘은 공식 제공 리소스와 구분한다. 생성형 AI 표시와 세부 규격을 확인한 뒤 등록한다.
- 팬꾹 사이트의 리본 선물상자 그림을 아이콘형에 그대로 사용하면 이번과 같은 반려가 반복될 수 있다.

## 4. 재등록 전 확인

- [ ] 실제 수신 대상과 발송 계기가 본문에 드러나는가?
- [ ] 변수 예시를 모두 입력했는가?
- [ ] 로그인 후 공개하는 정보를 알림에 새로 노출하지 않았는가?
- [ ] 이미지가 실제 알림 상태와 일치하는가?
- [ ] 이번 회신에서 요구한 아이콘 형태와 단일 포인트 색상을 반영했는가?
- [ ] 원본 도면과 솔라피 화면에서 크기·용량·배경·여백을 확인했는가?
- [ ] 작은 화면에서 글자와 아이콘이 선명한가?
- [ ] 생성형 AI 사용 여부에 맞는 표시를 확인했는가?
- [ ] 등록 본문·버튼·변수 이름이 실제 발송 설정과 일치하는가?
