# 크리에이터 받는 양 조절 스펙

크리에이터가 받는 양을 부담 없이 조절하게 한다. 물량이 많으면 **쉬는 중**으로 바꾸고(다시 받는 날짜를 정한다), 한 팬이 너무 자주
보내면 **팬 한 명당 한 달 N개** 한도를 켠다(기본 꺼짐). 생일과 기념일을 적어 두면 크리에이터 페이지에 30일 전부터 D-day 가 보이고,
기념일 7일 안에 등록하는 팬은 「{기념일} 선물」 표시를 고를 수 있다. 주간 전체 한도나 「이번 주 N개 남음」 같은 숫자는 두지 않는다 —
다른 팬과 겨루는 것처럼 읽힌다(추가분 F-4).

어기면 생기는 사고: 쉬는 중인데 선물이 들어오거나, 한도를 넘어 들어오거나, 남의 크리에이터를 쉬는 중으로 돌리거나,
한도에 닿은 팬의 사정이 다른 팬에게 보인다.

용어
- **쉬는 중**: 크리에이터가 정한 「다시 받는 날」이 아직 오지 않은 상태. 날짜가 오면 따로 바꾸지 않아도 받는 중이다.
- **이번 달**: 한국 시간 기준 달력의 달(1일 0시 ~ 말일 24시).
- **한도에 세는 주문**: 이번 달에 만든 그 팬 → 그 크리에이터 팬 선물 주문 가운데 결제가 실패로 닫히지 않았고 거절·반려·취소로 끝나지 않은 것.
  결제 대기도 센다(24시간 안에 결제하지 않으면 실패로 닫혀 빠진다 — payment INV-M15).

## 불변식

- INV-B1: 받는 상태·다시 받는 날·팬당 한도·생일·기념일은 그 크리에이터 본인만 바꾼다. 바꾸는 함수는 크리에이터 ID 를 인자로 받지 않고
  로그인 토큰이 확인한 계정에 연결된 크리에이터 한 줄만 바꾼다. 운영자 화면에서도 바꾸지 않는다.
  (강제 위치: DB 함수 — 본인 계정 / 크리에이터 표는 화면 쪽 API 로 쓰기 불가)
  위반 시: 남이 크리에이터를 쉬는 중으로 돌려 선물 받기를 막거나 기념일을 바꾼다.
- INV-B2: 쉬는 중인 크리에이터에게는 새 팬 선물 주문을 만들지 않는다. 이미 만든 주문(결제 대기·승인 대기·승인 뒤)은 그대로 처리된다 —
  승인·거절·입고·출고가 쉬는 중 때문에 막히지 않는다. 다시 받는 날이 되면(한국 시간 그날 0시부터) 따로 바꾸지 않아도 등록된다.
  (강제 위치: DB 등록 함수 — 주문을 만들기 전, 그 크리에이터 줄을 잠근 뒤 / 화면은 같은 판정으로 버튼만 숨긴다)
  위반 시: 쉬는 중인데 선물이 들어오거나, 쉬기 전에 승인한 선물이 멈춘다.
- INV-B3: 다시 받는 날은 쉬는 중으로 바꿀 때 꼭 정하고, 오늘(한국 시간)보다 뒤, 오늘부터 365일 안이다. 받는 중으로 바꾸면 날짜는 지운다.
  (강제 위치: DB 함수 — 저장 전 검사)
  위반 시: 날짜 없는 쉬는 중이 영원히 남거나 이미 지난 날짜로 쉬는 중이 되어 표시가 어긋난다.
- INV-B4: 팬당 한도가 켜져 있으면, 한도에 세는 주문이 이미 N개인 팬은 그 크리에이터에게 이번 달 새 주문을 만들 수 없다.
  같은 팬이 동시에 두 번 등록해도 N개를 넘지 않는다.
  (강제 위치: DB 등록 함수 — 팬·크리에이터 쌍을 잠근 뒤 세고 만든다)
  위반 시: 한도를 넘어 선물이 들어온다.
- INV-B5: 한도는 꺼짐(기본) 또는 1~10 이다. 바꾸면 바로 적용된다 — 이미 만든 주문은 그대로 두고 다음 등록부터 새 한도로 센다.
  (강제 위치: DB 함수 — 저장 전 검사)
  위반 시: 0개 한도로 사실상 받기를 막거나, 바꾼 한도 때문에 이미 결제한 주문이 취소된다.
- INV-B6: 한도에 닿았다는 사실과 한도 숫자는 그 팬 본인의 등록 화면에만 보인다. 크리에이터 페이지·찾기 화면·다른 팬에게는
  한도가 켜져 있는지도, 남은 개수도 보이지 않는다. 팬에게 보이는 문구는 「이번 달은 이미 마음을 충분히 보내셨어요. {다음 달 1일}부터 다시 보낼 수 있어요」 하나다.
  (강제 위치: 서버 — 크리에이터 페이지·찾기 응답에 한도 칸을 넣지 않음 / DB — 한도 판정 함수는 로그인한 팬 본인 것만 돌려줌)
  위반 시: 팬끼리 「몇 개까지 보냈다」를 비교하게 된다(추가분 원칙 「경쟁 대신 개인 기록」).
- INV-B7: 생일은 월·일만 받는다(연도 칸이 없다). 기념일은 최대 3개, 이름 1~12자 + 월·일이다. 이름은 직접 입력 태그와 같은
  업계 기본 필터를 거친다(금칙어·전화번호·이메일·인터넷 주소 꼴·기호만 거부 — creator-tags INV-T7).
  (강제 위치: DB 함수 — 저장 전 검사)
  위반 시: 나이가 드러나거나, 공개 화면에 욕설·연락처가 기념일 이름으로 뜬다.
- INV-B8: D-day 는 가장 가까운 생일·기념일 하나를 그날 30일 전부터 그날까지 보여 준다(한국 시간 날짜 기준, D-30 ~ D-day).
  2월 29일은 윤년이 아닌 해에 2월 28일로 친다. 같은 날이 둘이면 생일을 먼저, 그다음 등록 순서.
  (강제 위치: 화면 쪽 계산 함수 하나 — 크리에이터 페이지와 등록 화면이 같은 함수를 쓴다)
  위반 시: 지난 기념일이 남거나 두 화면의 D-day 가 다르다.
- INV-B9: 팬은 등록할 때 기념일 7일 안(D-7 ~ D-day)이면 「{기념일 이름} 선물」 표시를 고를 수 있다. 저장할 때 서버가 그날 다시 계산해
  7일 안이 아니면 표시 없이 저장한다. 표시는 그때의 기념일 이름을 주문에 복사해 둔다 — 나중에 크리에이터가 기념일을 바꿔도 남는다.
  (강제 위치: DB 등록 함수)
  위반 시: 지난 기념일 표시가 붙거나, 크리에이터가 기념일을 지우면 팬의 기록에서 표시가 사라진다.

## 스스로 정한 것 (추가분에 없던 세부)

- 다시 받는 날 상한 365일 — 판단. 날짜 없는 무기한 쉬기를 막는 추가분 「다시 받는 날짜 필수」의 연장이다. 더 길게 쉬려면 다시 고르면 된다.
- 쉬는 중 해제는 저장된 날짜와 오늘을 비교해 판정한다(예약 작업 없음) — 업계 일반 방식. 상태 칸을 따로 두면 예약 작업이 늦을 때 어긋난다.
- 한도 숫자 1~10 — 판단. 한 팬이 한 크리에이터에게 한 달 10개를 넘게 보내는 일은 드물고, 상자 수 상한(주문당 10개)과 맞춘다.
- 한도에서 거절·반려·취소된 주문은 세지 않는다 — 판단. 받지 않은 선물을 「보냈다」고 세면 거절당한 팬이 다시 보낼 수도 없다.
- 기념일 이름 12자·업계 기본 필터 — 판단. 추가분 불변식 21(고정 템플릿)은 「받기 어려운 품목·쉬는 중 안내」 문구가 대상이고, 기념일 이름은 태그처럼 짧은 이름표라 태그와 같은 필터를 쓴다.
- 기념일 「7일 안」은 D-7 ~ D-day 로 읽었다(그날이 지나면 표시 없음).
- 2월 29일 처리 — 업계 일반 방식(평년은 2월 28일).

## 시나리오

- S1 (INV-B1): Given 크리에이터 A·B / When A 로그인으로 쉬는 중 저장 / Then A 만 쉬는 중이고, B 의 ID 를 넣을 칸이 없다.
- S1b (INV-B1, 실패경로): Given 팬 로그인·로그인 안 함 / When 받는 상태 저장 함수를 부름 / Then 거부되고 아무것도 바뀌지 않는다.
- S2 (INV-B2, 실패경로): Given 크리에이터가 쉬는 중(다시 받는 날 = 내일) / When 팔로우한 팬이 등록 / Then 주문이 만들어지지 않고 「쉬는 중」으로 거부된다.
- S2b (INV-B2): Given 승인 대기 주문이 있는 크리에이터가 쉬는 중으로 바꿈 / When 크리에이터가 그 주문을 승인·거절 / Then 그대로 처리된다.
- S2c (INV-B2): Given 다시 받는 날 = 오늘 / When 팬이 등록 / Then 주문이 만들어진다.
- S3 (INV-B3, 실패경로): Given 쉬는 중으로 바꾸기 / When 날짜 없음·오늘·어제·366일 뒤 / Then 각각 거부된다. 내일·365일 뒤는 저장된다.
- S3b (INV-B3): Given 쉬는 중 / When 받는 중으로 바꿈 / Then 다시 받는 날이 지워진다.
- S4 (INV-B4, 실패경로): Given 한도 2, 이번 달 그 팬의 주문 2개(결제 완료 1·결제 대기 1) / When 세 번째 등록 / Then 「이번 달 한도」로 거부된다.
- S4b (INV-B4): Given 한도 2, 이번 달 주문 2개 중 1개가 거절 / When 등록 / Then 만들어진다. 지난달 주문은 세지 않는다.
- S4c (INV-B4, 동시): Given 한도 1, 이번 달 주문 0 / When 같은 팬이 동시에 두 번 등록 / Then 하나만 만들어진다.
- S4d (INV-B4): Given 한도 1, 팬 X 가 1개 보냄 / When 다른 팬 Y 가 등록 / Then 만들어진다(한도는 팬마다).
- S5 (INV-B5, 실패경로): Given 한도 저장 / When 0·11 / Then 거부. 1·10·꺼짐은 저장된다.
- S5b (INV-B5): Given 한도 3, 이번 달 주문 3개 / When 한도를 1로 바꿈 / Then 3개는 그대로 있고 다음 등록이 거부된다.
- S6 (INV-B6): Given 한도 켜진 크리에이터 / When 로그인 안 한 사람·다른 팬이 크리에이터 페이지를 봄 / Then 응답에 한도 칸이 없다.

- S7 (INV-B7, 실패경로): Given 기념일 저장 / When 4개·이름 13자·이름 「010-1234-5678」·2월 30일 / Then 각각 거부된다.

- S8b (INV-B8): Given 기념일 2월 29일 / When 평년 2월 28일 / Then D-day 로 보인다.
- S9 (INV-B9): Given 데뷔일이 5일 뒤 / When 팬이 「데뷔일 선물」 표시를 골라 등록 / Then 주문에 「데뷔일」이 저장된다.
- S9b (INV-B9, 실패경로): Given 데뷔일이 8일 뒤 / When 화면을 건너뛰고 표시를 붙여 등록 / Then 표시 없이 저장된다.
- S9c (INV-B9): Given 표시가 붙은 주문 / When 크리에이터가 그 기념일을 지움 / Then 주문의 표시는 남는다.
