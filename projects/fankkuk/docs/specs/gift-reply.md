# 받았어요 · 감사 답장 스펙

크리에이터는 「승인·받은 선물」 화면의 받은 선물 목록에서 상자마다 「받았어요」를 누르고, 같은 자리에서 짧은 답장(정해진 문구 하나 +
원하면 80자 한 줄)을 남기거나 답장 없이 확인만 한다. 팬은 알림을 받고, 자기 「함께한 시간」 화면(together 스펙)에서 답장 카드를 보고
카드 단위로 X 에 공유한다. 팬과 크리에이터가 둘 다 공개에 동의한 답장만 수령 확인 3일 뒤부터 링크 페이지의 「감사 답장 모음」에 보인다.

어기면 생기는 사고: 남의 선물에 답장하거나, 한쪽만 동의한 답장이 공개되거나, 알림·공개 화면에 보낸 사람·받는 사람이 드러나거나,
실시간 도착 시각이 공개돼 크리에이터의 생활 시간이 드러난다.

용어
- **받았어요(수령 확인)**: 크리에이터가 상자를 받았다고 남긴 확인 기록. 배송의 「수령」(택배사 연결이 쓰는 칸)과 따로다(사용자 답 ⑨).
- **답장**: 정해진 문구 하나 + 선택으로 한 줄(80자). 상자마다 하나.
- **답장 모음**: 링크 페이지 8번 자리(creator-link 스펙이 자리를 둔다).

## 불변식

- INV-G1: 받았어요와 답장은 그 상자가 속한 주문의 받는 크리에이터 본인만 남긴다. 함수는 크리에이터 ID 를 인자로 받지 않고 로그인 토큰의
  크리에이터와 주문의 크리에이터가 같은지 DB 가 확인한다. 상자가 출고된 뒤(출고·배송중·수령)에만 남길 수 있다.
  (강제 위치: DB 함수)
  위반 시: 남의 선물에 답장이 붙거나, 아직 사무실에 있는 상자를 「받았어요」로 표시한다.
- INV-G2: 받았어요는 상자마다 한 번이다. 「답장 보내기」나 「답장 없이 확인만」을 누를 때 확정된다(버튼을 여는 것만으로는 아니다).
  두 번 눌러도, 동시에 눌러도 기록과 알림은 하나다. 답장 없이 확인만 한 상자에는 나중에 답장을 한 번 더할 수 있다.
  (강제 위치: DB — 상자당 한 줄 고유)
  위반 시: 팬에게 같은 알림이 여러 번 간다.
- INV-G3: 답장의 정해진 문구는 다섯 개 중 하나다(잘 받았어요, 고마워요 / 너무 마음에 들어요 / 잘 쓸게요 / 덕분에 힘이 났어요 / 정성이 느껴져서 감동이에요).
  한 줄은 앞뒤 공백을 뺀 0~80자, 줄바꿈 없음, 업계 기본 필터(금칙어·전화번호·이메일·인터넷 주소 꼴 거부 — creator-tags INV-T7)를 거친다.
  이 한 줄이 크리에이터가 자유롭게 쓰는 유일한 칸이다(추가분 불변식 21의 예외).
  (강제 위치: DB 함수 — 저장 전 검사)
  위반 시: 답장으로 연락처가 오가거나 욕설이 팬의 기록·공개 모음에 남는다.
- INV-G4: 답장은 고칠 수 없고, 크리에이터가 하나씩 지울 수 있다. 지우면 팬의 기록·공개 모음·공유 카드 생성에서 모두 사라진다. 지운 상자에는 다시 쓰지 않는다.
  (강제 위치: DB 함수)
  위반 시: 지운 답장이 공개 모음에 남거나, 지우고 다시 쓰기를 반복해 팬에게 알림이 여러 번 간다.
- INV-G5: 팬에게 가는 알림은 둘이다 — 답장이 있으면 「답장이 왔어요」, 확인만이면 「보낸 선물이 도착했다고 확인됐어요」. 한 상자에 둘 다 가지 않는다
  (확인만 한 뒤 답장을 더하면 그때 「답장이 왔어요」 하나). 본문에는 알림 규칙(notifications INV-N1)이 허용한 값만 들어간다 — 크리에이터 이름·답장 내용은 없다.
  (강제 위치: 서버 — 알림 종류별 본문 틀)
  위반 시: 알림 미리보기로 누가 누구에게 보냈는지 드러난다.
- INV-G6: 팬 화면의 상자 상태는 받았어요 기록이나 배송 수령 중 하나라도 있으면 「받았어요」다. 날짜만 보이고 시각은 보이지 않는다.
  (강제 위치: 서버 — 팬 화면용 읽기)
  위반 시: 실시간 도착 시각이 남아 크리에이터의 생활 시간이 드러난다(추가분 불변식 22).
- INV-G7: 답장 모음에는 ① 팬이 그 답장에 「공개해도 괜찮아요」를 켜고 ② 크리에이터가 설정에서 「답장 모음 보이기」를 켜고 ③ 받았어요 날짜(한국 시간)로부터
  3일이 지난 답장만 최신순으로 보인다. 하나라도 꺼지면 바로 내려간다. 팬 닉네임은 팬이 「닉네임도 보이기」를 고른 답장만, 아니면 「익명의 팬」.
  보이는 칸은 정해진 문구·한 줄·날짜·팬 닉네임(또는 익명의 팬)뿐이다.
  (강제 위치: DB 공개 읽기 함수)
  위반 시: 한쪽 동의만으로 답장이 공개되거나, 막 받은 선물이 바로 공개돼 도착 시점이 드러난다(추가분 불변식 20·22).
- INV-G8: 공개 동의(「공개해도 괜찮아요」·「닉네임도 보이기」)는 그 선물을 보낸 팬 본인만 바꾼다. 「답장 모음 보이기」·X 계정·「태그 허용」은 크리에이터 본인만 바꾼다.
  (강제 위치: DB 함수 — 로그인 토큰의 계정)
  위반 시: 남이 팬의 답장을 공개로 돌린다.
- INV-G9: 공유 카드는 그 선물을 보낸 팬 본인만 만든다. 카드에는 크리에이터 프로필 사진·공개 이름·답장(문구와 한 줄)·날짜·팬꾹 로고, 그리고 팬이 고른 경우에만
  팬 닉네임이 들어간다. 주소·주문번호·운송장·물품·팬이 올린 사진은 없다. 공유 문구는 「#팬꾹」, 크리에이터가 X 계정을 등록하고 「태그 허용」을 켠 경우만 「@계정」이 붙는다.
  (강제 위치: 서버 — 카드 생성 라우트가 주인을 확인하고 정해진 칸만 받는다)
  위반 시: 남의 답장이 퍼지거나 카드에 주문 정보가 찍힌다.
- INV-G10: 「아직 답장 안 한 선물 N개」는 크리에이터 본인 화면에만 보인다. 받았어요를 누를 수 있는데(출고 뒤) 답장이 없고 지우지도 않은 상자 수다.
  (강제 위치: DB 본인 읽기 함수)
  위반 시: 답장률이 공개돼 크리에이터가 압박받는다.

## 스스로 정한 것 (추가분·사용자 답에 없던 세부)

- 정해진 문구 다섯 개 — 시안 그대로.
- 받았어요는 출고 뒤부터 — 판단. 택배사 연결 전이라 배송 수령을 기다리면 누를 수 없다.
- 답장은 고칠 수 없고 지우기만, 지운 상자엔 다시 쓰지 않음 — 판단(알림 반복 방지).
- 한 줄에도 태그와 같은 업계 기본 필터 — 판단. 개인 답장이지만 공개 모음·공유 카드로 나갈 수 있다.
- 3일은 받았어요 날짜(한국 시간) + 3일째 0시부터 — 판단(날짜 단위 표시 원칙과 맞춤).
- 답장 모음은 최신 20개까지 — 판단.
- X 계정은 영문·숫자·밑줄 1~15자(X 의 아이디 규칙) — 업계 표준.
- 탈퇴한 크리에이터의 답장은 팬의 기록으로 남고 이름은 「탈퇴한 크리에이터」·기본 이미지(사용자 답 ⑭). 앱 안 탈퇴 흐름과 「답장도 지우기」 선택은 탈퇴 흐름을 만들 때 — BACKLOG.
- 공유 카드 답장 문구는 길이에 따라 글자 크기를 줄인다 · 답장 속 팬 닉네임은 그대로(DECISIONS 2026-10-11).
- 메뉴 이름 「승인 요청」 → 「승인·받은 선물」(시안).

## 시나리오

- S1 (INV-G1, 실패경로): Given 크리에이터 B·팬 / When 크리에이터 A 가 받은 상자에 받았어요·답장 / Then 거부되고 아무것도 남지 않는다.
- S1b (INV-G1, 실패경로): Given 검수 완료(출고 전) 상자 / When 받는 크리에이터가 받았어요 / Then 거부. 출고된 상자는 된다.
- S2 (INV-G2, 동시): Given 출고된 상자 / When 받았어요를 동시에 두 번 / Then 기록 하나·알림 하나.
- S2b (INV-G2): Given 확인만 한 상자 / When 답장을 더함 / Then 답장이 저장되고 「답장이 왔어요」 알림 하나가 간다.
- S3 (INV-G3, 실패경로): Given 답장 / When 목록 밖 문구·한 줄 81자·줄바꿈·전화번호 꼴 / Then 각각 거부. 80자·빈칸은 저장.
- S4 (INV-G4): Given 공개된 답장 / When 크리에이터가 지움 / Then 팬의 기록·모음·카드 생성에서 사라지고, 같은 상자에 다시 쓰기는 거부.
- S5 (INV-G5): Given 답장과 함께 받았어요 / When 알림 줄 / Then 「답장이 왔어요」 하나, 본문에 크리에이터 이름·답장 내용이 없다.
- S6 (INV-G6): Given 받았어요만 있음(배송 수령 없음) / When 팬 화면 / Then 「받았어요」와 날짜, 시각 없음.
- S7 (INV-G7): Given 팬 공개 켬·크리에이터 모음 끔 / When 링크 페이지 / Then 안 보임. 크리에이터도 켜면 받았어요 3일 전에는 안 보이고 3일째부터 보인다.
- S7b (INV-G7): Given 공개된 답장, 팬이 닉네임 안 보이기 / When 링크 페이지 / Then 「익명의 팬」.
- S8 (INV-G8, 실패경로): Given 다른 팬·크리에이터 / When 남의 답장 공개 동의를 바꿈 / Then 거부.
- S9 (INV-G9, 실패경로): Given 다른 팬 / When 남의 답장 카드 생성 주소를 엶 / Then 거부.
- S9b (INV-G9): Given X 계정 등록·태그 허용 끔 / When 공유 문구 / Then 「#팬꾹」만, 켜면 「@계정」이 붙는다.
- S10 (INV-G10): Given 출고 상자 3개 중 답장 1·확인만 1·아무것도 없음 1 / When 크리에이터 화면 / Then 「아직 답장 안 한 선물 2개」. 다른 사람 응답에는 없다.
