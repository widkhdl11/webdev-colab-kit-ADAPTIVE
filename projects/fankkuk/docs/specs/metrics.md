# 측정 스펙

추가분 기능이 실제로 팬을 다시 보내게 하는지 운영자가 본다. 숫자는 비율과 건수만이고, 누가 몇 번 보냈는지는 운영자 화면에도 없다.

어기면 생기는 사고: 운영자가 아닌 사람이 집계를 보거나, 집계 화면이 팬별 활동 목록이 되거나, 가입 경로 값으로 아무 글이나 저장된다.

용어
- **보낸 선물**: 결제가 끝나고 취소·결제 실패가 아닌 팬 선물 주문(거절·반려 포함 — 보낸 것은 맞다).
- **첫 선물**: 한 팬이 처음 보낸 선물(크리에이터와 상관없이).

## 불변식

- INV-Q1: 집계는 운영자(대표·직원)만 읽는다. 집계 함수는 운영자가 아니면 거부한다.
  (강제 위치: DB 함수 — 운영자 판정 / 화면 — 운영자 틀 안)
  위반 시: 팬·크리에이터의 활동 규모가 밖으로 샌다.
- INV-Q2: 집계 결과는 비율과 그 분모·분자 건수뿐이다. 팬·크리에이터 이름·ID·주문번호 목록은 돌려주지 않는다.
  (강제 위치: DB 함수 — 돌려주는 칸)
  위반 시: 집계 화면이 팬별 활동 목록이 된다(추가분 원칙 「경쟁 대신 개인 기록」).
- INV-Q3: 재발송률 = 첫 선물을 보낸 지 60일이 지난 팬 가운데, 첫 선물 뒤 60일 안에 선물을 한 번 더 보낸 팬의 비율. 60일이 아직 안 지난 팬은 분모에 넣지 않는다.
  답장 여부별 재발송률은 같은 계산을 「첫 선물의 상자에 답장이 남은 팬」과 「아닌 팬」으로 나눈 둘이다.
  감사 답장률 = 받았어요가 남은 상자 가운데 답장이 남은(지우지 않은) 상자의 비율.
  (강제 위치: DB 집계 함수 하나 — 기준 시각을 받는 내부 함수로 나눠 경계 시험)
  위반 시: 아직 다시 보낼 시간이 없던 팬이 섞여 재발송률이 낮게 나온다.
- INV-Q4: 가입 경로 질문은 고르는 것 하나(X / 크리에이터 방송 / 팬 커뮤니티 / 지인 / 기타)이고 답하지 않아도 가입된다. 공유 링크의 utm 값(source·medium·campaign)은
  처음 들어온 순간에만 기록하고, 영문 소문자·숫자·밑줄·하이픈 1~50자만 저장한다(그 밖은 버린다). 가입할 때 계정에 붙는다.
  (강제 위치: DB — 가입 경로 칸의 값 목록·utm 칸 꼴 / 서버 — 쿠키 값 거르기)
  위반 시: 아무 글이나 저장돼 운영자 화면에 스크립트·욕설이 뜨거나, 답하기 싫은 사람이 가입하지 못한다.
- INV-Q5: 받기 어려운 품목 안내가 뜬 등록은, 안내가 뜬 품목과 마지막에 고른 품목을 주문에 남긴다. 「안내 뒤 바꾼 비율」 = 안내가 뜬 뒤 결제까지 간 주문 가운데 품목을 바꾼 비율.
  거절률은 달마다(한국 시간) 결정이 난 주문 가운데 거절·반려 비율.
  (강제 위치: DB 등록 함수 — 안내 품목은 서버가 그때의 받기 어려운 품목과 다시 맞춰 본다 / 집계 함수)
  위반 시: 화면이 보낸 값만 믿어 안내가 뜨지도 않은 주문이 「바꿨다」로 세진다.

## 스스로 정한 것 (추가분에 없던 세부)

- 보낸 선물에 거절·반려 포함 — 판단(팬 쪽 행동을 재는 숫자).
- 답장 여부는 첫 선물 기준 — 판단. 첫 경험이 다음 선물로 이어지는지를 본다.
- 결제 전에 그만둔 등록은 세지 않는다 — 판단. 등록 중간 기록을 따로 쌓지 않는다.
- utm 은 첫 방문 쿠키(30일) — 업계 일반 방식(처음 들어온 경로를 친다).
- 화면은 운영자 메뉴 「측정」 한 장, 기간 고르기 없이 전체 + 최근 3개월 달마다 — 판단.

## 시나리오

- S1 (INV-Q1, 실패경로): Given 팬·크리에이터·로그인 안 함 / When 집계 함수 / Then 거부.
- S2 (INV-Q2): Given 운영자 / When 집계 결과 / Then 비율·건수 칸만 있다.
- S3 (INV-Q3): Given 팬 A 첫 선물 70일 전·50일 전 두 번째 · 팬 B 첫 선물 70일 전 한 번 · 팬 C 첫 선물 10일 전 / When 재발송률 / Then 1/2(C 는 분모 밖).
- S3b (INV-Q3): Given A 의 첫 선물에 답장 있음·B 없음 / When 답장 여부별 / Then 답장 받은 쪽 1/1, 못 받은 쪽 0/1.
- S4 (INV-Q4): Given 가입 경로 안 고름 / When 가입 / Then 가입된다. utm 에 `<script>` 가 들어온 링크 / Then 그 값은 저장되지 않는다.
- S5 (INV-Q5): Given 꽃이 받기 어려운 품목 / When 팬이 꽃에서 안내를 보고 인형으로 바꿔 결제 / Then 안내 품목 꽃·마지막 인형이 남는다. 받기 어려운 품목이 없는데 화면이 안내 값을 보내면 버린다.
