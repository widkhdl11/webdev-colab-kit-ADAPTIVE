## 0. 먼저 알아야 할 사실 네 가지

1. **이번 배포는 출시가 아니라 시험 사이트다**(10-12 카드 d61 「시험용으로」). 실제 운영 DB 는 출시 때 새로 만든다. 그래서 「선착순 50명」「출시 후 3개월」「이름 선점」처럼 **운영 DB 에서 순번·기간을 세야 하는 것**은 시험 사이트에 넣어도 출시 때 사라진다.
2. **소형 4,900원은 지금 원가 가정으로는 상자마다 600원 손해다.** 지금 요금표의 원가 가정은 택배 4,000원 + 검수비 1,500원 = 5,500원이다. 원문은 택배 3,500원을 가정해 「1,050원이 남는다」고 계산했다. DB도 「원가 합 ≤ 받는 값」을 강제해서, 지금은 4,900원을 저장할 수 없다. 원문 요금표에는 그 뒤에 생긴 대형 구간도 없다.
3. **원문이 기대는 규칙 몇 개가 이미 바뀌었다.**
   - 「개봉은 기존 규칙(위험 신호·크리에이터가 켠 경우)」 → 오늘 위험 신호 개봉을 빼기로 했다.
   - 팬덤 이름의 「다른 크리에이터 이름」 검사 → 오늘 「이미 있는 욕설 필터만」으로 정했다.
   - 공지 이미지 요금 줄의 「추적 장치 검수 포함」 → 문구 v2에서 쓰지 않는 말이다.
   - 쇼핑몰에서 바로 받을 때 「받는 분 이름 = 주문번호, 송장번호로 매칭」 → 10-07부터 받는 주소 끝 6자리로 상자를 찾고, 받는 사람은 「팬꾹」으로 고정돼 있다.
4. **이미 있는 것:** 프로필 사진(EXIF 제거·정사각 자르기), 한 줄 소개 40자, 미리보기 이미지 주소의 판 값(사진을 바꾸면 갱신), 정사각 공유 카드, utm 가입 경로 측정, 「공유 이미지에는 고정 문구와 등록 값만」 규칙, 결제 뒤 요금을 바꾸지 않는 규칙.

## 5. 버리는 것 (원문에 있지만 지금 결정과 다름)

- 원문 1절 「개봉은 기존 규칙(위험 신호, 신고 불일치, 크리에이터가 켠 경우)」 → 위험 신호·크리에이터 설정 개봉은 오늘 하지 않기로 했다. 개봉은 지금 검수 규칙(탐지기 반응)대로.
- 원문 F-20 팬덤 이름 「다른 크리에이터 이름·팬꾹 사칭 단어」 검사 → 오늘 「이미 있는 욕설 필터만」.
