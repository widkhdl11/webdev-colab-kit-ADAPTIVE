2차에 가서 부딪힐 곳(지금 정할 것 아님, 기록만):
- 협찬은 건마다 카카오 승인 없이 **링크만으로** 주소를 연다 — 지금 「건마다 서명해야 주소가 열린다」는 규칙과 다른 길이라 2차 스펙에서 인가 규칙을 새로 써야 한다.
- 협찬 경로만 상온 밀봉 식품·화장품을 허용 — 지금 금지 품목 표는 하나라 경로별로 갈라야 한다.

## 4. 묶음 4 — 새로 만들 것과 시점

부딪히지 않고 지금 없는 것들이다.

| # | 기능 | 하는 일 | 크기 |
|---|---|---|---|
| 4-1 | 팬덤 이름 | 크리에이터 설정에 「팬을 부르는 이름」(선택, 10자). 링크 페이지 감사 문장이 「{팬덤 이름} 여러분의 마음 늘 감사해요」로 바뀐다. 금칙어 검사는 이미 있는 필터를 다시 쓴다 | DB 칸 하나 + 설정 칸 + 문장 하나 |

시점 선택지:

- **A. 배포 전엔 묶음 1·2의 문구 변경만, 4-1~4-5는 배포 바로 뒤 (추천)** — 지금 push 안 한 커밋이 48개이고 운영 DB 변경도 하나 대기 중이다. 4-1은 DB 칸이 새로 생겨 운영 DB 변경이 하나 더 늘고, 4-1~4-5 모두 리뷰·사인오프를 다시 돌아야 한다. 문구만 바꾸면 배포가 하루 안에 나간다.
- **B. 4-1~4-5까지 다 하고 배포** — 한 번에 나가지만 배포가 며칠 늦어지고, 그동안 쌓인 48개 커밋이 운영에 올라가지 않는다.
- **C. 문구 변경도 배포 뒤로, 지금 상태로 바로 배포** — 가장 빠르지만 「본인 확인 완료」「팬꾹 공식 계정」 같은 말이 운영에 그대로 나간다.
