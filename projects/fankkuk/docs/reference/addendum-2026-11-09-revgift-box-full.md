「팬에게 보내기(선물함)」 확정 사양 전체. 지금까지 보낸 관련 지시를 전부 이것으로 대체한다. 이 문서를 DECISIONS와 reverse-gift 스펙의 근거로 저장하고, 현재 구현과 한 줄씩 대조해 빠진 것·다른 것 목록을 먼저 보여 줘. 구현은 그 목록을 내가 확인한 뒤.

[용어]
1. 메뉴 「팬에게 보내기」, 설명 명사 「답례 선물」(안내 글 첫 등장에만 「답례 선물(역조공)」 병기). 신청 회차 이름 「선물함」. 크리에이터 「선물함 만들기」「선물함 마감」, 팬 「선물함 신청」「신청 취소」. 운영자 화면 「묶음 발송」. 「역조공」「합포장」「안 받을게요」는 화면에서 제거(코드 식별자는 유지). 팬의 받은 선물 목록은 「받은 선물」 그대로.

[선물함 만들기 — 크리에이터]
2. 정원(선택, 비우면 제한 없음, 안내용 숫자), 선정 방식(선착순/추첨), 신청 자격(팔로워 전체 / 팬꾹으로 선물 보낸 적 있는 팬만), 초대 링크.
3. 기존 개별배송·묶음배송 선택 네비게이션 제거. 흐름은 하나: 만들기 → 신청 받기 → 마감 → 상자 발송 → 실측 후 결제(또는 미리 결제) → 팬꾹 발송.

[신청 — 팬]
4. 링크 페이지에서 「선물함 신청」 → 받을 주소·이름·전화를 포함한 신청 폼 작성. 정원 안이면 「당첨」, 넘으면 「대기 N번」. 대기도 같은 폼을 작성한다.
5. 주소는 이 신청 한 건에만 복사. 팬 설정의 주소 저장 기능은 두지 않는다.
6. 「신청 취소」는 상자 입고 전까지 가능. 결제 전이면 환불 없이 명단에서 빠지고, 결제 후면 그 몫 환불. 입고 후는 반송 규칙.
7. 초대: 크리에이터가 신청 안 한 팬에게 「신청해 주세요」 알림 → 같은 신청 폼. 크리에이터가 명단에 직접 넣는 동작 없음. 양도 기능 없음.

[대기]
8. 자리가 나면 대기 1번이 즉시 당첨으로 바뀌고 알림만 간다. 입력 기한·다음 대기자 넘김·재알림 기능은 만들지 않는다. 크리에이터에게 묻지 않는다.
9. 추첨 방식은 당첨 N + 예비 K를 자동 선정, 예비가 대기 순서.
10. 선물함 발송 시 당첨되지 못한 대기자 주소 즉시 삭제, 「이번엔 정원이 찼어요」 알림.
11. 정원을 안 켜면 대기 관련 요소는 화면에 없다.

[신청 관리 모달]
12. 크리에이터 링크 페이지(로그인 상태)와 「팬에게 보내기」 화면 둘 다에서 같은 모달. 링크 페이지에는 「선물함 열림 · 모집 N / 신청 M / 대기 K」 띠. 크리에이터 메뉴에 「내 페이지」 한 칸(d6).
13. 모달: 모집·신청·대기 숫자, 닉네임 검색, 신청 목록(신청 순, 닉네임·[제외]), 대기 목록([포함] — 정원과 무관하게 넣을 수 있음), [선물함 마감] [닫기]. 페이지 이동 없음.
14. 크리에이터에게는 닉네임과 인원수만. 주소·탈락자 명단은 안 보임.
15. 마감 조건: 신청 1명 이상. 마감 전 선물함 취소 가능. 「10명까지」 제한 없음.
16. 마감 후에도 상자 입고 스캔 전까지 추가 신청·초대 받음(결제가 입고 후이므로 추가 결제 흐름 없음). 입고 스캔으로 명단 닫힘.

[화면 흐름 — 마감 후 4페이지]
17. 1페이지 설명: 그림 하나(크리에이터 → 팬꾹 → 팬). 왼쪽 「직접 보낼 때」(팬마다 주소 받기·포장·접수), 오른쪽 「팬꾹」(닉네임 적은 선물을 큰 상자 하나에 → 팬꾹이 팬마다 발송). 배송비 횟수 비교 금지. 큰 상자 택배비는 별도(크리에이터 부담, 착불 가능) 명시. 준비물: 팬 닉네임 적은 선물들, 큰 상자, 팬꾹 수령 주소. 버튼 「이해했어요, 진행하기」.
18. 2페이지 상자 선택: 당첨 팬 목록, 팬마다 구간 선택(극소형·소형·중형·대형), 「전부 ○형」 일괄 후 개별 변경, 구간별 상자 그림 + 세 변 합 재는 법 그림, 선택마다 예상 금액 갱신(택배비 + 서비스료), 「입고 실측 후 확정됩니다」「헷갈리면 한 단계 위로 고르세요. 남으면 환불됩니다」, 요금표(설정값에서 읽음).
19. 3페이지 다음 작업: 「큰 상자에 팬 닉네임을 적은 선물을 담아 팬꾹으로 보내 주세요」 + 그림. 라벨 PDF 없음, 닉네임 목록 복사 버튼. 「실측 후 명세서와 함께 결제 요청을 드립니다」 + 「미리 결제하기」(선택). 결제 기한 3일, 미결제 7일째 착불 반송 한 줄. 팁 영역 「우체국 방문수거 신청하기」: 우체국·CJ대한통운·한진·롯데 앱의 「방문접수」(착불)로 팬꾹 수령 주소(6자리 코드 포함) 입력, 메뉴 이름 한 줄씩, 주소 복사 버튼. 팬꾹 대신 신청 기능 없음.
20. 4페이지 결제: 입고 실측 후 알림 + 명세서(팬별 구간·택배비·서비스료·합계). 1회 결제(선결제했으면 차액만).

[입고·실측·결제]
21. 큰 상자 하나에 6자리 코드 하나. 안의 선물은 닉네임으로만 구분.
22. 닉네임 대조: 정확히 같으면 진행, 비슷하면 가장 가까운 닉네임과 맞춰 운영자 「확인 필요」, 명단에 없거나 안 적혀 있으면 보류 + 크리에이터 알림(모달에서 지정 또는 빼기, 처리할 일 카드). 명단보다 선물이 적으면 못 받는 팬을 크리에이터에게 알리고 금액에서 제외.
23. 미리 결제: 2페이지 예상 금액 선결제. 확정 ≤ 결제면 차액 자동 부분 환불 후 바로 발송, 초과면 발송 보류 + 차액 결제 요청(같은 화면·기한). 결제 상태 미결제·선결제·확정결제. 2회 미결제 계정은 선결제 필수.
24. 결제 기한 3일, 알림 2회, 7일째 착불 반송.

[요금 — 설정표 기반]
25. 택배사 요금표 관리 화면(/admin/pricing/couriers)과 요금 설정 화면(/admin/pricing)은 앞서 보낸 「요금 설정 구조」·「안전장치」 지시대로(활성 택배사, 표준 구간, 팬꾹 구간 「어디까지」 매핑, 검사, 원가로 맞추기, 결제 시 스냅샷, 인상은 30일 뒤 적용, 그 외 즉시).
26. 초기값: 활성 택배사 로지아이 CJ A등급(2kg/80 2,990 · 5kg/100 3,490 · 10kg/120 4,390 · 15kg/140 5,500). 팬에게 보내기 택배비 = 원가 100원 반올림(극소형 3,000 · 소형 3,500 · 중형 4,400 · 대형 5,500). 140cm·15kg 초과는 개인접수(우체국 실비, 수동).
27. 서비스료 정가 건당 700원. 초기 크리에이터(선착순 50명) 300원, 월 30건(출고 기준)까지, 초과분 700원. 약속은 「정가보다 낮게 유지」, 현재값·상한은 설정값, 변경 시 30일 전 공지, 계정 유지 동안 적용, 양도 불가. 표시 「초기 크리에이터 서비스료 300원 (월 30건까지, 이후 700원)」. 「영구」「평생」「할인」「N%」 금지. 배포 전 검사: 초기 서비스료 < 정가.
28. 크리에이터 → 팬꾹 큰 상자 택배비는 크리에이터 부담 실비.
29. 제주·도서 할증: 우편번호 판정, 제주 4,000, 도서 평균 5,000(설정값) 결제 시 미리 받음, 명세서에 팬별 표시.
30. 택배 계약 전 시험 운영 플래그(초기 크리에이터 한정, 서비스료 0원)는 설정값으로 둔다.

[발송·배송 현황]
31. 송장 발급: 로지아이 엑셀 반자동(직접출력). 출고분 엑셀 생성(대표 권한, 주소 복호화 1회, 열람 기록, 10분 만료) → 로지아이 업로드·출력 → 송장번호 엑셀 가져오기 → 출고 알림.
32. 배송 현황: 웹훅 전에는 「팬꾹에서 보냈어요」 → 「보통 1~2일 안에 도착해요」 → 「도착했어요」(팬이 [받았어요] 누르면 확정) → 미확인 출고 +3일 「도착했어요(예상)」. 택배API(deliveryapi.co.kr) 연결 후 실제 단계로 전환. 팬·크리에이터 화면에 송장번호 외 지점명·기사·지역 표시 금지(앞서 보낸 배송 현황 지시대로).

[약관·안내]
33. 약관: 요금은 택배비(설정표, 실비 반올림) + 서비스료, 금액은 「별표 요금표」 참조. 초기 크리에이터 조항(27번 내용). 금액은 입고 실측 후 확정, 결제 기한 3일 경과 시 반송 가능. 신청 주소는 그 건에만, 송장 출력 후 삭제, 크리에이터 비제공. 대기자 주소는 선물함 발송 시 삭제. 변호사 검토 목록에 추가.
34. 초기 크리에이터 안내문(쪽지·알림톡·안내 페이지, 격식체): 「안녕하세요, 팬꾹입니다. / 초기 크리에이터 선착순 50분께는 몇 가지 혜택을 드립니다. / 현재 적용 중인 혜택은 「팬에게 보내기」 서비스료입니다. 팬 한 분당 300원(정가 700원)이며, 매월 30건까지 적용됩니다. 택배비는 별도입니다. / 혜택은 계정을 유지하시는 동안 이어지며, 앞으로 다른 혜택도 추가할 예정입니다. 조건이 변경될 경우 30일 전에 안내드립니다. / 남은 자리는 N분입니다. / 감사합니다. 팬꾹 드림」
35. 외부 발송 글은 격식체, 가벼운 말투는 화면 안 짧은 안내에만.

[운영 지표]
36. 운영자 화면: 건당 실제 작업 시간, 초기 크리에이터 월 평균 건수, 51번째 이후 이용률, 직접 보내기로 돌아간 크리에이터 수, 월 발송 건수(두 달 연속 30건 미만이면 택배 경로 재검토 경고). 집계값만.
